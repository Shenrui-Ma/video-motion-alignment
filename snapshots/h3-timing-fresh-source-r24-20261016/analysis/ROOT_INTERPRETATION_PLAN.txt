R24 interpretation and follow-up rules
Written before any generated R24 clip was opened or any generated pose output was read.

This batch estimates behavior on four prespecified source/seed pairs. The two fresh sources were chosen for visible arm transitions, not sampled randomly from a population. Two seeds per source do not establish general failure frequency. Every one of the eight runs remains in the report, including editing failures, tracking uncertainty, normal results and regressions.

First require execution validity: per-pair input/condition/noise equality and the pre-intervention index005 endpoint equality, true20NFE/20Euler and expected0/450 block routes; exact PTS/frame count/geometry. Each outcome is attached to actual files and hashes. A failed integrity gate is an invalid comparison; it is not a scientific failure or permission to silently rerun a seed.

For each of the three source-only windows, retain all49 lag scores for each frozen feature at both confidence thresholds. Report accepted lag with sign, shape error at same physical frame, common-support coverage, and the original rejection reason for UNKNOWN. UNKNOWN does not acquire a zero or improvement label. The high-confidence wrist measurement is already source-limited for both primary windows.

The existing ±2frame interpretation band is descriptive at24fps. A native accepted value outside it followed by a guided accepted value inside it supports repair of that feature/window on this sample. Native values already inside it supply preservation evidence; movement outside it is a regression. Improvements that remain outside it are partial. Opposite signs in other windows show nonuniform timing effects. Disagreement among reliable features is reported as mixed, not resolved by selecting a favored feature. No new metric threshold is tuned to R24 outputs.

Timing and image quality are separate axes. Inspect the previously fixed source-semantic frames and full same-frame videos for identity editing, duplicated body parts, hand blur, background, body proportions and camera consistency. A reduction of temporal error accompanied by visible damage is a tradeoff. Pose confidence is not an image-quality score, and a pose model agreeing with a controller is not independent human confirmation.

Possible next decisions after pair results:
- At least one fresh pair has a reproducible relevant native mismatch and Full repairs it: retain that pair as a new development case; inspect whether quality cost and late/early windows motivate a targeted mechanism. A second seed/source is kept as a prospective comparison wherever possible. Further use of a seen pair is labeled development, not held-out testing.
- Native motion is already aligned in all reliable measurements: quantify preservation or damage under Full. This is useful evidence about when guidance should remain inactive. Do not search unlimited seeds until a bad case appears and report only that case.
- Full fails on the fresh mismatch or degrades motion/appearance: retain the negative result and compare its correspondence/visibility characteristics with the old cases before further GPU work.
- Coverage or tracking prevents a conclusion: report insufficient observation and use the existing source-semantic video display for manual review. Replacing tracking or adding a new representation requires an explicitly recorded new evaluation arm; it cannot overwrite frozen metrics.

Layer-selective intervention is currently only a candidate diagnostic. Ordinary depth ablation alone is not an architecture novelty. Before any GPU extension, require the local inventory and primary-source overlap review, a definite causal question, a frozen small comparison and a claim limited to what it tests. No threshold or attention variant is queued simply because compute remains available.

Current services process the four frozen jobs per source consecutively. CPU analysis starts only after each run has successful persisted history and immutable stable outputs, while later jobs continue. Keep the models through queued work as requested. Record wall time/NFE/capture costs without speed optimization.
