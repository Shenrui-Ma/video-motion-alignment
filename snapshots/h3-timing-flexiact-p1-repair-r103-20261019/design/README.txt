R103：两条既有 FlexiAct 失败任务的 P1 修复提案

两条任务沿用原视频、原目标图；已有输入节点确实把这两份素材送入 H3 reference 编码。当前证据表明编辑任务失败，失败原因尚未定位到某一模块。

1. human2animal_2 / game_man_4
原片是坐姿前屈拉伸：盘腿坐直、双手下移支撑、身体前倾、双臂向前伸、低位保持。旧 R66 普通编辑和固定引导仍呈现原女人、蓝色运动上衣、花纹裤及湖边场景，角色替换未完成。原目标图为短黑发动漫男性、绿披肩、棕夹克、交叉绑带、长靴和腰侧装备，白色背景；其字节与 R98 已成功使用的目标图完全相同。
P1 把角色与环境归给 Picture 1，把坐姿动作与时间归给 Video 1；沿用 R98 成功提示词的身份描述和六段组织，动作段替换为本源可见的前屈拉伸。图中站姿不充当首帧。该素材主要是一轮持续前屈，适合修复身份任务及检验缓慢动作，不新增为“动作密集”的例子。

2. chest / game_girl_1
原片为男性双手持拉索把手，双臂展开、向身前低位合拢、再展开。旧 R49 普通编辑在已检查六个时刻保留源男性和蓝背心，女角色替换失败；此结论来自固定时刻审阅，尚不冒称逐帧完整身份标注。旧自动版零次触发且与普通版等同的记录，不能用于归因引导造成身份残留。
原目标图是半身铠甲女性：侧分深色头发、金属灰胸甲和肩甲、深色内衬、暗青黑背景；下方有图库文字边条，参考中没有完整手部与下半身。P1 明确面部与可见铠甲来源，动作幅度和取景范围沿原运动视频；手持拉索另列为动作接触物。原官方 chest caption 本身也明确要求握住器械把手、向下拉动并回到起点；旧推理的三句话未使用这份 caption。验收只要求可见身份和装甲符合参考，不把未给出的腿部、手部细节当成身份真值。现有原图继续保留。

提示词的作用范围
两条均按官方 full-reference 六段格式拟写，用 [reference generation]、Subject定义、Picture 1/Video 1来源和 [Shot 1]。
原任务本来要求图像角色与图像场景，因此白背景、暗背景分别属于任务要求。新版补充了具体外观、动作阶段和来源归属；chest 还把原片已有拉索把手作为动作交互物明确保留。这是整段提示表达修复，不能把可能的改进单独归因于六段格式。当前没有新推理结果。

后续最小验证
先按现有20步Euler配置运行新的普通编辑，保留原源/目标图、时间映射和seed。完整审阅147有效帧及49个原动作时刻，先分别判断目标身份、环境和动作顺序，再检查时差。通过基本任务验收后再生成同设置固定引导版，实际条件、原始AV噪声和干预前预测必须匹配。若旧版本跨主机或运行环境改变，旧片仅作失败记录，新版与旧版差异不解释成单一prompt因果作用。
正式MF仍按49个原视频时刻0,3,…144报告，身份失败也保留分数并标记失败。原始8fps使事件时间精度约125ms，三次重复帧不提供更高的动作时间精度。
