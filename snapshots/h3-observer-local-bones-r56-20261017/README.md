# R56: arm-only 特征入口候选

当前 `timing_metrics.pose_features` 在计算任何特征前，要求存在可靠的双肩与双髋，以确定躯干尺度。手臂单位方向的计算仅依赖每根骨骼的两个端点，未使用该尺度。画面裁掉髋部时，这个统一入口会提前中止仍然可计算的手臂方向。

`arm_features.py` 独立返回原有六个手臂字段。骨骼索引、坐标差分、单位化、端点置信度和缺失值规则沿用原计算。时间坐标、有效帧前缀与扫描阈值也沿用现有配置。身体坐标、相对腕部位置等依赖躯干尺度的字段保留在原入口。

本目录是独立 CPU 候选，当前实验 producer、官方评测和已有结果均保持其冻结版本。这里验证的是特征入口的适用性；研究新颖性和生成效果需要后续独立验证。

检查：

- `test_arm_features.py`：原六字段精确相等、计算 AST 一致、平移、正缩放、缺失髋部、局部手臂遮挡、零长度骨骼、置信度边界、无人帧、已知正负时差、有效帧前缀。
- `check_five_sources.py`：固定五条源视频，完整扫描 16/32 帧窗口，stride 4；置信度 0.3/0.5、覆盖率至少 0.8、至少 8 个有效帧。统计源侧可用条件，不代表源与生成视频已成功匹配。
- `SOURCE_SNAPSHOT.json`：原函数、几何规则、原五条 source90 pose 的路径与 SHA；原字节保存在 `source_snapshot/`。
