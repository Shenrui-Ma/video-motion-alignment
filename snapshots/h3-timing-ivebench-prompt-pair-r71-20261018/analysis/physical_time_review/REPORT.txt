R71：提示词协议适配后的动作时序与可见性

结论
同一条 short_0210 参考视频、同种子和实际输入条件检查通过的 P0/P1 成片中，P1 保住了可测的手臂运动。固定观察器的 102 个重叠诊断行中，99 行判定 aligned，3 行 UNKNOWN；可靠时差为 0、提前 1 帧、提前 2 帧，均处于既定 ±2 帧容差。当前样本没有支持继续施加时序纠正的残余延后证据。

这是 1 条源视频的 2 种提示词输出。102 行来自 34 个重叠时间窗口 × 双臂/左臂/右臂三个特征，不能作为 102 个独立样本，也不能将 99/102 当作跨视频成功率。结论支持在继续研究时序干预前先适配 H3 输入任务协议；泛化判断等待其他参考视频。

实际数据与执行
三条原始媒体均为 1312×736、90 帧、24 fps；仅有效前缀 87 帧进入数值分析。CPU 姿态提取保持原 R55 全画幅协议。展示的 16,8,1280,720 裁剪只用于页面；数值输入保留原画幅，保证与源姿态缓存的模型、脚本、环境和输入哈希一致。
P0 与 P1 各新执行一次 CPU DWPose，耗时 71.27/71.14 秒。参考姿态使用 SHA 完全对应的既有 90 帧缓存。22 项实际 producer gate 检查通过。全过程 GPU 工作由 root 管理，本评估仅 CPU。

可见性
阈值 0.3 / 0.5 下，“双肩、双肘、双腕均可见”的有效帧数：
源视频：87/87、87/87。
P0：19/87、7/87。
P1：87/87、87/87。
P0 的两个髋点在两阈值下均不可见，原观察器因此直接返回 UNKNOWN。改用固定 R59 整臂特征后可以进入扫描，但 P0 的 102 行仍因检测覆盖不足全部 UNKNOWN。P1 的完整双臂可见率恢复，同时原 R55 与 R59 两种观察器产生完全相同的 102 行结果。

局部时间诊断
窗口长度 16/32 帧、步长 4 帧，覆盖有效前缀；特征是上臂和前臂的二维单位方向。沿用 confidence=0.3/0.5、覆盖率≥0.8、至少 8 帧、时差搜索 ±24 帧，以及原来对多解、残差和小收益的拒绝规则。
P1 在两个 confidence 下均为：48 行 0 帧，48 行 −1 帧，3 行 −2 帧，3 行 UNKNOWN。负号表示生成动作比参考稍早。3 行 UNKNOWN 分别为：帧 36–51 的右臂、帧 28–59 的双臂、帧 48–79 的右臂；它们的最佳偏移只有 −1 帧，且比同帧误差改善不足 5%，因此保留 UNKNOWN。
这些最终成片的离线诊断不等于去噪中间状态的可观测性，也没有实际触发在线干预。

旧配对汇总的耦合问题及补充
原 evaluate90 将 source、P0、P1 的特征提取放在同一个 try 中。P0 缺少躯干锚点时，原 physical_original.json.gz 会同时将 P1 标为 UNKNOWN。原输出和冻结代码已完整保留。
新增独立 adapter 对每个目标分别调用相同的冻结 evaluator；重复目标槽位只用于兼容函数签名，保留一份诊断，完全不增加样本。独立数值诊断不重命名为共同可见区域对比。5 个测试覆盖：A 不可见不影响 B、两条可测时原诊断完全等值、source 不可见时两条均 UNKNOWN、坏格式仍抛技术异常、输入不被修改。本机与 .41 均通过。
独立 P1 固定窗口结果：
全片 0–86：双臂 UNKNOWN，左臂 −1 帧，右臂 0 帧。
前段 0–31：双臂/左臂/右臂均 0 帧。
中段 32–63：三种特征均 −1 帧。
后段 64–86：三种特征均 −1 帧。
两个 confidence 的数值一致。1 帧=41.67 ms。全片双臂 UNKNOWN 仍遵守既有拒绝规则；局部诊断支持在该观测分辨率下动作时序接近参考。
