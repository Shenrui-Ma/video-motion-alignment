3. 采样位置与固定选择

既有 native_features 保存的是 SDPA 后、W_O 前的 contextual output，不是 Q/K；旧 temporal_readout 又先平均头和空间。两者都不能反推出这里的逐行 p 和完整 reference mass。原封存文件保持不变，未来实现须使用独立版本的只读适配器，并单独验证输出/RNG/条件/cache 不变。

4. 固定统计与数值门

令 z_qk=Q_q·K_k/sqrt(128)，l_qu=logsumexp_{k in R_u} z_qk，l_qR=logsumexp_u l_qu，l_qall 为原完整 Flash 的 LSE。计算 p_qu=exp(l_qu-l_qR)、m_q=exp(l_qR-l_qall)。只统计 target-query→reference-video-key；不混入反向 reference query 或 target audio。

建议未来复用相同 Flash backend，对固定 Q 和42个参考 bin 分别取得 LSE（42次小调用，V 只为接口所需，输出丢弃）；再用一次全部 reference keys 的小调用核对 logsumexp(bin LSE) 与 reference-group LSE。总额外43次 attention 调用/状态，不是43个 DiT NFE。保留 raw LSE 差、p 和质量检查；按 bin 分调用的浮点归约不等于原 full softmax 逐字节拆分，不能伪称旧模型真正显式存过全部概率。

在任何 GPU 采集之前需冻结小型数学/backend 门：同 QK 正确分组、分段和整组 LSE 一致到预声明工程误差、有限性、p 和为1、reference subset LSE 不超过 full LSE 的误差范围，以及 exact Native endpoint。本文不借两状态数据拟定数值容差或 motion 阈值。发生可能影响排名/偏移解释的数值差异时保留 UNKNOWN，不用悄悄裁剪掩盖；如展示 clamp(m,0,1)，raw excess 也必须保存。

每个 head/query 完整保留42项分布与各组 LSE、m；派生仅包括 same-bin mass、相邻bin mass、条件熵、最大bin与多峰、物理中心偏移和区间距离。以 head×time×space 保留结果，再另给不加权和按 m 加权的描述，不能先平均后声称每条 query 一致。低 m、峰相近、未覆盖身体的行明确保留；不从这些两状态生成自动 ON/OFF 阈值。

选定 BF16 Q 和参考 K 的小副本可落盘以便独立重算；无需保存全 QKV 或全 attention matrix。保存探针/code/model/condition/position/sigma/输入/输出 SHA、原始分布、全固定行清单、CPU/GPU RNG 前后与调用计数。capture不得写 QKV、重置模型缓存、替换 Native output 或追加 Full。检查前后输出等值及原始张量未改；不能以只看版本号替代 inference_mode 下的真实不变验证。

5. 最低观察目的及否证规则

先验已知比较区域只作二级定位：R27 bad index4 的旧策略曾因左臂44..59持续候选触发；两 confidence 的 lag 为15/13；normal同窗三part均约−1。这些是同一开发数据的既有 pose 读数，不是新的 attention 真值或独立标签。主描述仍是固定全42bin网格。不能把该二级窗扩大成“所有 sampled rows 应显示同一 bad lag”。

本次最低价值是同时报告：(a)正常状态是否也普遍远时刻/尖峰读取；(b)异常与正常差别能否在固定同一头/位置上看见，而非靠挑头、忽略低 m 或取平均符号；(c)方向解释是否与“读取过去姿态可能是负 offset”的反例相容；(d)分布是否主要是固定 RoPE/时间端点、背景/身份模式，而非随可见动作关系变化。两状态差别也可能来自 seed/形状/texture，不是 lag 的因果识别。

若正常也出现同样显著的远时刻读取、m接近0、主要只有平均量变化、结果全靠事后选头/网格、或当前位姿与采样对应无法判断，这个最小版本即 NO-GO/无信息。保留全部分布，不扩层扫头寻阳性。若数据无扰动可复现，且固定读数对上述正常反例显示有意义的区分，只能 conditional GO 到以后独立来源/已知时间扰动的预注册验证；尚不足以构建 pose-independent gate、替代现有观察器或证明自动方法有效。

当前同源两 seed 是两个相关开发轨迹，4200行、42bins不是独立样本；不估计置信区间、错误概率或 Conformal 覆盖。对 anime、source07、新素材的适用性全部 pending。本提案也没有把 attention readout 当成动作真值；后续即使不用 RGB pose 做在线观测，评价仍需独立的可见动作/时间依据。

6. 机会成本与停止边界

已有两个 Native4 forward 的记录耗时分别71.3382s、71.3687s，仅历史参考；2NFE合计约142.7s，不包含模型加载、conditioning恢复、采样统计、落盘和校验。新机器/并发下不能据此承诺时长。模型驻留本身约60GB级，当前本轮没有资源准入，也不会搭便车插入 live service。

每状态固定 Q 副本1,075,200 bytes；四头 reference K 副本40,556,544 bytes；p 的FP32阵列705,600 bytes，bin LSE同量级。磁盘约43MB级加少量元数据/标量，两个状态约86MB级；Flash V 工作选择另约40.6MB，不必落盘。完整三份 QKV 是3,767,156,736 bytes，禁止为此探针整体复制。

仅参考 logits 的 QK 乘加约42.58G浮点操作/状态；Flash还计算AV，整reference复核又重复一次，粗略约170G操作/状态，不能用这数字替代wall/peak实测。42个小kernel有调度开销，GPU峰值还取决于索引副本和backend工作区。将原Native forward、统计、transfer/hash、加载费用分列。完整 dense [allQ,allK] 不分配。

因此这不是无成本观察模块；它是一次明确的前置机会成本。任何新 gate 的每步成本、准确性与正常保护均未验证。若原 review 的反例已经足以使项目暂不投入这2NFE，停止此支路完全合理。
