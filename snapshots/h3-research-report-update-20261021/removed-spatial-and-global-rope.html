2.4　参考视频 Value 特征的空间对应

另一条尝试在参考视频的 latent patch 网格上建立相邻时间的空间对应：计算各 patch 的 Value 特征余弦相似度，保留互为最近邻且没有并列最优的匹配。然后保持原 QK Attention 权重，将参与加权的参考 Value 向输出 query 的时间推进一个 bin；接收位置由这个 patch 匹配确定。这里使用参考视频的 DiT Value 特征，匹配坐标为 latent patch 索引。

已实现的消融还包括：将 Value 拆成时间均值和残差后分别干预；或保持每个空间 patch 的总 Attention 权重，只替换其时间位置。这些方案用于判断动作、外观与空间对应对结果的影响。三条空间对应变体中，部分动作提前，同时出现路径或内容变化，后段延后仍存在；该轮配置已停止，继续使用 2.2 节的时间对齐引导。

2.5　参考与生成序列的 RoPE 时间坐标对齐

H3 的序列打包器先为参考视频安排时间坐标，再为输出音视频安排后续坐标。同一物理时刻的参考和生成 tokens 因此带有一个由序列打包产生的时间坐标差。新的对照在 Q/K 施加 RoPE 之前，将输出音视频的时间坐标整体平移，使其起点与参考视频相同。

Δ = toutput,0 − treference,0　，　t′output = toutput − ΔΔ 使用 PackedLayout 中的模型位置坐标，取值由输入序列决定。视频物理帧号与播放时间沿用原值。

这一变换会改变输出 tokens 与参考、文本 tokens 的相对旋转相位；输出音视频内部的相对时间间隔保持。它作用于全部采样步、全部 DiT Block 的 Q/K，改变 softmax 前的相似度计算。2.2 节的算子则在计算完 Attention 后重分配参考视频的时间权重。

该配置参考社区公开的 aligned video guides 实现，源／目标共享时间索引也见于 VideoCoF。该结构对照在书封改色样例中改善了动作时间，但保留了原书封颜色，编辑失败。
