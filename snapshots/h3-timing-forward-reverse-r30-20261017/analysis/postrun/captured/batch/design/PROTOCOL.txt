3. Exact operator and row direction

Let T denote target-video tokens and R reference-video tokens. A_QK means query rows reading key/value columns. The portrait, text, target audio and video reference are distinct segments even where both references are tagged ref_img. Identify R from actual reference kind=video and validate all ranges.
For unchanged same-call Q,K,V, define native O=softmax(QK^T/sqrt(d))V.
Forward component F, only T_event query rows:
  O_F = O + m_R [ Attn(Q_Tevent,K_R,same-bin,V_R,same-bin) - Attn(Q_Tevent,K_R,V_R) ].
m_R is the native full-softmax reference-video group mass from the original full and reference group LSE. Reuse original R3 rounding/work-dtype and LSE/clamp rules. Other reference content and other groups retain the same ideal mass at this call.
Reverse component B, only R_event query rows:
  O_B = Attn(Q_Revent,K_not-Tvideo,V_not-Tvideo).
This deletes ALL target-video keys for these reference rows and renormalizes the complement. It is not deletion of same-time target keys only. Use direct complement attention; do not implement a numerically ill-conditioned subtraction divided by1-m_T. Keep portrait, text, reference video and target AUDIO in the complement. This is not complete reference isolation.
Joint output:
  O_FB[T_event] = O_F[T_event]; O_FB[R_event] = O_B[R_event]; O_FB[all other rows] = original native O.
The two row sets are disjoint. Each component uses original unchanged QKV; no computation consumes already modified output as K/V.
