human2animal_1 原视频主要动作转折参考标注

用途
给后续生成视频的逐阶段人工审核提供一套固定的源动作描述和时间范围。标注依据全部49张原始帧，读取原片8fps时标，未使用生成结果决定本次转折范围。本标注者此前已看过该例Native；本轮只打开源视频帧，不声称独立盲标。forced未读取。

来源核验
源文件是官方数据集固定版本的 benchmark/reference_videos/human/human2animal_1.mp4；SHA256 bed32214852074b5b7cc030e9b731c0e2b01725b511bf4e7fbe9caff9847188d，与官方LFS和当前准备记录一致。49帧、720×480、8fps，原帧0..48对应0..6秒，容器持续6.125秒。已核验全部PTS=index/8；逐帧PNG保留完整原图，未补帧或改变时间。
后续prepared24fps中，对应原帧i的代表索引为3i；连续重复的三帧只提供一份原始动作观测。

可复用转折

1. 低位屈肘 → 抬胸撑起
定义：双手维持地面支撑，头胸从靠近地面转为持续上升，随后肘部逐渐打开。判断结合胸/肩高度与肘部，不单用头发摆动或单独抬头。
开始范围：原帧21–23，2.625–2.875秒。
进入高位伸臂范围：原帧32–34，4.000–4.250秒。
证据：18–20帧仍有明显屈肘、胸头较低；21–23开始连续上升；24–31持续撑起；32–34处于高位，手臂较接近伸直。这个动作本身持续约1.25–1.625秒，应记录起始和到达两个范围。

2. 高位抬头 → 低头
定义：在手掌与较直手臂继续支撑、胸部尚较高的情况下，头部从向前上方转向下方。
转折范围：原帧35–37，4.375–4.625秒。
证据：32–34仍抬头挺胸；35–37下巴/面部朝向连续下转；38–39低头更明显。此时的低头先于明显弓背，不能将两个转折强行共用一个时刻。

3. 背部由凹/平转为圆弓
定义：手臂保持伸展支撑，胸椎区域逐渐上提，背部上轮廓从高位伸展姿态转为圆弧；同时头部继续向下收。
开始清楚可辨范围：原帧40–42，5.000–5.250秒。
明显弓背形成范围：原帧44–46，5.500–5.750秒。
证据：39帧处于低头过渡，40–42背部轮廓开始呈圆，44–46已明显弓起，47–48继续保持/加深。头发遮挡使部分肩颈轮廓不可见，因此参考整体背部轮廓并结合胸肩变化。

上述范围的人工边界以±1个原始帧（±0.125秒）表达，已包含在每个三帧范围内。这是当前视觉定义下的判断余量，不是统计置信区间，也没有证明误差被严格限制在0.125秒。动作过渡渐变时，姿态定义不同可产生更宽范围。

保留UNKNOWN的项目
- 下降动作的真正起始时刻：片段开头已在四肢支撑，缺少更早静止姿态；可描述开头至约1.5秒的下降过程，精确起点UNKNOWN。
- 唯一的“最低点”时刻：低位中还存在头部转动/前移，不指定一个统一最低点来代表胸、头与肘。
- 头/胸是否真正接触地面及接触起点：发丝遮挡、二维投影和地面反光影响判断，UNKNOWN。
- 足部动作与完整承重方式：部分脚部位于画面外，UNKNOWN。

后续比较规则
先判断生成视频是否包含同一动作阶段以及顺序，再用同一定义独立给出生成结果的时间范围。源区间为[a,b]、生成区间为[c,d]时，可以报告局部区间差[c-b,d-a]作为该转折的人工匹配范围；若阶段类型/支撑方式已经改变，则保留不匹配或UNKNOWN。范围重叠表示当前采样与标注精度下难以区分，不能证明严格同步。
“低位→撑起”“高位→低头”“背部转圆”分别对照，不用两点去估计整段统一lag，也不将本标注当作已完成独立双人复核的benchmark GT。
