The design correctly separates physical video windows from denoising indices, observes current Native predictions on the actual current trajectory, allows zero/multiple automatically proposed windows, recomputes at most one Full prediction with their bin union, and makes one Euler update. No fixed observation-start step or manually supplied event window is present. All-state automatic operation remains to be demonstrated; offline final-pose scans do not prove this.

Implementation clarifications needed before sealing:
1. Spell out gain=(Cnull-Cproposal)/max(Cnull,1e-8), minimum across five null offsets and two confidence levels; retain original candidate agreement/reliability gates. The selector ranking uses the minimum absolute reduction, a distinct quantity. Per-comparison support differs, so neither ranking nor0.5 gain is a calibrated risk/utility/probability.0.5 is a data-informed development choice among the three already reported candidates, not independently validated.
2. Distinguish valid measurement UNKNOWN from execution error. Missing/low-confidence/ambiguous pose may use Native with an explicit abstention. Child process failure, bad hash, nonfinite model tensor, VAE fallback/shape mismatch or decode/pose implementation errors must fail closed as an operational error with evidence, not silently become a scientific UNKNOWN and complete.
3. Persistence bookkeeping must use only immediately previous Native observations on the real chosen trajectory. After an active Full update, next Native is recomputed at the actual new state, not the old archived Native future. Missing evidence resets state as written. No claim that two correlated endpoints diagnose self-healing, or that the first temporary reliable event needs intervention.
4. Connected components and tie-breaking must be deterministic over the current frozen proposal set, then transformed to deduplicated physical query bins. A component can join distinct nearby actions through a chain of overlapping windows; selecting one representative may leave other action intervals unsupported. This is a declared baseline limitation, not yet a blocker or evidence to tune posthoc.
5. Log observations, proposals including advanced/UNKNOWN, matched previous representative, reason for every ON/OFF and selected query bins; retain native/full branch input/sigma/condition/RNG identity and exactly-one-Euler evidence. NFE=20+active calls, not20. All-OFF should replay actual Native endpoints/final; before first ON prefix may bridge, later archivedNative comparisons become N/A.

Evaluation: old failure+normal1313 are development cases; final-normal does not make all its early deviations false alarms. FixedFull differs in both video support and schedule, already correctly acknowledged. Replay the actual selected mask sequence as an open-loop matched control only after feasibility to isolate feedback policy from action support; a mask learned on this same run is a descriptive matched replay, not a deployable held-out policy. Keep whole-video errors, edit quality, control cost, uncontrolled advances and large UNKNOWN fraction. Overlapping scans are not independent replicates. New-source Native screening must retain all outcomes and must not become cherry-picked generalization.

Precedent boundary: local automated repair and confidence-weighted control already exist broadly (VIDEOREPAIR/UAPG/MotionEcho etc.). Here the potentially useful technical question is whether physical-time errors observed on current Native predictions can cause beneficial sparse intervention without damaging naturally normal trajectories. That is a concrete causal question; successful wiring alone is not a new architecture. R25 reverse-edge experiments remain separate mechanism diagnostics.
