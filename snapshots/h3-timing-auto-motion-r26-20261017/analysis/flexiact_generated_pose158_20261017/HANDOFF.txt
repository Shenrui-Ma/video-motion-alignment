Fixed five pairs × two methods generated-pose sidecar, denominator ten.

This scope performs only existing DWPose CPU extraction and integrity checks.
Source full158 sidecar remains separate and unchanged. Each generated case uses
the same frozen probe/model/selection implementation, plus the frozen source
helper to verify158 full frame records at24fps and1152×768.

Preparation creates a MANIFEST.json with all ten records status=pending and null
actual paths/SHA. Actual use requires root authorization and completed postrun
METRIC_INPUTS.json, matching release49.mapping.json, and CASE_FILES.json covering
both metadata files. The metric and mapping must lie in their declared method
root and represent the fixed pair/run, original source/target bytes and49 samples
0,3,...144 at0,1/8,...6sec. All actual source/target/full158/release49 bytes are
hashed before and after pose extraction. Missing postrun parents return pending.
False/mismatched parents fail with retained audit. Partial outputs cannot overwrite.

Local command: existing Python run_one.py --source chest --method native
  --metric-inputs <actual remote absolute METRIC_INPUTS.json>
  --mapping <actual remote absolute edited49_8fps.mapping.json>
One invocation acquires Mac and server CPU locks nonblocking; online observers
have priority. The CPU4threads probe timeout is240sec, outer remote transaction
300sec. TMPDIR/TMP/TEMP point to this sidecar's own remote temp directory.

After each actual complete extraction, run manifest.py locally. It verifies every
completed output inventory and all pair/method/run/SHA metadata, preserving all
ten records including pending/technical_incomplete. Upload MANIFEST.json to the
same remote directory for root's scoring adapter. No timing score is computed here.

Manifest: schema, status, expected_count=10, completed_count, records (five pairs
in fixed order, each native then automatic), protocol_sha256,code_freeze_sha256.
Each completed record uses remote absolute pose_path,full158_path,
metric_inputs_path,release49_mapping_path,extraction_complete_path,provenance_path
and correspondingSHA. local_paths references the actual downloaded pose and
metadata copies. probe_and_models preserves the original raw provenance.
The full158 pose stays unchanged; valid_observation_frames=[0,146],
padding_frames=[147,157], original_sample_indices=[0,3,...144] remain explicit.
R50 original parent-generation closure is checked in its own production lane;
this component does not substitute for it or advance pending generation status.

Pure stdlib consumer entry: import this directory's manifest.py using importlib;
call verify_supplied_record(record). It verifies the local deployed protocol/code
freeze, all exact completed receipt identities and hashes, then compares every
record field with actual products except local_paths (host-specific copy locations).
It returns the verified record. Pending/partial items raise before numerical use.
The adjacent contract.py is imported by exact file path, independent of other
lanes' sys.modules['contract']. No model initialization occurs in this entry.

Preparation tests cover all ten metadata identities, physical sample mapping,
wrong pair/method/target, padding, nonfinite/shifted times, literal boolean gates,
full/release hash mismatch, cross-method paths, copied completion and missing
parents. They use synthetic metadata and no generated video or GPU.
