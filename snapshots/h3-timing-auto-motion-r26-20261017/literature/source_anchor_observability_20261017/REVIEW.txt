源动作时间可辨识锚点：有界先例核对与可否证候选
2026-10-17。只读文献/公式审查；没有运行模型、GPU、姿态评分或新实验。

判断
可以保留一个候选：用源视频的时间检索歧义筛选少量“相位观察锚点”，在当前 Native clean endpoint 上保留多个可能对应时刻，用它们是否一致支持同一控制动作决定开停。它首先是观察器/决策模块，不是已证明的新 DiT 架构。源锚点的时间可辨识性、实际端点中的可见性、以及该处干预的可控性是三个不同性质。

自动可靠关键帧、按特征独特性加权时间定位、时间对应分布与方差、误差触发/停止、稀疏早期帧影响全视频，都已有明确先例。当前检索没有确认下文完整候选的同构实现；这个检索结果不证明不存在。最值得检验的差别是：在人物替换及重复动作下，保留动作实例的对应歧义能否改善“该不该引导”的判断，而不是再给自动关键帧或两阶段阈值换名称。

一、当前证据限定设计目的
R27 用全时间16/32帧窗、stride4、双臂/左右臂三种描述，共186描述子；双置信阈值、共同支持 min_gain>.5、相邻两步兼容后触发。同一时间重叠组件仅选一个代表，且相容性没有数值 lag 接近门。R33 的位移5-bin干预同样改善主窗，故不能称 R27 找到的“高风险 query 时间位置”已经必要。
Frame Guidance 也说明早期少量帧约束可传播。候选必须把观察锚点集合 A 与实际执行器支持 S 分开：A 用于判断相位，S 是被路由的 query；A=S 只是一种需验证的设计，不能由“锚点容易识别”推出“在锚点干预最有效”。单个锚点对齐也不能证明全片对齐。

二、最接近原文/代码：已知机制和可比较差别

1. ORVE — Occlusion-Aware Physics-Semantic Keyframe Selection for Robust Video Editing
原文：https://arxiv.org/html/2605.23192v1 ，§3.1、Eq1–4、§3.2/4.1。
先以检测文本分数×边界完整性筛 top-M；再以双向循环跟踪 IoU、属性可见性和基础分数选最优锚帧。它明确自动选择可靠、可观察的编辑锚点。§3.2/4.1 的编辑结构有训练/LoRA，不能把整套方法称 training-free。读到了全文，检查的作者链接/论文中未定位可核运行代码，不作代码已复现声明。
这里的稳定性是物体完整和跟踪稳定；一个长期静止但清楚的姿态可以得高分，却不能辨别物理时刻。候选应与该类 visibility/trackability 排序比较，不能把“可靠锚点自动选择”当新贡献。

2. AdaFlow — Efficient Long Video Editing via Adaptive Attention Slimming And Keyframe Selection
原文：https://arxiv.org/html/2502.05433v1 ，§4.1、Algorithm1。
源码：https://github.com/jidantang55/AdaFlow/blob/d20a2c6a23d1dacce396c46bf6da456573fc1287/run.py#L269
源 DIFT token 最大相似性用于全局/局部相似度检查并分段。实际 check_similarity 检查均值与空间区域阈值；generate_pivotal（281–294）每个去噪步在各段随机选一帧，余帧特征对应传播。自动分配关键帧与覆盖分段已经存在。
候选所问的是“这段动作能否与远处重复实例区别”，不只是内容改变/相邻帧易传播。必须比较同分段随机和均匀选帧；不能只比较没有任何引导。

3. Temporal Cycle-Consistency Learning（TCC）
原文：https://arxiv.org/pdf/1904.07846 ，§3.3 Eq3–4。
源码：https://github.com/google-research/google-research/blob/5b09c22d73a9d35eb6c5d2a99b95677a45053466/tcc/tcc/losses.py#L100
代码从 softmax 对应分布 β 计算时间均值 μ 和方差 v，优化 (true_time−μ)^2/v + λ log(v)；deterministic_alignment.py 做跨序列 soft nearest-neighbor 循环。时间定位分布/不确定性早已进入对齐目标。它训练表征，不是冻结视频生成模型的在线启停。
README 还警告加入位置编码可能产生靠计数的平凡解。候选描述子不得把源绝对时刻作为检索特征来“制造唯一性”。低熵/低方差可错误自信；它们本身不是校准置信保证。

4. VADER — Video Alignment Differencing and Retrieval（不是同名扩散奖励优化论文）
原文：https://arxiv.org/html/2303.13193v2 ，§3.1 Eq2–4、§3.2。
查询 chunk 权重 w_i(s)=σ_i/rank_i(s)^λ，其中 σ_i 是检索相似度标准差；以更有区分力的 chunk 加权粗时间起点。随后学习连续时间对应及循环一致性。因此“独特性高的片段更适合时间定位”是直接先例。
任务是视频检索/编辑溯源，不是人物替换后的运动相位控制。检查到 https://github.com/AlexBlck/vader 当前仅有 .gitignore；未核到可运行作者实现。区分力加权本身不能作为候选的原创核心。

5. TempoControl — Temporal Attention Guidance for Text-to-Video Models
原文：https://arxiv.org/html/2510.02226v3 ，方法节。
源码：https://github.com/Shira-Schiber/TempoControl/blob/ac28c443ec112e0da6f9f5cbca26a2218d8d12dc/wan/text2video.py
词语的视频注意力时间曲线与用户期望曲线做相关性优化，另有幅度和空间熵项；达到相关阈值可停止内部优化，外层使用预设早期范围。时间匹配程度控制收手已有先例；其熵项是空间注意力，不等于动作实例的时间检索歧义。已核原文和固定代码，不声称执行。
候选输入是源动作/当前预测的物理对应集合，而非用户文本时间曲线；需证明重复动作下的决定更可靠，不能以输入类型不同就宣布阈值创新。

6. MotionEcho — When Distillation Breaks Motion Control
原文：https://arxiv.org/html/2506.19348v2 ，§3.4、§7.1、Algorithm1；项目：https://euminds.github.io/motionecho/ 。
过去 W 步运动损失均值大于 δ1 启动教师；教师当前运动损失低于 δ2 停止内部校正，实验 W=2。伪代码含未施本次引导的 clean prediction。当前观测/本次干预分离、两步稳定化和动态停止都有先例。项目 Code 尚标 Coming soon，作者仓库核到的是网页，不称运行代码已复现。
它没有在所读算法中用源短动作的全时域重复检索来选观察锚点。教师换同一骨干、标量换 pose、均值换集合，各自不是独立新原理；需要具体可靠性/质量收益。

7. FlowMotion — Training-Free Flow Guidance for Video Motion Transfer
原文：https://arxiv.org/html/2603.06289v2 。
源码：https://github.com/HKUST-LongGroup/FlowMotion/blob/f5b4dcfc2ac00d21c05e2290111dde468ddb1d9d/run.py
141–150 有 velocity projection，255–285 以 clean 预测 z−tv 的参考重构/时间差分损失优化 latent，并按 guidance_step 限定区间。无需生成教师的运动约束和 clean endpoint 引导已知；源码读到的是固定引导范围，未见本候选的源时间歧义选点与相位集合控制。
差别可能位于可拒判的动作实例对应决策，而不是再提“利用运动差异引导”。

8. Frame Guidance: Training-Free Guidance for Frame-Level Control in Video Diffusion Models
原文：https://arxiv.org/html/2506.07177v2 ，§4.2 Fig4(c)、§4.3、§4.4。
源码：https://github.com/agwmon/frame-guidance/blob/e9719c0bcec45800932099b25ac8d7e8ce5b9210/pipelines/pipeline_wan_i2v.py#L620
选定帧解码/损失，经去噪器反传更新视频 latent；早期单帧影响相邻帧，style 可用少量选定或随机帧。620–650、690–702、965–1004 对应选帧损失与更新。读到了全文及固定代码。
这直接限制“少量早期锚点锁定全局相位”的新颖性表述。H3 同帧 attention pulse 的算子不同，但若随机/均匀/其他低风险位置同样有效，自适应锚点选择没有证明独立控制贡献。

三、仅保留一个候选：可拒判的时间定位锚点观察器
以下是可实现的设计草案，不是已冻结运行协议；没有替换 R27 算法。需要先冻结具体描述子、扰动集、ε、预算与 tie-break，不能看生成结果后调。

A. 源端时间可辨识性
用既有相对单位骨方向构造短序列 f_W。候选长度/起点先沿16/32、stride4；附加运动方向若采用，必须单独验证它在跨身份下是否稳定，不能默认它解决同姿态反向运动。源时间只作标签，不进入特征。
在源视频所有合法同长度位置 u 上计算同一共同支持的距离 D_src(W,u)，不能只查 ±24 而遗漏更远重复。可见性不足的比较保留 unknown。
定义兼容位置集合：
  C_src(W;ε_W)={u: D_src(W,u)≤min_v D_src(W,v)+ε_W}。
将相距≤2帧的时间位置视为同一容差类。优先选择 C_src 仅有一个窄模态、扰动后仍窄、且可观测支持充足的 W；宽平台、重复动作的远模态、静态段均不强迫选中。源自匹配必然好，真正的筛选信息来自离开容差类后的可分辨性及扰动稳定性。
ε_W 可以研究由源姿态测量扰动得到的经验余量，但目前没有有效校准保证：源±2最大误差方案曾漏掉 source07；不能照搬并称已验证。检测置信不是概率，真实跨身份误差也未必被源增强覆盖。

B. 0..K 与预算
在通过上述条件的候选中，以时间定位集合宽度/远模态数量及可见支持排序，预算约束下覆盖分离的源时间段；所有候选和拒判保留，允许 K=0。排序和区间覆盖是已知优化原语。不能把“连通组件代表”当自动识别了真实动作；明确保留成员覆盖和代表覆盖。
预算需分开：观察窗口数、执行器 query-bin 并集、NFE、完整 VAE/pose 成本。若仍解码全视频并跑完整 pose，减少窗口数不会自动省掉主要观测成本。源无可辨识锚点只说明本观察器无证据，不说明生成正确。

C. 当前 Native 端点的相位集合
对固定源锚点 a，在本步实际 Native clean endpoint 计算 D_{n,a}(d)，d>0 表示目标动作晚。先保持 ±24 搜索以便与原基线比较，边界最优需删失/拒判。构造 H_{n,a}={d:D(d)≤D_min+ε_a}，再保留形状、支持和未匹配状态；必要时 H 含⊥。这里称“经验兼容集合”，在覆盖校准完成前不要叫具有概率保证的置信集合。
保留不连续模式，不用一个平均 lag 代替，例如{-12,+12}的均值0不是已对齐。
  ON：H 非空、无⊥，所有可接受假设都 d>2，且相邻观测支持同一个源→目标动作实例；
  OFF_ALIGNED：H 非空、无⊥，全部 |d|≤2；
  ADVANCED/UNKNOWN：含提前、混合方向、未匹配、支持不够等情况，当前 Full 正延后执行器不能推定有正确反向作用。
多个正 lag 若都支持相同控制动作，可以不要求唯一数值；“动作决定可辨识”比“lag唯一”更合适。目标形状若不匹配，不应强行解释为时间偏移。

D. 持续与全局传播
跨去噪步需要跟踪源与目标两端的对应支持和模态身份，而不只是 source 窗重叠。去噪状态正在改变，不可把两步集合简单求交后当独立重复测量提升置信；每次新观测都必须保留自己的未匹配/可见性门。
先保持执行器为已有 Full，以固定支持或同预算支持单独测试观察决策。即使一个锚点的 pulse 可全局传播，也要在未选位置独立评估 lag、幅度/形状、身份与重影。不能因主锚点对齐宣布所有事件完成，亦不能仅凭全片扰动非零宣布损害。

四、最小可反驳比较，先 CPU 再决定是否值得 GPU

第1门：仅现有源/归档轨迹的离线必要性，不新增生成。
先冻结全部源及窗口，报告 source-only 可辨识性、周期重复和静态段。用已知0、±4/8/12帧偏移、顺序反转/重复、幅度变化、缺测做合成校准；这些是变换控制，不计作新的独立生成视频。划分扰动留出，避免同一自匹配库既设置ε又验成功。再在既有跨身份真实 Native 端点检查；最终成片与中间端点不是同一个真值，独立姿态/肉眼标签缺失时保留 unknown。
必需同预算选择对照：均匀、预固定随机（记录seed）、仅可见性、最大运动变化，以及源可辨识性；加入一组可见而低时间辨识的窗口。各方案同 K、长度/相同并集bin数、相同测量器，不让候选靠更多可见槽获不公平优势。原R27全扫另作为高观测预算参照。
比较错误动作实例率、正常假ON、延后假OFF、unknown率、经验集合覆盖/宽度及可覆盖的物理时段。报告分母是视频/轨迹/窗口，不能把186行当独立样本。若只会增加 unknown、可靠收益可由可见性排序解释，或重复姿态只有检测噪声才显得独特，就否定该选择模块的必要性。

第2门：最小真实因果比较应先隔离一个因素。
若第1门通过，保持同一 Full、同一候选步数预算、同一组观察/停止规则，只比较“可辨识锚点选择”与同预算 random/even/其他低风险选择。不能只比较无引导或原9次Full。S与A的耦合另外做消融，避免观察更可靠和干预位置更有效混为一谈。实际 m_ref 和校正范数另记录；同query数不是同实际扰动剂量。
另一个独立因素是集合决策相对单峰决策，宜在选择器冻结后比较，不能两者一起改变再把收益都归因于可辨识性。离线回放只能证明决策不同，真实轨迹才能证明因果效用。

足以推翻候选主张的结果
• 同预算随机/均匀/低风险锚点具有相同相位和质量收益：不能声称 observability 排序带来控制收益。
• 源可辨识但当前编辑预测仍常匹配到错误重复实例：源自检不具有所需跨身份泛化。
• 只能晚期可辨识，已错过有效干预窗口：不能以终局定位准确支持在线用途。
• 所有有用收益只来自已有 Full 的单次全局传播，决策选择无增益：贡献应回到已有执行器效果诊断。
• 错时参考控制同样修复：不能把成功解释成读取了该锚点正确动作时刻。已有 +10-bin 错时设计可独立提供此反证，尚未执行。
• 集合忽略未匹配/支持丢失才减少unknown：不接受这种伪改善。

可能保留的贡献表述
“针对视频编辑中重复动作和部分可见造成的相位观测歧义，研究源时间可辨识锚点与可拒判对应集合能否提高自动引导决策的可靠性；执行器沿用已有同帧参考读取，实际影响允许跨时间传播，并用匹配预算与正常样例验证价值。”
现在不写：首次自动关键帧、首次不确定性时间对齐、首次动态运动引导、已证明局部高风险窗口必要、已找到新架构、保证全片同步、无额外预训练模型。
