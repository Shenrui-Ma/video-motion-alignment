HALO / QWERTY 精确机制与可运行性审查
核查日期：2026-10-17；范围：原文、作者仓库、公开模型元数据。未安装依赖、下载权重或启动推理。R27 policy_replay 保持冻结，未运行实际轨迹。

结论
HALO 直接覆盖“识别运动/结构 attention heads，再有选择地注入参考特征”；QWERTY 直接覆盖“分离语义/时间查询分量、空间 warp queries、同状态原生/修改预测构成自引导”。以后只提出这些一般操作，不能据 H3 平台不同就宣称新机制。两篇已核内容均不等于当前 H3 的 reference-group 总质量固定、组内同时间读取，也未给出 R27 的局部有符号 lag、跨步窗口匹配、自动 0..K 物理窗口控制。但这种区别只构成可测实现边界，不能证明新颖性或价值。

二、HALO 的实际计算位置
作者代码：https://github.com/SunYJ-hxppy/HALO-Official-code/blob/a4933506563a32ac38a17ba071d34ea6c428788e/guidance_utils/utils.py#L55
1. head_classification 用空间/时间两种 pattern masks。对固定 CPU seed=42 抽出的32行，比较 masked attention 输出与完整 attention 输出的 MSE，取较小者。顺序 [spatial, temporal]，返回类别1实际是 temporal；motion_flow 文件变量名 spatial_indices 具有误导性，但不能按变量名反向解释方法。
2. 运动分支：对类别1 heads 的跨帧 QK logits 求平均，按每个目标帧的空间 token 归一化。参考对应在 attention top-k 候选中取接近 DIFT 对应的坐标；目标读出在 DIFT 指向位置增加 beta=.1 的 bias 后计算期望位移。以参考/目标位移 MSE 优化当前 latent；这是在线 latent optimization，网络权重保持冻结。
代码：https://github.com/SunYJ-hxppy/HALO-Official-code/blob/a4933506563a32ac38a17ba071d34ea6c428788e/guidance_utils/motion_flow_utils_final.py#L8 和 #L123；https://github.com/SunYJ-hxppy/HALO-Official-code/blob/a4933506563a32ac38a17ba071d34ea6c428788e/inference_ourmethod_final.py#L513、#L645。
3. 结构分支：noised reference 单独 forward 得到 Q/K/V；对128条抽样视觉 query 的注意力熵按行平均，H<7选择head。在目标 forward 的 SDPA 前替换这些head的视觉 V，不替换 Q/K。命名 inject_kv 不意味着真的替换 K。公式可写成固定当前 Q/K 下 O_h'=A_h V_h'，V_h,video'=V_h,reference（仅选中heads）。它会影响所有读取这些 V 的 query，并非只作用于一个参考视频 key group。
代码：https://github.com/SunYJ-hxppy/HALO-Official-code/blob/a4933506563a32ac38a17ba071d34ea6c428788e/guidance_utils/custom_modules_inject_final.py#L95；https://github.com/SunYJ-hxppy/HALO-Official-code/blob/a4933506563a32ac38a17ba071d34ea6c428788e/guidance_utils/utils.py#L107。
4. guidance_blocks_5b=[20]、structure blocks15..26，50步；get_timesteps([50,38])实际 Python slice为前12步，优化每步5次。guidance_step 会关闭 motion block20 的注入并打开 copy；不能笼统说12层始终同一种状态。停止按固定区间，未见基于局部物理时间 lag 的启停。
代码：https://github.com/SunYJ-hxppy/HALO-Official-code/blob/a4933506563a32ac38a17ba071d34ea6c428788e/configs/guidance_config_inject12.yaml；https://github.com/SunYJ-hxppy/HALO-Official-code/blob/a4933506563a32ac38a17ba071d34ea6c428788e/inference_ourmethod_final.py#L167、#L566、#L727。
HALO paper也报告Wan扩展，不能说其原理只支持CogVideoX；公开仓库当前实现是CogVideoX。

四、QWERTY 的已核论文机制
原文§4.1：对第一帧空间tokens及逐帧空间均值分别PCA。通道显著性 s_d=max_i sigma_i*abs(V_di)，语义分数不低于时间分数的通道形成 STCD mask。
§4.2：pre-RoPE查询定mask→施加空间RoPE→把第一帧语义查询按用户mask/flow空间warp到后帧→施加该目标帧的时间RoPE。对象移走位置用背景邻近查询填洞；flow不可见洞保留目标查询。
§4.3/算法1：同一x_t计算 native u 与 warped u；停止 warped 分支梯度，对latent优化 ||u-u_w||² 加 Fourier-phase cos/sin约束，再以 warped 预测推进solver。固定前5/50步，每步5次Adam。主Wan2.2 TI2V5B，补CogVideoX I2V5B；所有attention层应用querywarp。
§C.4作者测49帧：Wan query-only17.61GB/132.62s，含优化40.17GB/314.34s；Cog含优化47.59GB/1092.66s，单48GB A6000。均是作者特定配置测量，代码尚未公开到可复核程度。
论文来源：https://arxiv.org/html/2607.01869v1#S4 ，https://arxiv.org/html/2607.01869v1 。此处无作者实现可验证的接口、依赖/权重清单或端到端运行证据。

五、与当前 H3 算子的数学边界（本段为独立对照推导）
令 A 是当前target query对全keys的原生softmax；m=sum_(j in ref)A_j，P_ref=A_ref/m；P_same只在物理相同时间bin的参考keys中归一化。当前Full对指定query使用
O_new=O+alpha*m*(P_same V_ref-P_ref V_ref)，alpha=1。
Q/K/V、其他key组贡献均保持；参考组总mass固定；只重排该组内部时间读取。这是已存在算子控制，不以分解恒等式为新数学。
HALO原语保持target Q/K但用独立ref forward的V替代target视觉V，其差分为 A_video(V_ref-V_target)。一般不等于 m*(P_same-P_ref)V_ref：它更换值来源；我们更换已有ref组的条件权重。退化情况下可数值等价，但不存在一般等式。两者都涉及参考特征读出，是应比较的邻近基线，不因不同写法就推断贡献。
QWERTY更换target Q的语义/空间内容，然后用全部K/V重算attention；通常会改变所有key组mass。当前Full没有query语义warp、PCA子空间或latent梯度优化。把Querywarp限制到reference branch并补mass守恒属于一种适配；不能仅凭这个约束声称超越QWERTY，需要保留相应消融证明可测价值。

六、未来 head/layer / 在线局部反馈的交叉边界
已经直接覆盖：按head功能分工挑选注入；以低熵减少结构破坏；head/layer范围选择；语义/时间特征分解；querywarp诱导期望空间对应；原生/修改同状态预测形成self-guidance；填补旧对象位置以避免复制；固定早期引导后放手。
已读内容没有实现的具体组合：独立可见姿态的有符号物理lag与质量拒判、扫描0..K自动物理动作窗、跨连续native端点的局部对应持续性决定reference-group时间路由。注意HALO在每次迭代重算head类别/熵也有输入依赖，不能把它说成所有head固定不变；QWERTY也已经有同状态两预测，不能把native-first本身当区别。没有在这两篇里找到该控制策略，不代表全领域不存在，MotionEcho等相关工作仍必须保留。
如探索head选择，最低必要性对照：Full全heads；HALO式低熵；temporal-patternheads；等head数的预先固定/随机选择；拟议局部反馈选择。同一stem/时窗/schedule和计算预算记录，支持不足/非动作区/正常片段须保留；选头只用源或事先固定校准集，不能靠测试输出挑。只有显著减少ghost/身份损伤而保持时间误差及正常case，才支持其独立价值。若低熵或固定子集已达到同样结果，则新增复杂选择器无必要证据。
当前最稳妥claim仍是：H3局部时序错误诊断与参考时间读取的因果效果；R27待完成的反馈算法与泛化/质量门另算。HALO/QWERTY不是否定探索的理由，却明确阻止“首次选头/查询语义warp/同模型自引导”的表述。
