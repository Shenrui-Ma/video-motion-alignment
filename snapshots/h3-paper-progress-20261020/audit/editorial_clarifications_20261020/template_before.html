视频编辑中的动作时序保持

MiniMax H3 参考视频 Attention 的时间重分配与自动干预
研究进展 · 方法、实验与后续工作

摘要

视频编辑可能完成角色或外观修改，却使原有动作延后。我们在 MiniMax H3 上研究 training-free 的时序干预：对 DiT Block 的多模态 self-attention，在 softmax 后保持输出视频 query 对参考视频 tokens 的权重总和，将这些权重重新分配到对应时间的参考 tokens，再计算加权 Value 特征。我们进一步以每步去噪预测视频中的手臂姿态时差，自动决定引导的开启、作用时间段与停止，并尝试在参考视频的 latent patch 网格上按特征匹配调整 Value 对应位置。使用动作迁移 benchmark FlexiAct 和指令式视频编辑 benchmark IVEBench 的公开数据，预设去噪区间执行本方法后，部分样本的局部动作时差缩小。目前清楚改善集中在少量来源；已有普通编辑同步、基础编辑失败和引导收益有限三类情况，后续重点扩大有效配对并完善物理时间评测。

1　相关工作

动作迁移。FlexiAct 在 CogVideoX 上训练 RefAdapter，并为参考动作学习 embedding；推理时按去噪阶段调节相应 Attention。其 benchmark 提供动作视频、目标角色图及 caption。我们使用这些公开输入测试 H3 的动作保持能力。

Attention 与特征控制。DIAL 的推理方法依据主体空间注意力图，在视频 query 到参考图 key 的 logits 上加偏置，控制主体参考强度。我们的早期参考加权与其形式接近；当前方案将改动放到 softmax 后，保持参考视频的总 attention probability，并调整其中的时间分布。EditVid 用扩散特征对应、token 替换和 latent 混合传递编辑，是参考特征匹配方案需要直接比较的工作。

动态引导。MotionEcho 根据运动损失选择性调用教师模型，修正蒸馏模型的预测，并控制教师迭代的提前停止。Information Bottleneck CFG 根据条件与无条件 score 之差的平方范数确定 CFG 开启时刻。AV-FlowEdit 用源／目标 flow 差异和音频活动调节局部编辑强度。我们检验的机制是：测量参考视频与当前预测视频的动作时间偏差，用它控制参考视频 Attention 的时间分配。

位置编码。VideoCoF 在训练的 WAN 编辑模型中，将源视频与目标视频的 RoPE 时间索引都设为 1…F，并为预测编辑区域的 reasoning frame 单独保留索引 0。我们将参考与输出的时间原点对齐作为已有机制的结构对照，检验它在冻结 H3 中对动作时差和阶段时长的影响。

2　方法

2.1　输入表征与干预接口

参考视频与可选的角色参考图经 VAE 编码，得到 T′×H′×W′ 的 latent 网格，patchify 后展开为视觉 tokens。文本条件经过投影和 Token Refiner。参考 tokens、文本 tokens、带噪音频与带噪视频 tokens 进入同一序列，在 50 个 DiT Block 中计算多模态 self-attention。

每个 Block 中，Q/K 经过归一化和 RoPE，再计算 softmax Attention 与加权 Value 和。我们的补丁位于这个加权和 O 之后、Attention 输出投影 WO 之前。补丁只修改输出视频 query 对参考视频 tokens 的加权特征。更新后的 O 继续进入残差、FFN 和后续 Block，最终改变本步预测的 flow velocity。

Temporal bin 表示 latent 的时间索引。它决定输出 query 应与参考视频的哪个时间位置对应。物理帧映射为 bin 后，当前执行器处理该 bin 中的全部空间 patch tokens。采样步则决定在哪次去噪前向启用补丁；两种时间坐标分别记录。

2.2　参考视频 Attention 的时间重分配

对某个输出视频 query，普通 self-attention 会给参考视频中不同时间、不同空间位置的 key 分配权重。记 softmax 后的权重为 A，参考视频 tokens 为 R，与该 query 具有相同相对 temporal bin 的参考 tokens 为 Rτ。

mq 是该 query 在一个 Attention head 中分配给全部参考视频 tokens 的概率总和；zq 是参考视频内部归一化权重对 Value 的加权和。重新对 Rτ 内的 QK logits 做 softmax，得到同一时间位置的加权特征 zq,τ。

A = softmax(QKᵀ / √d)　，　O = AVmq = ∑j∈R Aqj　，　zq = ∑j∈R (Aqj / mq) Vjzq,τ = softmax(qKRτᵀ / √d) VRτO′q = Oq + αmq(zq,τ − zq)α 为替换比例。当前成片对照取 α = 1；实现中由参考子集与完整序列的 log-sum-exp 差得到 m。

这相当于把参考视频内部的概率分布改为 (1−α)pR+αpRτ。当 α=1 时，该 query 的参考视频权重全部分配到对应 temporal bin；同一 bin 内的空间匹配仍由 QK 相似度决定。代码通过加权 Value 和的差值实现这个变换。

预设采样区间的实验：在 20 步去噪中的第 7–15 步启用本算子，覆盖全部 50 个 Block 和有效视频时间。普通编辑与干预编辑使用相同输入、提示词、初始噪声及采样器。每个步骤都执行一次完整模型前向，启用时增加内部参考 Attention 子计算。

2.3　基于预测视频动作时差的自动干预

当前可见手臂测量原型（R86）在每个采样步先由当前 noisy latent 预测 clean latent，解码出该步估计的最终视频，再用 DWPose 提取手臂姿态。观察器比较它与参考视频中肩—肘、肘—腕的单位方向序列，搜索动作发生的时差；通过条件的时间窗口才启用 2.2 节算子。开启时从该步相同 noisy latent 再做一次带引导的预测，sampler 使用选定预测更新一次。

窗口长度为 16、32 帧，stride 为 4 帧。每窗分别测量左臂、右臂及双臂，在 ±24 帧内搜索使方向差最小的时差 ℓ。正值表示生成动作晚于参考。

C(W,ℓ) = ∑f∈W,jw(f,j)‖dref,j(f)−dpred,j(f+ℓ)‖ / ∑f∈W,jw(f,j)j 为肩—肘或肘—腕方向，d 为二维单位向量；w 取源／预测中对应端点的最小置信度。分别在截断 0.3 和 0.5 下测量。

将最佳偏移与“接近同步”的 ±2 帧假设比较，在共同可见帧上计算方向误差的相对下降 g。取两种置信度及全部近同步偏移的最小值，使候选同时通过这些检查：

g(W) = minc,e [Cc,e(W,e)−Cc,e(W,ℓc)] / max(Cc,e(W,e), ε)c∈{0.3,0.5}，e∈{−2,…,2}；每对比较使用相同的共同可见帧与权重。
控制项R55／R86 的控制规则
可靠测量肩—肘、肘—腕方向的有效观测覆盖 ≥80%，且至少 8 个有效帧；最佳偏移离开搜索边界；独立匹配谷相对差距 ≥0.05，移位比同帧误差改善 ≥0.05；移位后方向残差 ≤0.5。
触发条件两种置信度下偏移同向、相差 ≤2 帧，偏移绝对值 >2 帧，且 g>0.5。连续两步出现偏移同向、共享手臂的候选，且交集长度／较短窗口长度 ≥50% 时启用。
窗口数量每步扫描全片，合并重叠候选；每组选择 minc,e[C(W,e)−C(W,ℓc)] 最大的窗口。窗口数随合格组数变化。
停止条件下一步重新测量，候选不再合格就停用该窗引导；UNKNOWN 跳过反馈。重新开启需要连续两步证据。

扫描从第 1 个采样步开始。上述阈值目前是固定工程参数，后续用开发集标定。停止沿用候选资格判断，因此可能由测量不清楚或时差估计冲突触发。

实现演进：早期版本仅对延后候选触发，已在两段开发视频中自动选择窗口并完成启停。后来将提前候选也纳入触发；五条 IVEBench 测试均未触发。最新实现改用可见肩、肘、腕，降低对髋部可见性的依赖，GPU 成片验证待完成。目标人物选择目前仍含指定画面范围。

2.4　参考视频 Value 特征的空间对应

另一条尝试在参考视频的 latent patch 网格上建立相邻时间的空间对应：计算各 patch 的 Value 特征余弦相似度，保留互为最近邻且没有并列最优的匹配。然后保持原 QK Attention 权重，将参与加权的参考 Value 向输出 query 的时间推进一个 bin；接收位置由这个 patch 匹配确定。这里使用参考视频的 DiT Value 特征，匹配坐标为 latent patch 索引。

已实现的消融还包括：将 Value 拆成时间均值和残差后分别干预；或保持每个空间 patch 的总 Attention 权重，只替换其时间位置。这些方案用于判断动作、外观与空间对应对结果的影响。当前额外收益尚未稳定，主要成片证据仍来自 2.2 节算子。

2.5　参考与生成序列的 RoPE 时间坐标对齐

H3 的序列打包器先为参考视频安排时间坐标，再为输出音视频安排后续坐标。同一物理时刻的参考和生成 tokens 因此带有一个由序列打包产生的时间坐标差。新的对照在 Q/K 施加 RoPE 之前，将输出音视频的时间坐标整体平移，使其起点与参考视频相同。

Δ = toutput,0 − treference,0　，　t′output = toutput − ΔΔ 使用 PackedLayout 中的模型位置坐标，取值由输入序列决定。视频物理帧号与播放时间沿用原值。

这一变换会改变输出 tokens 与参考、文本 tokens 的相对旋转相位；输出音视频内部的相对时间间隔保持。它作用于全部采样步、全部 DiT Block 的 Q/K，改变 softmax 前的相似度计算。2.2 节的算子则在计算完 Attention 后重分配参考视频的时间权重。

该配置参考社区公开的 aligned video guides 实现，源／目标共享时间索引也见于 VideoCoF。在书封改色样例中，复用普通编辑的输入、提示词与实际初始噪声后，五个动作的发生区间均回到参考范围，但书封保持原色，编辑失败。对应成片见 3.5 节。

2.6　参考分支的时间相位对齐

接着测试一个作用范围更小的配置：保留原始多模态 Attention 的 Q、K 和输出 O，只在额外计算“输出视频 query → 参考视频 keys”时，将 query 的 RoPE 时间相位减去 Δ。该分支仍可读取参考视频的所有时间位置。随后沿用 2.2 节的替换公式，并保持原参考视频概率总和 m。

q′ = Rtime(−Δ)q　，　zq,Δ = softmax(q′KRᵀ / √d)VRO′q = Oq + αmq(zq,Δ − zq)q 已施加原始 RoPE；Rtime 只旋转时间维度，空间维度沿用原值。Δ 来自实际序列的时间原点差。

3　实验

3.1　数据与任务

FlexiAct 是动作迁移方法及其 benchmark。公开评测集包含 25 类动作、250 个参考视频—目标图像对，图像涵盖真人、动物、动画和游戏角色；每个任务还提供目标 caption，部分 caption 包含动作顺序。任务要求目标图中的角色执行参考视频的动作。[论文]

IVEBench 是指令式视频编辑 benchmark，包含 400 条短视频和 200 条长视频、8 个编辑类别。主要输入是原视频与 edit_prompt，数据另提供源／目标描述和编辑短语。我们优先选择主体替换、外观或交互物体编辑，并检查原有场景和动作是否保留。[论文]

3.5　自动决策与结构消融

自动启停。两段早期开发视频分别只在 1 个、3 个采样步开启引导，预先约定评价窗中的姿态时差从 +13 帧变为 +2 帧、从 +15 帧变为 −1 帧。第二段后续仍有提前。窗口均由在线扫描产生；停止分别由姿态覆盖不足和两种置信度的时差估计冲突触发。后续五条 IVEBench 测试均未开启，当前改进重点为可见部位测量与触发覆盖。

特征匹配。此前白色服饰改黑色的样例来自 IVEBench 长视频片段，采用预设第 7–15 步的相邻 Value 特征匹配干预。关键动作与普通编辑接近，当前未见清楚时序收益。该样本保留为结构消融。

编辑完成度。部分普通编辑会改变人物、背景或动作内容，属于基础任务失败；这类结果先进入失败记录。部分结构变体也会额外改变外观或运动路径，配对审阅单独记录这些副作用。

4　结论与后续工作

H3 中对参考视频 Attention 的时间重分配，已经在 IVEBench 的三个独立源视频上减小部分动作的延后。新增物体改色样例中，抬书与翻书提前，伸手过程却变长；后续同时检查动作发生时间与动作持续时间。早期自动原型另有两段开发视频的姿态时差改善。当前继续扩展主体替换、外观和交互物体编辑。

样本与提示词。先按任务类型和动作可见性选素材，保留 benchmark 的编辑指令并完成 H3 输入格式适配；优先对编辑成功且时序偏移明显的结果运行本方法。保存全部已选样本的验收记录，并用少量原本同步样本检查引导是否引入偏差。提示格式对照与同提示词的方法对照分别归档。

方法迭代。每次修改 Attention 算子或自动决策，先在已确认改善的样本上复测相同提示词与种子，确认收益和副作用，再扩展新样本。自动版本以达到人工／预设方案的成片效果、减少无关干预为目标。

评测。继续采用两套公开 benchmark，补充可复核的动作时间标注与编辑完成度。若物理时间标注能稳定解释 MF 与视觉判断的分歧，再扩展为跨模型的时序评测子集。
