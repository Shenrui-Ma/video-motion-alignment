RESEARCH PROGRESS · 2026.10.21

视频编辑中动作时间对齐-研究进展v1

摘要

角色替换与外观编辑可能改变源视频中局部动作的发生时间，导致编辑结果与源动作在时间上错位。针对这一问题，我们在 MiniMax H3 上研究一种 training-free 的路由方法。在 DiT 的 MM Self-Attention 中限制目标视频 query 只能关注对应 VAE 时间 bin 内的参考视频token，从而直接加强源视频特定时间的特征。最新十组对照实验中，引导幅度为α = 0.25 的全程弱引导优于 α = 1 在固定去噪区间的强引导；同时进一步测试双向时间 Attention。实验基于 FlexiAct 和 IVEBench 公开数据进行视频编辑任务，可以减小部分样例的局部动作时间误差，但改善主要提现在常规编辑后出现动作错误的任务结果。

1　相关工作

动作迁移。FlexiAct 在 CogVideoX 上训练 RefAdapter，并为参考动作学习 embedding；推理时按去噪阶段调节相应 Attention。其 benchmark 提供动作视频、目标角色图及 caption。我们使用这些公开输入测试 H3 的动作保持能力。

源与目标的时间同步。Vidu S2-Editing 的 frame-aligned attention 让目标帧读取同一时刻的源帧；Wan-Animate-2 将 Sparse-Ref Attention 与时间对齐的 RoPE 用于角色动画。两者都在训练中加入对应结构。我们在冻结的 H3 上测试这一时间约束，同时保留每个 query 原有的参考视频概率总和。

Attention 与特征控制。DIAL 依据主体空间注意力图，在视频 query 到参考图 key 的 logits 上加偏置，控制主体参考强度。RefGAP 根据编辑区域和保留区域的参考 Attention 概率总和，动态计算正、负 logit 偏置。RefDrop 将参考与自身 Attention 输出线性组合，控制外观一致性。我们的方案沿用分组 Attention 运算，保留参考视频的概率总和，按物理时间重分配其内部权重。

2　方法

2.1　输入表征与干预接口

参考视频与可选的角色参考图经 VAE 编码，得到 T′×H′×W′ 的 latent 网格，patchify 后展开为视觉 tokens。文本条件经过投影和 Token Refiner。参考 tokens、文本 tokens、带噪音频与带噪视频 tokens 进入同一序列，在 50 个 DiT Block 中计算多模态 self-attention。

每个 Block 中，Q/K 经过归一化和 RoPE，再计算 softmax Attention 与加权 Value 和。我们的补丁位于这个加权和 O 之后、Attention 输出投影 WO 之前。正向引导修改输出视频 query 对参考视频 tokens 的加权特征；双向变体还修改参考视频 query 对输出视频 tokens 的加权特征。更新后的 O 继续进入残差、FFN 和后续 Block，最终改变本步预测的 flow velocity。

Temporal bin 表示 latent 的时间索引。它决定输出 query 应与参考视频的哪个时间位置对应。物理帧映射为 bin 后，当前执行器处理该 bin 中的全部空间 patch tokens。采样步则决定在哪次去噪前向启用补丁；两种时间坐标分别记录。

2.2　参考视频时间对齐引导

对某个输出视频 query，普通 self-attention 会给参考视频中不同时间、不同空间位置的 key 分配权重。记 softmax 后的权重为 A，参考视频 tokens 为 R，与该 query 具有相同相对 temporal bin 的参考 tokens 为 Rτ。

mq 是该 query 在一个 Attention head 中分配给全部参考视频 tokens 的概率总和；zq 是参考视频内部归一化权重对 Value 的加权和。重新对 Rτ 内的 QK logits 做 softmax，得到同一时间位置的加权特征 zq,τ。

A = softmax(QKᵀ / √d)　，　O = AVmq = ∑j∈R Aqj　，　zq = ∑j∈R (Aqj / mq) Vjzq,τ = softmax(qKRτᵀ / √d) VRτO′q = Oq + αmq(zq,τ − zq)α 为替换比例。区间强引导取 α = 1，全程弱引导取 α = 0.25；实现计算 m = exp(LSER − LSEall)，其中 LSE 是对应 QK logits 的 log-sum-exp。

这相当于把参考视频内部的概率分布改为 (1−α)pR+αpRτ。当 α=1 时，该 query 的参考视频权重全部分配到对应 temporal bin；同一 bin 内的空间匹配仍由 QK 相似度决定。代码通过加权 Value 和的差值实现这个变换。

参考视频的 Value 同时包含外观与动作信息，并在后续 Block 中持续参与多模态交互。保持 m 约束当前 Attention head 的参考概率总和；时间权重的重分配仍会改变加权后的 Value 特征，并经残差与后续层影响最终编辑。因此，实验同时检查编辑完成度与动作时间。

与 logit 操作的数学关系

令参考 logits 的指数和为 ZR，目标组内分布为 p′。将参考 logits 设为 log ZR+log p′，即可保持参考概率总和，并得到与上述输出公式相同的结果。两种写法属于同一概率变换。当前实验比较同时间参考约束的引导区间、强度，以及正向与双向结构。

本方法在采样过程中直接应用。区间实验比较第 1–9、7–15、12–20、1–4＋16–20 步的 α=1 引导，以及第 1–20 步的 α=0.25 弱引导，均作用于全部 50 个 Block。强引导沿用各样例原定的视频时间窗口，全程弱引导覆盖全部有效视频时间。每组普通编辑与引导编辑使用相同输入、提示词、初始噪声及采样器。

2.3　双向时间 Attention

正向引导约束生成 query → 参考视频 K/V。双向变体进一步约束参考 query → 生成视频 K/V：两组 query 分别从对方视频的同时间 bin 提取特征，并在 Attention 输出投影前更新各自的 head 输出。

在同一个 DiT Block 中，两向计算共用原始 Q、K、V 和 Joint Attention 输出。参考 tokens 的 hidden states 经输出投影、残差与 FFN 更新后，进入后续 Block；后续层的生成 query 再读取这些参考特征。每个采样步仍从固定的参考 latent 构建条件序列。

记生成视频 token 集合为 T、参考视频集合为 R。沿用 2.2 节的组内归一化 Value 加权和，正向与反向修正分别为：

O′T = OT + α mR(μR,same − μR,all)O′R = OR + β mT(μT,same − μT,all)mR、mT 为当前 query 在原 Joint Attention 中分给对方视频组的概率总和；same 表示同时间 bin，all 表示对方视频全部 tokens。

α 控制正向引导，β 控制反向引导。β=0 对应已有正向方法；α=0、β=1 用于单独检查反向作用。已完成的三组结构实验在第 1–9 步取 α=β=1，结果见 3.4 节。

2.4　参考分支的时间相位对齐（已暂停）

这项尝试在辅助参考 Attention 分支调整 query 的 RoPE 时间相位：保留原始多模态 Attention 的 Q、K 和输出 O，只在额外计算“输出视频 query → 参考视频 keys”时，将 query 的 RoPE 时间相位减去 Δ。该分支仍可读取参考视频的所有时间位置。随后沿用 2.2 节的替换公式，并保持原参考视频概率总和 m。

q′ = Rtime(−Δ)q　，　zq,Δ = softmax(q′KRᵀ / √d)VRO′q = Oq + αmq(zq,Δ − zq)q 已施加原始 RoPE；Rtime 只旋转时间维度，空间维度沿用原值。Δ = t生成,0 − t参考,0，为序列打包产生的 RoPE 时间原点差，单位为模型的位置坐标。

组合配置进一步将上式的参考 K/V 限定为同时间 bin 的 Rτ，同时保留原参考视频概率总和 m。两种配置均在第 7–15 个去噪步启用，覆盖全部 50 个 Block，α=1。相位单独配置先测试书封改色，组合配置随后测试五组已有样例；结果见 3.4 节。当前固定 Δ 相位配置已暂停。

3　实验

3.1　数据与任务

FlexiAct 是动作迁移方法及其 benchmark。公开评测集包含 25 类动作、250 个参考视频—目标图像对，图像涵盖真人、动物、动画和游戏角色；每个任务还提供目标 caption，部分 caption 包含动作顺序。任务要求目标图中的角色执行参考视频的动作。[论文]

IVEBench 是指令式视频编辑 benchmark，包含 400 条短视频和 200 条长视频、8 个编辑类别。主要输入是原视频与 edit_prompt，数据另提供源／目标描述和编辑短语。我们优先选择主体替换、外观或交互物体编辑，并检查原有场景和动作是否保留。[论文]

3.2　引导区间与强度

本轮比较 10 项已完成基础编辑的任务，来自 9 条独立参考视频：6 项使用 IVEBench，4 项使用已有舞蹈素材。对每项任务固定提示词、输入、初始噪声与 20 步采样，只改变引导配置。强引导在 7 项任务覆盖全片、3 项舞蹈任务覆盖已有动作窗口；全程弱引导在全部 10 项覆盖全片。新增 45 条区间对照视频，沿用已有普通编辑与第 7–15 步结果。

平均时间误差统计其中 7 项动作延后的任务：先计算每项任务的绝对时间偏移，再对任务等权平均。六项使用动作转折标注区间的中点差，一项舞蹈沿用手臂动作序列时差。另两项用于检查原本同步的动作保持，一项用于检查短动作恢复。编辑完成率统计全部 10 项任务。

4　结论与后续工作

当前优先方案是参考视频时间对齐引导，覆盖全程去噪并取 α=0.25。在七项延后任务中，平均绝对时差由普通编辑的 11.40 帧降至 0.33 帧，十项任务均完成基础编辑。固定区间中，第 1–9 步优于原先沿用的第 7–15 步。

双向时间 Attention 作为候选结构继续检查。与单向全程弱引导相比，双向早期引导的三组 MF 较高，动作时差在两组更大、一组持平。后续统一采样区间、正向强度和视频覆盖范围，测试增加反向约束的收益。

后续测试。优先选择 IVEBench 的主体替换、外观与交互物体编辑，保持官方编辑指令，并固定必要的 H3 输入适配。继续在基础编辑成功且动作延后明显的任务上做同条件配对，同时保留原本同步的样本。每次方法修改先复测已确认有效的案例，联合记录编辑完成、动作时刻、动作持续时间和 MF。
