Attention 公式与原加权实验的关系

对一个 query 和一个 attention head，令 R 为整段参考视频 token 集合，B(q) 为与该 query 对应时间 bin 的参考 token 集合。原生 attention 输出可以分解为各条件组的加权读出。

(1)sⱼ = qᵀkⱼ / √d ，   mR = Σj∈R exp(sⱼ) / Σj∈all exp(sⱼ)oR = Σj∈R softmaxR(s)ⱼ vⱼ ，   oB = Σj∈B(q) softmaxB(q)(s)ⱼ vⱼ
(2)o′ = o + gₙ α mR (oB − oR)

本轮 α = 1，radius = 0，time offset = 0。gₙ 表示当前采样步骤是否开启。公式把原参考组读出替换为同时间读出；本次 attention 中参考组总质量 mR保持原值。后续网络层会基于改动后的 hidden state 继续演化。

此前三倍加权

给选中参考 keys 的 logits 加 log 3，其未归一化 softmax 权重乘 3，也会改变它与其他条件组的竞争。这个操作与 DIAL 的参考 logits 引导直接相近。

s′ⱼ = sⱼ + log 3 · 𝟙[j∈Revent]

当前 Full 的检验目标

选中 query 的参考读取集中于对应时间；实验隔离“读哪个时刻”与“给参考更大总权重”。分组 softmax 的分解属于已知代数，方法价值要由时序、质量与控制实验支持。

行：画布时间；列：参考时间。色块表示可读范围的示意。

数学对应：Full 也可写成 query 相关的 mask 与 logits 偏置

在 α=1 时，记 ZR=ΣRexp(s)、ZB=ΣBexp(s)。对选中 query，把参考组内 B 以外的 keys 屏蔽，对 B 内 keys 加 log(ZR/ZB)；其他组 logits 使用原值。

s′ⱼ = sⱼ + log(ZR/ZB)   (j∈B)s′ⱼ = −∞   (j∈R\B) ;   s′ⱼ = sⱼ   (j∉R)

实数运算下，参考组归一化前的总量仍为 ZR，得到式 (2) 的同一个读出。这说明当前算子属于 attention mask / bias 家族；可检验区别集中在时间对应、组质量约束和实际控制用途。实现采用分组 Flash 读出并记录数值路径。

02

反馈方案：先看当前预测，再选择本步引导

Native 是在当前真实 xₙ、σₙ 和原 H3 条件下，关闭本研究路由后得到的预测。它包含此前干预对轨迹的影响。每步先计算 Native；观测器判定需要继续修复时，在同一个 xₙ、σₙ 上额外计算 Full，再把所选预测交给原 Euler 更新。

(3)ŷₙN = Fnative(xₙ, σₙ, c) ，   gₙ = C(Observer(ŷₙN, R))ŷₙ = { FFull(xₙ, σₙ, c)   if gₙ = 1 ;   ŷₙN   otherwise }dₙ = (xₙ − ŷₙ) / σₙ ，   xₙ₊₁ = xₙ + (σₙ₊₁ − σₙ)dₙ

这里 ŷ 是实际 ComfyUI sampler 接口返回的 clean endpoint；实现保留原视频/音频 sigma 处理及 Euler 运算次序。NFE 是 DiT 调用次数，额外 Full forward 会使 NFE 增加；一次物理采样步骤仍只执行一次 Euler 更新。

R12 · 已完成

latent 粗时延反馈

H3 当前 VAE 将 17 帧分块编码成 5 个时间 bin。跨 5 bin 差分可以抵消同编码相位的某些偏差；它同时具有约 17 帧跨度的平滑效果。

D₅z[k] = (z[k+5] − z[k]) / 17

把参考与当前预测的有符号变化信号插值到物理时间，再在固定事件窗内搜索 δ ∈ [−24,24]，以匹配代价估计局部时延。正值表示生成动作较晚。

接受且 δ≥4：开启；δ∈[−2,2]：关闭；δ=3：保持上一实际选择；δ≤−3：记录提前并关闭；测量拒判：UNKNOWN。

实际结果：开启索引 6–9。索引 10 的内部读数 +2 触发停止，同一端点的外部姿态为 +4；最终仍延后 3–4 帧。

完整解码后的姿态反馈

索引 6–9 采用相同固定引导。索引 10–19 对当前 Native 预测做完整 VAE 解码，再用冻结的 DWPose 测量双臂方向和相对腕位置；每项分别使用 0.3、0.5 的检测置信阈值。

4 个可靠值均 >2 → Full均在 ±2 → Native均 <−2 → 记录提前缺失 / 类别冲突 → UNKNOWN

每一步重新观测，允许停止后再次进入。外部姿态网络使用已有权重，因此方案可归为 training-free，并包含额外预训练测量模型。

实际 26 NFE、20 次 Euler 更新、10 次额外 VAE 解码和姿态测量。主窗方向与腕位置在两个置信阈值下均为 +1 帧；总 wall time 3,286.889 秒，其中观测链 1,181.678 秒。

为什么要换观测器：当前同端点证据表明，latent 读出在接近零时延时低估了残余误差。R19 在线姿态停止将最终主窗残余时差缩小到 +1 帧，并复现固定 6–11 的轨迹。观测器与停止分类规则同时改变，其各自贡献还需独立对照。训练无关、阈值开关、两阶段调度各自已有先例。
R19 完整记录：在线停止与固定策略逐像素复现

当前实际 Full 索引为 6–11：索引 10 的四个姿态时延均为 +4，因此继续引导；索引 11 均为 +3，继续；索引 12 均为 +2，停止；索引 13 为 [1,1,2,2]，保持 Native；索引 14–19 的四项均为 +1，继续 Native。

局部测量、已知限制与接下来的混合观测器

当前事件窗由人工预先固定。Full 在选中的时间 bins 内覆盖全部空间；自动定位动作、区分动作遗漏与幅度不足、理解用户允许改动的动作，仍是独立待解决问题。姿态测量在低可见性、遮挡或人体检测不稳定时会拒判；UNKNOWN 只表示当前测量不足。

R24 两个新视频、两个种子的八条推理和四组配对已完成。原生主窗可测时差为 −1 至 −2 帧，引导后约 −1 帧，主要提供正常对照。R26 的三条新源已完成原片选段，两条运行通道正在生成原生编辑。R27 正在实现整段自动定位与启停，实际控制结果待验证。

阶段切换点 10 来自开发轨迹观察，属于固定设计选择。gap5 也与 17 帧跨度的加权差分等价。需要通过对照检验表示校准、观测可靠性与实际控制各自的作用。
