# 跨 query 约束的数学检查

这是候选一的算子检查，使用二值分布解析条件和 Python 标准库数值求根；未使用 H3 输出。

设各输出 query 的参考时间分布为 \(A_{ij}>0\)，行质量为 \(\rho_i>0\)，\(\sum_i\rho_i=1\)。下式中的 \(X\) 是联合质量，而非每行归一化 Attention：

\[
F(X)=\mathrm{KL}(X\|\operatorname{diag}(\rho)A)
+\lambda_t\langle X,C\rangle
+\lambda_c\mathrm{KL}(X^\top\mathbf1\|b),
\quad X\mathbf1=\rho.
\]

令 \(c_j=\sum_iX_{ij}\)。一阶条件给出：

\[
P_{ij}=X_{ij}/\rho_i
=\frac{A_{ij}\exp(-\lambda_tC_{ij})(b_j/c_j)^{\lambda_c}}
{\sum_kA_{ik}\exp(-\lambda_tC_{ik})(b_k/c_k)^{\lambda_c}}.
\]

这里 \(c_j\) 依赖所有行，因此某行的输入变化会影响其他行。它是已知的软边缘 OT/KL 形式；研究问题在时间覆盖目标和 H3 作用范围。

取两行、两列，\(\rho=b=(0.5,0.5)\)，
\(C=[[0,1],[1,0]]\)，\(\lambda_t=1\)，\(\lambda_c=0.8\)。

| 第 1 行先验 | 第 2 行先验 | 优化后第 1 行 | 优化后第 2 行 |
|---|---|---|---|
| (0.9, 0.1) | (0.9, 0.1) | (0.911475, 0.088525) | (0.582194, 0.417806) |
| (0.9, 0.1) | (0.1, 0.9) | (0.960730, 0.039270) | (0.039270, 0.960730) |

第 1 行先验完全一致，但优化结果随第 2 行改变，证明这个有限惩罚算子具有跨 query 耦合。它既没有退化为每行独立的同时间硬选择，也没有保证最终视频动作对齐。后一个问题需要实际视频实验。

若令时间成本无限大、只允许严格同时间索引，结果会退化为硬对角分配。若 \(\lambda_c=0\)，结果退化为逐行的时间偏置。它们分别对应必要的强约束和无耦合消融。

## 测量和实现约束

- 列质量统计必须以有效物理时长加权，避免 H3 1/4 帧交替 bin 被当作等时长。
- 使用 sampled queries/tile 汇总后，解的边缘只对汇总矩阵成立。广播到全部 queries 后需重新测量实际边缘偏差。
- 参考总概率 \(m_i\) 来自联合 attention；这里优化的 \(P\) 是参考视频内部条件分布。两者分开归一化。
- 强制均衡参考各时间的使用量可能破坏合理停顿或遮挡，软列惩罚和可见支持用于限制这一问题。
