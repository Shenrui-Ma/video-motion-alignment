    困难样例的实际执行

    模型自动选中第 44–59 帧的左臂动作，映射到 5 个视频 latent 时间 bin。在第 5 个去噪步（从零编号 index 4）执行一次参考时间约束，后续继续检测。全程 20 次 Euler 更新，共 21 次模型预测。

    合格候选的合并区域为第 28–63 帧。当前规则取其中误差改善量最大的代表窗，因此实际覆盖其中 16 / 36 帧。第 96–111 帧的右臂候选当时仅出现一次，未达到连续观察条件。

    作用位置

    当前 noisy latent→原始 H3 预测 → clean endpoint→解码＋姿态读取→全视频局部时差扫描→连续观察＋窗口选择→选定 query 时间 bin 的参考读出→一次 Euler 更新

    在同一实际输入状态上，先取得原始模型预测；满足条件时重新计算带时间约束的预测。干预发生在各 DiT 块的注意力输出，保留参考视频组的总注意力质量，并将组内读取集中到同一时间 bin。

    O′(q) = O(q) + 𝟙[q 的时间 bin 被选中] · mᵣ(q) · [Oᵣ,same(q) − Oᵣ(q)]

    其中 mᵣ 是原注意力分给参考视频的总质量，Oᵣ 是组内原始加权读出，Oᵣ,same 是同时间 bin 的组内读出。本轮选中时间 bin 内的全部空间 query、全部 50 个 DiT 块。

    当前证据与待检验处

      局部反馈、动态掩码和持续观察均有相关先例。本轮用于验证全自动执行能力及效果，方案的独立贡献仍需消融和新素材结果支撑。
