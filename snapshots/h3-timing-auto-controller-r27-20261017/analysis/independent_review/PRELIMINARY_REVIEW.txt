Scope: read-only scientific control flow, runtime ownership/lifecycle and postrun acceptance. No GPU/CPU model work performed by reviewer. Only this independent_review directory written. This is not the final sealed review or GPU authorization.

Core design findings (no current scientific blocker found):
1. PredictionProbe gets actual current Euler x and physical sigma, evaluates Native once, persists actual normalized AV endpoint, observes that endpoint via isolated VAE/CPU pose, and optionally evaluates Full on the same x/sigma/condition. Only chosen endpoint returns to the original Euler sampler. Runtime audits require20 callbacks and20+K complete50-block forwards, K<=19; no active index0 because persistence needs the previous endpoint, not because of a fixed denoising handoff.
2. Observations cover indices0..19. Policy uses full-clip16/32-frame windows, stride4 plus final complete start, bilateral/left/right arm features and frozen conf.3/.5, ±24lag scan. Gain>.5, immediately prior endpoint, shared arm and >=.5 overlap/shorter are fixed development hyperparameters. These are not learned or statistically calibrated thresholds.
3. A measured delayed proposal must survive per-window frozen reliability and pairwise-gain rules; advanced/aligned/UNKNOWN remain in observation archives but are not directed into delay correction. Missing reliable torso normalization becomes explicit scientific unknown_visibility. Hash/schema/process/decode/shape errors raise and abort. Empty or unknown proposals clear previous evidence, so re-entry needs fresh persistence.
4. Each overlap component chooses one representative. Shared-arm matching prevents switching from one arm alone to the other arm alone from counting as persistence; bilateral features share both. This remains an engineering persistence rule on correlated windows, not evidence of independent repeated detections or guaranteed self-healing distinction.
5. Selected physical intervals map through frozen (1,4,4,4,4) nominal H3 bins into a set union; QueryGain copies all spatial rows for selected bins, with zero mask rows left at Native attention output. These bins are positional coverage, not exact VAE receptive-field support. The all-one path matches original Full operation ordering; empty path is Native. Model-free actual BF16 kernel gate remains pending root execution.
6. Historical comparison is available only before first ON, inclusive of current Native on first ON. Full and later Native branches permanently become N/A, even after subsequent OFF. Missing pre-index5 old checkpoints are explicit unavailable and do not delay control. Historical postaugmentation full tree remains unavailable; current tree/clean producer evidence/code/seed/noise are bound. No later old Native output is substituted for current controlled trajectory.
7. Isolated decoder admissions allow only exact main-parent identity and >=12GiB free memory on the same GPU. The child exits before CPU pose; OOM tiled fallback aborts. Pose obtains only the shared remote CPU lock after decoder exit; no CPU lock is held waiting for GPU. Local CPU evaluators use Mac→remote order, so this remote-only child creates no reverse lock dependency. Parent guard binds actual inputs/output/sigmas/condition/RNG/model residency and wrapper identities. GPU resident decode/G3 bridge remain actual acceptance requirements.

Requested fixes before final seal:

Old controller could submit its next graph to a new service generation before its later poll/finally rejects the old owner. Require expected_owner in submit, check registry identity immediately before /prompt, and pass/check original owner each controller iteration. Add stale-generation submit negative test. Existing stop(expected_record) prevents wrong shutdown but not wrong submission.
P2-B (postrun): cleanup flags are currently accepted without binding cleanup.pid/service_record to current recorded service and actual job records. Require exact owner/GPU/port and per-job identity; reject stale cleanup or mixed-generation jobs. Resident verification must use the same bound owner.
P2-C (archive acceptance): chosen manifest schema/geometry should be checked against fixed protocol, not only manifest/record self-equality. Full branch PT metadata should bind nfe/sigma/sigma_next/condition/reference/raw signatures to its audit row, analogous to live Native decoder. Add corrupt-source/metadata negative cases.

Scope/claims to preserve:

- Early noisy endpoints may become visible late or self-correct. UNKNOWN is not alignment and low final error is not proof of correct early stopping.
