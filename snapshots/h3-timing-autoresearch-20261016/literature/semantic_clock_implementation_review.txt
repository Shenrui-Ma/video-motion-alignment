WHAT THE CODE ACTUALLY CHANGES

1. Pixel phase P and timestamp phase T are independently applied at the real native clip.tokenize(minimax_ref_items=...) entry. This is not an unused configuration field. ClipProxy receives the actual 141-frame prepared video captured by VAEProxy after native preparation. P changes only the 12-frame semantic data tensor; T changes only its presentation timestamps. The original dense video VAE path is executed before this change and remains the native path.

2. P0/T0 passes through the native item/list/tensor objects. P0/T6 retains native visual pixels and changes timestamps. P6/T0 changes sampled pixels and keeps native timestamps. P6/T6 changes both. The independent graph diff showed only those phase parameters and each arm's run/source/output identifiers differing among B/C/D. Native router mode, seed 2026101311, video geometry 1312 × 736 × 141 at 24 fps, sampler, and sigma settings remain fixed.

3. There are 12 sampled semantic pictures and 6 two-picture visual blocks in every arm. The native MiniMaxH3Tokenizer still converts each two-frame block into a vision entry and formats its mean timestamp. No token repetition or positional padding is introduced to force a matching layout.

4. P6 is a physical 6/24 = 0.25 second sampling shift. Native one-decimal formatting renders T0 as <0.2 seconds>, <1.2 seconds>, ... and T6 as <0.5 seconds>, <1.5 seconds>, ...; the displayed/text label difference is 0.3 seconds. Those are distinct interventions and must not be reported as the same numerical shift.

5. The dense reference/target coordinate origin gap is intentionally retained at 235 native RoPE units. The implementation checks actual full position arrays and corresponding spatial coordinates; it does not silently align the dense temporal origins.

INITIAL FINDINGS AND VERIFIED RESOLUTIONS

HIGH, fixed: Reference/Gate initially depended on external baseline/zero-marker files without a Comfy IS_CHANGED hook. The real execution cache can skip such nodes if inputs are unchanged; OUTPUT_NODE is not a blanket no-cache guarantee. Both nodes now return NaN from IS_CHANGED, forcing the actual external-state gate on reuse.

HIGH, fixed: Failed A0 Gate retries could leave an older valid marker if upstream encoding was cached. A0 Reference and Gate now revoke the old marker before any attempt. GuardedNoise revalidates current state for every use. The tests cover marker deletion/replacement and noise corruption.

MEDIUM/HIGH provenance, fixed: Merely recording the present baseline hash would allow a changed baseline to become the new truth. Both original baseline file hashes are now pinned in source and independently matched to the existing audit archive.

MEDIUM, fixed: A topology check which erases ordinary text IDs cannot establish that only timestamp words changed. The new code calls the real native tokenizer for the six old/new timestamp labels, locates those exact spans in the actual full token ledger, checks equal BPE lengths, and requires every non-timestamp text entry to remain equal. Inspection of the frozen MiniMaxH3Tokenizer confirms its add_text uses the same underlying tokenization path for these independently added segments. Real-word-vocabulary execution remains an A0/B/C/D runtime requirement.

MEDIUM, fixed: The offline checker used assert and insufficient actual provenance validation. It now uses explicit exceptions, checks baseline and current extension files, binds accepted condition hashes, and checks same-P visual tensor/block hashes and same-T timestamps across arms. No assert remains in that checker.

SCIENTIFIC LIMITS, EVEN IF THE IMPLEMENTATION PASSES

This is a controlled diagnostic of fixed-count semantic pictures versus textual time labels. P changes which motion/appearance evidence the model sees; a P effect alone does not establish a clock bug. C and D intentionally introduce inconsistent metadata, so either may be out of distribution. T modifies time words and contextual Qwen hidden states; it is not a pure numerical clock shift or a direct DiT temporal-coordinate intervention. A positive effect establishes sensitivity under these conditions, not a proven sparse-versus-dense clock conflict.

A0 is an engineering equality gate, not an additional generated-outcome replicate. One source/identity/seed plus the already selected failure case cannot establish prevalence or a general architectural cause. Report the pre-registered window, full-video/other-window behavior, uncertainty and rejection cases; do not shift the evaluation window or scan phases until an attractive result appears. No architectural novelty or successful correction is certified by this code review.
