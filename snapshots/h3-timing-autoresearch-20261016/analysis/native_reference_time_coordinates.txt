CONCLUSION

For the actual source05/full1312x736/141-frame run, corresponding output-video and
reference-video latent tokens do NOT share the same native temporal RoPE origin.
For every one of42 temporal bins and943 spatial tokens per bin:

  native_time(output Q) - native_time(reference K) = +235.0 RoPE coordinate units.

At the implemented scale5/3 units per physical video frame, that is a coordinate
interval equivalent to141 frames, or5.875 seconds at24fps. This is NOT a measured
141-frame motion delay. The absolute origins also include text-token indexing,
so these coordinates are not literal playback timestamps.

The current PhaseRoPE actuator does NOT first remove this origin offset. Its
delta=±12 physical frames is a post-native-RoPE extra rotation of the selected
output-Q reference branch by±20 units, around the existing+235-unit separation.
The corresponding-coordinate gap becomes+255 or+215, not+20 or−20.

ORIGIN CALCULATION

Text origin contribution:6960.
Identity image occupies1.0 time unit, although it has950 tokens.
Therefore reference video origin=6960+1=6961.

The42 video bins cover8 complete (1,4,4,4,4) cycles plus(1,4):
  8*(1+4+4+4+4)+(1+4)=8*17+5=141 physical-frame units.
  reference span=141*(5/3)=235 RoPE units (reference audio_t=0).
Therefore target audio AND target video origin=6961+235=7196.

Writing S(j)=sum_{k<j}FRAME_PER_TOKEN[k%5],
  p_ref(j)=6961+(5/3)*S(j)
  p_out(j)=7196+(5/3)*S(j)
  p_out(j)-p_ref(j)=235 for corresponding j.
More generally, with current packing, the separation to a particular reference
includes that reference's span and any later reference blocks' spans. It is not
a universal H3 constant. Here text and the earlier identity-reference contribution
cancel from the reference-to-output difference. Their absolute coordinates still
appear in the saved tensor. Different reference content/order/durations can change
the packing; this audit does not extrapolate235 to every H3 task.

WHAT THE CURRENT PHASE ACTUATOR DOES

Source: extensions_staged/H3PhaseRoPE/core.py
SHA256:83f0fffeac265d0c77d540c8ed730a8b9c639ca73660877aaba72425be88b395
Relevant locations:TemporalRotation.__init__:19–33;
TemporalRotation.__call__:35–49;phase_attention:62–101.

The override receives Q,K after native RMSNorm/RoPE. It takes the selected output
queries, clones them, and applies an extra rotation delta_rope=delta_frames*5/3
only on temporal pairs0:16 with48:64. It computes that changed branch against all
video-reference K/V, then preserves the ORIGINAL reference-group attention mass:
  O_new=O_native+alpha*m_ref*(O_ref_rotated−O_ref_native).
It neither subtracts ref/target origins nor changes the native PackedLayout.
Only the selected query-to-reference-video branch changes; global Q, spatial
coordinates, identity-image/text/audio branches, and K/V remain untouched at that
attention operation. Later network states can nevertheless change.

Ignoring finite precision, compositions of time rotations give:
  Q_branch=R(p_out(j)+delta_frames*5/3) q_unrotated
  K_ref   =R(p_ref(k)) k_unrotated
  coordinate gap for j=k =235+delta_frames*5/3.
The conventional Q^T K relative rotation is R(p_ref−p_out−delta), so its angle
sign is the negative of this chosen Q-minus-K gap convention. Neither convention
is a measured action-delay sign.

  delta physical frames    added RoPE units    same-bin Q−K gap    frame-equivalent gap
          0                       0                 235                    141
        +12                     +20                 255                    153
        −12                     −20                 215                    129

The implementation is an extra post-native rotation, so with float32 angles and
BF16 native Q it is not bitwise equivalent to recomputing all native positions
at the shifted coordinate. Tiny-tensor tests measured that rounding difference;
the coordinate equation is the ideal algebraic description, not a promise of
exact equality for nonzero delta. Delta0/alpha0 uses the exact native path.

For completeness, exact origin coincidence in that branch's ideal coordinates
would require delta=−235/(5/3)=−141 physical frames for this layout. That has NOT
been tested and is far outside±12. This is a calculation, not a recommendation
that origin cancellation is desirable or a predicted cure. The learned model
already operates with the native packed coordinate separation.

The existing same-frame mass router is also not an origin-reset implementation.
It selects matching reference temporal bins for its aligned branch, but uses
the already native-RoPE Q/K, retaining their235-unit offset. Selecting keys by
corresponding bin and making their RoPE origins equal are different operations.

WHAT CAN AND CANNOT BE INFERRED

Established by source and tensors:
  - This Comfy H3 implementation serializes reference-block time spans ahead of
    a shared target audio/video origin.
  - Our actual source05 case has an exact235-unit native offset.
  - Current±12 intervention perturbs that native arrangement; it does not start
    from a zero-origin aligned-reference state.

Not established:
  - Why training used these coordinates or whether their purpose was modality /
    reference separation. The code exposes a rule, not training intent.
  - That the235-unit offset causes the observed13-frame action lag.
  - That decreasing the raw coordinate distance must improve temporal alignment.
    RoPE is a bank of periodic rotations; the complete attention score also
    depends on learned Q/K content, spatial dimensions, normalization and layers.
    Scalar coordinate proximity is not a monotonic attention-strength guarantee.
  - That positive delta necessarily advances or delays visible motion. The actual
    ±12 outcome is empirical and may be content/layer/step dependent.
  - That a hypothetical origin-removal variant is novel, safe, or generally valid.

Interpret pending phase results as native-coordinate perturbation experiments.
Do not rename them origin-alignment experiments or attribute their results to
fixing a demonstrated coordinate bug. No code, model, configuration or GPU state
was modified for this audit.
