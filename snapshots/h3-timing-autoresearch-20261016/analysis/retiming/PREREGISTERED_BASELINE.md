# 旧 Sam05 后处理 retiming baseline：计算前固定方案

目的：检验已知局部延后是否能用普通离线时间重采样明显缓解。此baseline使用源、生成整片姿态，属于有参考的离线/近oracle后处理，不是扩散过程干预。

- 数据固定为旧 `05_real_megumi_v.mp4` 与 `05_sam_s1_baseline_00001_.mp4` 的现有141帧/24fps姿态。
- 禁止改原视频；重采样结果另存完整141帧24fps MP4。
- 标准单调 DTW，允许步长 `(1,1), (1,0), (0,1)`，优先对角处理相同代价。
- Sakoe–Chiba band：`|source_index-edited_index| <= 20`，0/140端点固定。
- 匹配代价：双臂单位方向平均距离 + `0.25 ×` 躯干归一化身体坐标距离；关节原始分数阈值0.3；任一特征有效覆盖不足80%时该特征代价固定为2，不能把漏检当零误差。
- 水平/垂直DTW步额外惩罚0.05，固定不调参。
- 每个源帧对应的路径目标索引取算术均值；对该单调实值映射施加一次5帧中心均值滤波（边界复制），再固定首尾0/140，四舍五入取最近原始帧。保留原始、均值映射、平滑映射、最终整数映射。
- 输出映射带宽、端点、单调性、有效关节覆盖、重复使用帧、未使用帧、步长>1次数、最大跳帧步长。输出优化后的匹配代价只能说明该优化器工作，不能作为独立视觉质量或方法创新证据。
- 如映射满足约束，生成 nearest-neighbor 重采样对照，**不插帧**。检查卡顿、动作压缩、姿态是否本来就错，保留完整视频而非只截最优窗口。
- 不将DTW用于本研究主评估消除时序误差；此处只把它当现实后处理竞争baseline。同一pose用于优化和评价会循环论证，必须靠人工时序/连续性检查或独立标注验证。
