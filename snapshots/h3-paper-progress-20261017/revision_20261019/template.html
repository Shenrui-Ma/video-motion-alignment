参考时间读取与视频编辑的动作对齐

MiniMax H3 · Training-free 推理实验

摘要

我们研究视频编辑保留原动作内容时，动作发生时间发生偏移的问题。在 H3 的 Attention 中，保持参考视频的总注意力权重，改为读取对应 latent 时间 bin 的参考特征。机舱面罩样例的抓取和举带阶段得到改善；饮酒样例仅前半段改善。在更多公开样例中，当前固定引导的收益有限，部分结果仍有动作变化或编辑失败。新增的空间分配保留结构在一个长片段中改变了绕行路径，并丢失持书动作，该结构目前未带来有效修复。采样器对照中，Euler 与 res_multistep 均保留约 15 帧的初段延后。

相关工作方法实验机制检查结论

1　相关工作

DIAL 根据参考内容构造 Attention logits 偏置，并在预设采样区间增强参考影响。MotionEcho 通过运动误差调度教师模型指导。二者分别覆盖参考增强和状态驱动的引导时机，动态开关本身已有先例。

MOFT 以时间去均值和运动通道选择构造运动特征；HALO 区分运动与结构 Attention heads，并向所选结构头注入参考 Value。面部表情理解任务中的 MiRA 将帧置信度和空间集中程度组成时间先验，再对 Attention 重加权，提供了相关的数学先例。Story2Board 的 RAVM 用互惠对应关系混合匹配的 Value，已实现 training-free 的 Value 干预。本次结构试验约束每个 query 的参考空间总量，并使用对应时间的 Value。已有同帧读取作为直接对照；本轮成片显示该改动损害了动作内容。

DiffTrack 分析不同层和去噪步骤的跨帧对应，并通过扰动所选层的跨帧 Attention 构造 guidance。EditVid 从固定时刻的特征建立对应关系，复用匹配并传递参考 token。后续对应关系方案需检验匹配质量、实际修正幅度与动作时间，冻结匹配本身已有先例。

公开社区实现也提供了相关方法。Alisson Anjos 的 H3 aligned video guides 让参考视频与输出共享 RoPE 时空坐标，其同步效果示例结合了配套 LoRA 训练。H3 Flow-Aligned Regenerate 从低分辨率 predicted-clean latent 建立相邻帧对应，用运动补偿残差修正高分辨率预测。当前后续实验检验的是 DiT 内按 query 时间调整参考 Value 读取的作用，并用固定空间坐标读取作对照；对应关系计算沿用已有研究思想。

2　方法

2.1　参考时间读取

将参考视频 token 索引写成时间 t 与空间位置 s。对于当前输出 query q，Aq(t,s) 是参考视频内部归一化的注意力，mq 是完整多模态 Attention 分给参考视频的总权重。τ(q) 是与输出 query 对应的参考 latent 时间 bin。实现按 H3 的位置规则，将视频帧以循环的 (1,4,4,4,4) 帧跨度映射到 latent 时间 bin；这一坐标映射不代表 VAE 的精确时间感受野。

zq = ∑t,s Aq(t,s)V(t,s)
O′q = Oq + αmq(z*q − zq)

已有固定引导只在对应时刻 τ 的参考 K/V 中重新归一化，得到 z*。本轮配对实验采用 20 步采样，在零基去噪索引 6–14 的全部 50 个 DiT blocks 中执行修正，α=1。修改后的 hidden state 会继续影响后续网络，因而也可能影响角色外观和场景。

2.2　保留空间分配的读取结构

该算子已加入 H3 的推理代码，并完成一组配对成片实验。同帧 K/V 读取同时改变参考时间和空间分配；这次改动先保留原参考注意力在每个空间位置上的总量 M，再读取对应时间的 Value：

Mq(s) = ∑tAq(t,s)
z*q = ∑sMq(s)V(τ(q),s)

实现保持全参考 K，将同一时刻的 V 沿参考时间维重复，然后用原参考总权重恢复输出。对固定 Q/K，追加修正对时间恒定的空间 Value 分量为零。该式保留坐标上的总量，人物跨位置时的对应关系仍可能改变。本轮成片观察到绕行路径和持书动作改变。

2.3　自动决策与当前验证范围

先前自动原型会在去噪中解码当前预测，按可见身体部位测量与参考的动作时间差，选择视频区间并决定启停。迁移到公开数据后，遮挡和角色变化使部分观测返回 UNKNOWN。当前先用固定采样区间检验读取修正的实际效果；自动决策模块将在有效执行器上继续验证。本页以下“时序引导”均指固定读取修正。

4　机制检查

4.1　延长引导是否有效

饮酒样例将引导从去噪索引 6–14 延长到 6–19。末次瓶口离嘴仍在 94–97 帧，参考为 80–84 帧；MF 从原固定版的 @@FIXED_MF@@ 降至 @@EXTENDED_MF@@。该对照未支持“增加晚期引导就能修复残余延后”。

4.2　编辑失败与动作偏移

篮球任务的一句提示词产生篮球特写并丢失前半段球员；加入 Video 1 引用和保留要求后恢复人物、运球和霓虹球，但镜头仍向下偏。俯卧支撑任务的新版本完成角色外观替换，后段支撑姿态仍与参考不同。这些结果分别按构图改变和动作迁移不完整记录。

4.3　MF 对时间的敏感性

对 IVEBench 官方 MF 实现的输入诊断发现，可见点被重新插值到归一化序号，原始帧号可能被丢弃。构造一个整体延后 @@DIAGNOSTIC_DELAY@@ 帧、可见区间同步移动的单轨迹，仍可得到 MF=@@DIAGNOSTIC_SCORE@@。这个人工反例说明 MF 不能单独确定物理时间对齐；实际成片同时报告原始帧上的事件时间和编辑完成情况。

4.4　空间分配保留结构的结果

将女子白色衣服改黑的任务中，新结构额外生成帽子、丢失书，并把女子从身后绕过改成从身前经过。三个预先定义的动作事件均失去对应关系。该结构完成了衣服颜色修改，但损害了原视频的动作与物体内容。官方 MF：普通编辑 @@SPATIAL_NATIVE_MF@@，原固定引导 @@SPATIAL_FIXED_MF@@，新结构 @@SPATIAL_NEW_MF@@。干预前六次预测与普通编辑逐字节一致；两种引导在采样位置的平均修正幅度接近。现有结果支持继续检查跨时刻物体对应关系。

4.5　采样器对照

机舱人物替换采用相同提示词、原始噪声、参考条件与 20 个采样时间点，分别使用 Euler 和 res_multistep。两版均在第 57–60 帧抬手、63–66 帧握面罩，参考为 42–45 和 48–51 帧。两版的官方 MF 分别为 @@SAMPLER_EULER_MF@@ 和 @@SAMPLER_RES_MF@@，可见动作事件的时间区间相同。更换采样器提高了这个样例的轨迹相似分数，约 15 帧的初段延后仍然存在。

5　结论

现有证据支持参考时间读取能够改善部分局部动作的时间，但当前固定方法在公开样例上的收益尚不稳定。本轮空间分配保留结构未通过动作保持检查，下一步从跨时刻的物体对应关系修正读取，并继续完成角色替换对照。当前成果是局部可复现现象与干预证据，尚未形成稳定有效的完整自动方法。
