Execution
Both DiT parent and its isolated VAE exec child use .9 GPU2 UUID
GPU-REDACTED. Only one of our physical GPUs is needed.
DiT forward is paused while observing. The child has its own Comfy model
manager and receives only immutable CPU files; it cannot unload or mutate
the parent's Comfy model objects. CPU pose remains CUDA-invisible.

No parent empty_cache, model unload/reload, dtype change, or sampler changes
are introduced. Observed headroom is already larger than the decoder peak.
Admission immediately before each child initialization must require:
  - exact GPU UUID and memory.free >=12288 MiB;
  - the only existing compute PID on that GPU is the registered DiT parent;
  - parent UID/start_ticks/command hash and current request identity match;
  - no foreign compute PID or stale/duplicate decoder child on that GPU;
  - all user resource limits and timeout/cleanup rules still hold.
If insufficient headroom, preserve evidence and fail the run according to
the existing bounded wait/error policy. Do not substitute a different decode,
coerce a missing measurement to UNKNOWN, or touch another user's workload.

The new adapter must replace both old frozen assert_idle_gpu calls with this
strict owned-parent admission, leaving the historical decoder file intact.
The old frozen regular VAE numerical path is unchanged. Explicit OOM/tiled
fallback rejection remains mandatory. Child memory errors abort the run.

Cleanup
After VAE child exit, verify its exact PID is absent and the GPU compute set
contains only the expected live parent. Parent VRAM residency is expected.
Do not require the GPU to be empty while the parent is sampling. Capture
child peak/cost and parent state/RNG/condition/grid/residency before/after.
Final service exit must also clean all registered descendants by their exact
identities. Keep parent-death/timeout/lock-wait CPU tests and add admission
negative tests (foreign PID, reused PID, wrong GPU, insufficient free memory,
duplicate child, missing parent). No killing foreign or unbound processes.
