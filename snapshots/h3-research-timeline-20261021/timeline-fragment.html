问题：短动作修复先确认短动作失真，再尝试增强参考信息。

目标用 H3 做 training-free 视频编辑，保留短动作的出现、姿态和发生时间。

两轮集中实验首轮 3 段真人、16 条输出，目标动作均保留。改选动作切换密集的 2 段真人＋1 段动画，再做 12 条、6 对输出。

观察动画近眼手势失真；真人更多出现约 15–17 帧延后。提示词强调有时会插入或延长动作。

实验：参考加权验证早期对参考片段做 2×／3× 加权；后续由时间对齐引导替代。

验证目的检验提高参考视频的注意力权重，能否改善动作失真或延后。部分真人样例出现时序改善，随后研究逐时间 bin 的对应约束。

具体操作选定动作时间窗口，对该窗口内的生成 query → 参考视频 keys 的 logits 加 ln 2 或 ln 3。代码通过重复选中的 K/V 实现；2×／3× 指 softmax 归一化前的相对权重。

问题：动作时间对齐将首次编辑中的动作时间保持设为研究重点。

问题调整将动作是否出现、姿态是否正确、发生时间是否对齐分别记录；优先处理更常见的动作延后。

比较方式参考视频、普通编辑、引导编辑在相同帧号比较。普通与引导使用相同输入、提示词和种子。

研究目标在一次编辑推理中保持动作时间，同时完成换人、换装或物体编辑。

调整依据动画先试 2×、3×；随后两段真人舞蹈分别替换为 Musk / Sam，做普通编辑与 3× 加权，共 4 对、8 条。 流萤 2×、3× 均未恢复早期近眼动作；真人配对中，原本晚约 9–16 帧的动作接近参考时间。

✓︎方法：参考视频时间对齐引导在 DiT Attention 输出处，以 α 将参考贡献转到对应时间 bin；α=1 时只读取该 bin 的参考视频。

作用位置H3 单流 DiT 各 block 的 Attention head 输出，out_proj 之前。生成视频 latent 经 token 化与各层变换后产生 query，参考视频特征产生 keys 与 values。

时间对应生成视频第 b 个 latent 时间 bin 的 query，对应参考视频第 b 个 bin 内的全部空间 K/V。bin 是 VAE 时间压缩后的时间索引。

强度参数 α保留原 Attention 分给整段参考视频的概率总和 mR，将其中 α 比例的 Value 加权贡献改为同时间 bin 的贡献。α=1 时，参考视频这部分全部来自对应 bin；α=0.25 时，75% 沿用原参考分布，25% 使用同时间 bin。

公式O′ = O + α mR (μsame − μall)。μall 是整段参考视频内部归一化的 Value 加权和，μsame 是同时间 bin 内归一化的 Value 加权和。文字、角色参考图和生成序列等其他 token 组的直接贡献保持原值。

与早期验证的关系后续实验采用本方法。固定区间与全程弱引导共用此算子，通过采样步范围和 α 调节引导。
