The row direction is correct. R is the dense reference video, T is the generated video. Both proposed arms directly edit eligible R-query outputs reading T-video KV; the forward Full and R17 do not directly edit these rows. Matching steps, event-query rows, all spatial keys, and all 50 blocks is a suitable first bounded comparison. Prefix equality alone is not a substitute for the actual conditioning tree.

One validity statement requires correction before implementation acceptance:
“selected reference rows change when target mass is nonzero” is not universally true. SAME can have nonzero m_T yet O_B=O_T, e.g. identical value vectors or a coincident mixture. BLOCK can also yield the same output with a nonzero removed mass. The gate must require correct formula, finite outputs, executed eligible-row count, unchanged inputs/nonselected rows, and logged correction magnitude; require a nonzero change only on an explicitly nondegenerate numerical test. A zero correction on a real input is a result, not automatically a broken implementation. 450 eligible calls likewise does not imply 450 nonzero or causally effective changes.

Required interpretation boundaries (may be stated in an addendum; no extra GPU runs needed):
1. BLOCK removes only T-video KV for the selected R-query rows. Target audio remains in the complement; text, portrait, other R rows can mediate coupling. It is not full generated-to-reference isolation, a reference-independent cache, or a reproduction of the trained papers.
2. The exact untouched-output claim is local to the same input/attention call. Reference embeddings are rebuilt each model forward; there is no persistent reference-hidden state accumulated in place across Euler steps. Downstream changed reference states can influence target states, but no measured next-layer causal claim without a true paired native intermediate.
3. Keep the proposed inexpensive first active-call row-preservation audit. Existing R3 block25_step006 four-head output, if compared after all input/runtime gates and matching hook placement pass, is only a downstream selected-head observation. It cannot reconstruct KV/mass, localize the first effect, represent all 56 heads, or independently identify why motion changed. No additional NFE is required for this first pilot.
4. Native→SAME tests this fixed temporal-support intervention while preserving the native T-group mass at each same-input computation. BLOCK→SAME intentionally changes group mass and permitted support together. The pair cannot identify a mass-independent benefit. Without an equal-cardinality wrong-time control it also cannot prove correct physical-time specificity over generic sparsification; that is a later claim gate, not a demand for a third arm now.

Why the two-arm comparison is scientifically useful despite prior art:
The complete-block principle is explicitly old (OmniTransfer, Identity as Presence, FullDiT2). SAME asks whether retaining time-matched feedback is useful in this frozen H3 setting. BLOCK matching/dominating SAME would weaken that retained-feedback rationale. Both failing rejects these fixed candidates only. Both succeeding would establish a controlled effect on this selected development case, not defective contamination as the universal cause. Vidu S2's same-frame information-exchange language remains a strong collision risk because its exact reverse mask is undisclosed.
