R25 candidate: direction-specific reference feedback experiment
Draft 2026-10-17; no GPU queued and no novelty claim.

Question
Does changing how reference-video queries read generated-video keys causally alter the selected delayed motion? Existing forward Full alters target queries reading reference-video keys. R17 also acts on target queries. The proposed experiment isolates the opposite edge inside joint attention. Target-dependent reference hidden states are expected in a bidirectional transformer; their variation alone is not evidence of defective contamination.

Evidence and prior-art condition
Old source05/Sam/seed2026101311 has Native main delay +13 and forward Full6..14 approximately +1; normal seed1313 and fresh references show failure is conditional. OmniTransfer, Identity as Presence, FullDiT2 already block reference reading target, with their own training contexts. Vidu S2 describes information exchange at corresponding times; exact mask availability must be stated. Our experiment is a frozen-H3 causal ablation and cannot establish method novelty by changing the edge name.

Two proposed additional runs, conditional on implementation review
Keep exact R3 host9 input/conditioning/runtime, prompt, Sam reference, 20Euler/CFG1/noLoRA/1312x736x141/24fps. Fixed zero-based denoising steps6..14 and all50blocks. Same original main RGB window50..65, mapped via actual verified layout to reference bins14..19. All spatial reference-query rows in these bins are eligible. Full target-video key group T includes all target times; B(t) contains target spatial keys at the corresponding relative physical-time bin. Both R and T have equal verified geometry; reject mismatched layouts. Here reference-video refers to the dense VAE reference, distinct from the portrait and text/Qwen semantic rows. Those groups remain eligible in the BLOCK denominator.
Arm reverse_block: for eligible reference queries, replace attention output with Attn(Q_R, K_not_T, V_not_T). This correctly renormalizes remaining groups after masking target-video keys. Target audio, text, portrait and other reference rows remain available, so indirect generated-content paths remain; this arm is not full generated-to-reference isolation. It is a local event-window application of a known asymmetric-attention principle.
Arm reverse_same: let native output be o, target-video total softmax mass m_T, within-target normalized output o_T, and same-time within-target output o_B. Use o'=o+m_T*(o_B-o_T). It retains the native group mass while changing the temporal support. This algebra is already known from the existing forward operator; the new empirical question is the reference-update path and benefit of retaining corresponding feedback.
These modifications occur in the multihead attention output before W_O. All other rows, including target queries, equal native outputs at this attention call. Subsequent blocks can propagate the changed reference states to the target.

Minimal validity evidence
Actual condition/noise/layout and original source byte bindings must match R3. Actual video/audio step005 prefix equality is required. Each run20NFE/20Euler/1000blockcalls/450eligible modifications. Log actual query/key intervals, mapping, target-group mass and finite correction norms. At the first modified layer (index6/block0) independently verify that target-row and all nonselected-row outputs remain bitwise unchanged, selected reference-row changes and group mass are recorded, including zero changes; nonzero group mass does not imply a nonzero correction when the two group outputs coincide. Only a preregistered nondegenerate toy is required to change, and input Q/K/V are unmodified. A per-layer target-row output equivalence only concerns each call, not downstream hidden-state equality. Do not claim measured next-layer propagation from different hashes across different layers. Existing R3 native block25/step006 four-head postattention features could serve as a later-layer comparator after input/prefix binding, if reused with exact mapping; they do not isolate next-layer changes or prove the reference is corrupted. No additional diagnostic NFE is currently requested. Reference embeddings are reconstructed at every model forward; any cross-denoising-step persistence occurs through the evolving target latent. Tests must include explicit dense-attention oracle for reverse-block renormalization, reverse-same real-number equivalence and disjoint row preservation; zero/off replay remains exact. No dense full attention matrix in real production. All allocations and extra NFE/time must be recorded.

Evaluation and decision
Reuse exact original main and auxiliary windows, both .3/.5 thresholds, all49lag curves, original reliability rejection, tracking checks and common-support shape errors. Existing Native and forward Full are benchmarks only after actual input/prefix bridges pass. Report both new arms even if failed or UNKNOWN.
A useful reverse-edge effect requires reliable main direction/wrist delay to improve versus Native and same-frame pose error to improve on common support, with target appearance/background and fixed-frame artifacts separately assessed. Full correction target remains original +-2-frame tolerance. These are single development-case efficacy observations, not statistical significance or architecture proof.
Native retains unconstrained target feedback, BLOCK removes it and renormalizes the other groups, and SAME retains its native mass with matched-time support. BLOCK and SAME therefore intentionally differ in group mass as well as available support; their comparison alone cannot isolate a single mass-independent effect. Native versus SAME isolates the temporal-support intervention at the first modified call, with downstream changes part of its causal effect.
No wrong-time or matched sparse-support arm is included. A successful SAME result therefore supports this tested temporal restriction, while specific superiority of correct physical correspondence over generic sparsification remains untested.
The retained-feedback distinction needs reverse_same to improve the timing/quality tradeoff versus reverse_block. If block matches or dominates it, the proposed time-matched feedback contribution lacks support. If both fail, stop these exact two candidates rather than sweep offsets/layers/strengths on the same sample. If reverse_same succeeds, next evaluate unchanged parameters on existing second delayed source07 and normal source05seed1313 before expanding claims; the completed R24 fixed-forward runs remain a separate generalization study.
No combined reverse+forward arm yet. A combined mechanism needs evidence of complementary effects before spending more runs.
