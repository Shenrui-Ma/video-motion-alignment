R86 观察器自动化范围审查

结论
现有代码可直接提供“最大人物框初始化＋IoU连续跟踪”的自动选人，以及按左右手臂可见性测量时差。R86 额外把被选人物的框中心限制在画幅横向 40%–75%。这个范围由源片及任务指定；时间窗口、开始与停止由当前预测自动决定。去掉范围后，可以测量每段视频独立选出的主要人物，但现有代码尚不能确认该人物就是提示词要求编辑的对象，也没有源人物与生成后人物的语义身份匹配。

1. 手工范围具体在哪里生效
当前 Native x0 → 完整 VAE 解码 → pose_probe.py 检测每帧所有人物并选人 → adult_only() 后置筛选 → arm_features → 全有效时域扫描 → Controller 决策 → 可选同状态引导预测。

scripts/pose_live_child.py:22–37 调用 pose_probe.py 后，在第 30 行直接调用 adult_only(raw, geometry.video_geometry)。scripts/adult_selector.py:15–28 的默认 bounds=(.4,.75)，只检查原 selected_person 的 bbox 中心 x/width，超出则改成 None。当前宽 1312，合法中心为 524.8–984 像素（端点包含，按完整含 padding 画幅）。它不裁图、不识别年龄，也不会改选范围内另一个人。先前人物跟踪状态已在 pose_probe 内更新，后置筛掉不会修正该状态。

configs/protocol.json/person_selection 记录同一范围；scripts/r86_contract.py:32 强制一致。目前执行调用使用函数默认值，协议数值用于冻结核对，而非动态传参。原始 native.pose.json、过滤后的 native.adult.pose.json 及 adult_selection.json 都保存，run_observer.py:58 / live_observer.py:44–55 将过滤版 SHA 绑定至观察器响应。

这也是测量对象筛选，作用范围没有直接写进注意力空间 mask。selector.py:95–102 明确 spatial_support='all_spatial_queries'：最终按选中的视频时间 bins 引导全空间 query，覆盖 50 个 block。

2. 去掉范围可以直接复用什么
输入：源视频已存的全人物 COCO17 坐标/置信度/检测框；每一步当前 Native x0 解码的 107 帧、24 fps 视频及全人物姿态；1312×736 几何；98 个有效帧（尾部 9 帧不参与时差测量）。无需新增检测模型即可消费原始人物选择。

人物规则（scripts/pose_probe.py:50–63,154,192–205）：每段视频首帧取最大面积人物；之后最大化 IoU(当前框,上一选框)+0.05×相对面积。无检测返回 None，连续 12 个采样帧无检测后清空上一框。每次 x0 视频独立初始化，源视频与当前预测之间也不共享身份。即使所有 IoU 为零仍按现有分数选人。前两名过于接近只记 selection_ambiguous，当前扫描和策略没有读取此标志，所以歧义本身不会阻止引导。

部位规则（scripts/arm_features.py:8–43）：由肩→肘、肘→腕的二维单位方向构成双臂、左臂、右臂三种测量。置信度分别以 0.3 和 0.5 计算；某方向的两个端点均过阈值且长度非零才有效。左、右臂可以分别给出结果，不要求髋部或整个人体可见。当前登记中没有只测一段上臂、腿部、手指或物体的独立特征；持续只看清一段上臂会使单臂两段方向的覆盖率约 50%，达不到现有 80% 条件。

时间规则（geometry.py:59 / scan_current_pose.py:18–45）：枚举长度 16、32 帧、stride 4 的候选区间并加入最后一个完整区间；在本例共 40 区间×3 部位=120 行。每个去噪 index 0–19 都观察当前预测。每行搜索 ±24 帧，0.3/0.5 两种置信度所得 lag 相差须≤2；同号且幅度>2 才构成延后/提前候选。候选与 ±2 帧容许偏移比较，最小相对误差收益须>0.5。重叠候选分组取代表，再要求上一去噪步也有同方向、共有手臂、区间重叠/较短区间≥0.5 的代表。满足便引导，不满足即恢复当前 Native；没有独立的手工动作开始帧或固定停止步。跨步 persistence 不额外要求两步 lag 数值相近。

3. 何时 UNKNOWN、停止或失败
• 可见性/匹配 UNKNOWN：有效方向覆盖<80%、有效帧<8、最优匹配缺乏足够可见支持；最优 lag 碰到 ±24 边界；多个动作阶段匹配近似、局部曲线平坦；平移后姿态方向残差>0.5；非零位移相对同帧改善<5%；两置信度 lag 不一致。候选的共同支持比较也会因支持不足或残差大而 UNKNOWN。（timing_metrics.py:111–144；pairwise_gain.py:5–28）
• 已对齐、收益不足、尚未连续两步满足 persistence：均可正常 OFF；这些状态与 UNKNOWN 分开。某行 UNKNOWN 不会阻止其他可靠行触发。全部没有合格候选时，本轮 visible_only 返回当前 Native；虽然继承模块保留 weak_fallback 分支，R86 实际仅注册 visible_only，未启用弱全片兜底。
• 姿态 JSON/帧数/时间/来源 SHA 不符、观察器执行失败、过期响应、缺失完整扫描、去噪 index 不连续：抛错并中止，不作为科学 UNKNOWN。（pose_domain.py:29–49；selector.py:12–47；live_observer.py:41–55）

4. 现有源片的实际核查与实验语义
原参考在 98 个有效帧中全部检测到多人，原规则 98 帧都有 selected_person，歧义标志为 0。全部 107 帧被选框中心为 0.61422–0.65749；raw 与过滤版的 selected_person 在全部帧均相同。此结论仅针对已存参考，不证明每步生成预测也会自动选对成人。源 JSON SHA 与计数见 EVIDENCE.json。

去掉范围后，研究对象将从“预先指定空间范围内的成人”变为“当前片段独立检测并跟踪的主要人物”。在成人与儿童同框时，主体大小、遮挡或生成变化都可能改变选人；现有歧义日志未转为拒绝条件。现有可见部位逻辑解决的是被选人物的手臂是否可测，不解决选错人物。

未来如比较无人工范围版本，须显式登记源与当前预测的选择规则，并重新绑定 source pose/响应路径/协议 SHA；不能仅删除目标侧筛选后仍声称与已注册 R81/R86 完全同一测量。本次参考虽没有实际筛掉任何帧，取消筛选仍改变当前预测的拒绝规则及干预轨迹。当前代码中尚缺“依据任务自动确定编辑对象并在源/当前预测之间保持同一对象”的能力；本轮审查没有实现或评价新的选择方法。

范围与证据
只读 R86 及其直接观察器模块；未加载模型、执行姿态推理、重放决策、修改封存代码或启动任务。代码行号以 EVIDENCE.json 中 SHA 对应版本为准。现有阈值是注册的工程规则，本报告不把它们当作独立校准的动作错误分类器。
