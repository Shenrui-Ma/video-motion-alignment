编码分块相位校准 → 局部时间匹配 → 参考注意力收窄：有界机制审查
2026-10-16。只读已有实验、论文全文和作者代码；没有运行 GPU、模型或新实验。范围是这一条候选，不是通用相关工作清单。“未见”仅指下面实际核查的来源，不证明不存在。

结论

这条路线有明确可检验的需求，值得先验证观测器，再做最小闭环。可争取的区别是：把编码器造成的槽位变化与物理动作时移分开，输出有单位、有拒判条件的局部时延，再把它用于当前参考条件模型的时域选择。不能把 latent 差分、单调匹配、阈值触发、修复后停止或同帧参考 attention 各自称为新机制。MotionEcho 已有监控、触发、指导、停止的完整调度结构；FlowMotion 已从预测干净 latent 提取运动并无需教师地指导；ReTime 已把测得的时间误差反馈到模型时间坐标。具体组合仍可研究，必须证明校准和实例相关决策各自有独立作用，不能仅靠“没有完全相同标题”判断创新。

目前最准确的定位是“编码感知的粗动作时序 observer 与选择性控制候选”。当前证据没有证明短动作缺失检测、可靠的早期整体现实时延、自动找到运动部位、自动排除用户要求修改的动作，或闭环停止后的最终质量。不能先写成已成立的新架构。

恒定 RGB 的 H3 编码有精确五槽位重复：相邻 latent 有非零差异，相隔五 bin 差分为零。实际冻结 encoder 每17物理帧独立编码成5 bin；覆盖宽度为1/4/4/4/4，末段有 trimming。FastVideo 的实现文档明确独立 clip 编码与拼接/trimming；它支持结构解释，不替代本轮恒定输入实验：
https://haoailab.com/FastVideo/api/fastvideo/models/vaes/minimax_h3_parallel/
H3 社区扩展也已检查 suffix_video_step % 5 的相位一致性，不能称首次发现 H3 相位问题。该项目不是 MiniMax 官方来源：
https://github.com/seitanism/ComfyUI-H3-Motion-Context-MultiRef/blob/main/h3_masked_bridge.py

跨身份结果覆盖两片源视频、两种生成条件、若干检查点与窗口，共152格，绝非152个独立样本。gap5 full-frame 在独立 pose 可判的 final 7/7、intermediate 14/14格内均在2物理帧容差；未知 pose 格不能算成功。phase_mean full-frame 只有 final 5/7、intermediate 9/14。gap5 对本组已知格的优势是继续验证的理由，不是泛化保证。

step005 主窗口整体 pose 仍 unknown：双臂方向两阈值均不可判；左臂单独 +13/+12 有支持。latent full-frame +10 仅提供粗延后线索，不能追认原先失败的双臂触发门。step005 是第6次模型调用的端点，不是第5个物理帧。

当前 scan 在每个固定物理时间窗口，搜索常数 lag ∈[-24,24]，用插值后的 signed latent derivative cosine error 选最小值。它没有求局部单调时间映射。拒判项是低 RMS、不完整非零覆盖、间隔至少4帧的竞争极小值差≤1e-6、搜索边界、端点 clamp。152格全部通过这些门，说明它们尚未证明能筛掉错误时延；“有清晰极小值”不等于估计正确。已知近零 pose 格主要来自 mass 修复臂，也不能充当自然正常 native 分布。

gap5 的精确数学限制：令 c_k 为物理覆盖中心，d_i=(z_{i+1}-z_i)/(c_{i+1}-c_i)，则
  D5_k=(z_{k+5}-z_k)/17
      =sum_{i=k}^{k+4}[(c_{i+1}-c_i)/17] d_i。
因此它严格是相邻 signed derivative 的17帧跨度加权平均。五相位加性项会抵消，但相应真实周期动作也可能抵消。不能把“gap5”与这个完全等价的积分基线重复跑成两项创新；也不能把其改进自动归因于相位知识，而非长窗口滤波。17帧约0.708秒，短事件可能被合并，插值到逐帧不会恢复丢掉的时间分辨率。覆盖中心也不等于 encoder 的真实神经感受野。

2. 最接近的五项原文/实现

FlowMotion
原文：https://arxiv.org/html/2603.06289v2 ，§3.2 Eq.2–3、§3.3 Eq.4–5、§3.4 Eq.6–9。
作者代码：https://github.com/HKUST-LongGroup/FlowMotion/blob/main/run.py ，107–127、215–250。
其预测端点 zhat0=z_t-t v_theta；损失同时匹配源/目标端点和跨帧差分，再约束 flow 更新方向。当前作者实现使用相邻及 frame-to-all 的绝对差，不能简化成我们的 signed adjacent 失败版本。它还对加噪参考运行源预测，不只是直接拿 clean VAE reference 作比较。区别可落在物理时延读出、编码槽位校准与拒判，以及直接选择参考 attention 时域；不能主张首次无需教师、首次使用早期 x0 或首次 latent 运动差分。真实 FlowMotion 对照应保留其组合损失和实现；移植 H3 后须标注 adaptation。

MotionEcho
原文：https://arxiv.org/html/2506.19348v2 ，§3.3–3.5、§8.1。
作者页：https://euminds.github.io/motionecho/ 。本次页面仍列 Code(Coming soon)，没有声称审过公开完整实现。
它将学生预测端点重新加噪到教师轨迹，教师作运动修正，再插值端点；运动损失触发教师，教师损失低于另一阈值便截断指导。故“需要时启动、几步后关闭、继续监控”已是直接先例。候选可以不用教师，并针对保留动作的局部物理时延进行拒判；必须证明这些选择降低误触发/开销且保留质量。不能把使用已训练教师说成它必须为每个视频新训练。

MOFT
原文：https://arxiv.org/html/2405.14864v1 ，§3.1–3.3 Eq.1–2、§4。
固定作者实现：https://github.com/xizaoqu/MOFT/blob/44ec33d5eafb99a0dd18bc620dd7d5d5eed3d544/process.ipynb 。
核心为扩散特征减全时间均值，并按 PCA 选择 motion channels；随后用运动特征损失优化 noisy latent，已有粗运动/细控制阶段安排。候选使用 encoder 同相位差分及物理时间匹配，不等价于全时间均值去除；但“去内容以读运动”本身已知。对 adjacent derivative 先减全时间常数又会完全抵消，不能作为有效新组件。需要比较真正的 MOFT 特征读出或明确其受控移植。

ReTime / Semantic Progress Function（SPF）
原文：https://arxiv.org/html/2604.22554v1 ，§3、§4.1 Eq.11–13。
固定作者代码：https://github.com/SagiPolaczek/semantic-progress-function/blob/bf5a388378d5153a9b25ae4a64c2de377e62f48f/spf/retime.py ，58–76、103–167；同仓 spf/solver.py 的 invert_potential。
SPF 从帧语义距离拟合进度；ReTime 以逆进度误差更新时间 RoPE，按频率和去噪步调节，生成后重测并迭代。代码还把物理帧位置映射到 Wan latent 覆盖中心。因此“时间匹配→反馈校正”和考虑 VAE 时间坐标均有先例。候选测当前 x0 与参考的局部相对动作时间，目标保留参考节奏，不是把语义进度线性化；只改参考读取时域，不改全局 RoPE。若只换信号/模型而未改善可靠性、局部保真或成本，这个区别较弱。

TempoControl（动态门的具体开源对照）
原文：https://arxiv.org/html/2510.02226v3 。
固定作者代码：https://github.com/Shira-Schiber/TempoControl/blob/ac28c443ec112e0da6f9f5cbca26a2218d8d12dc/wan/text2video.py ，约550–734。
它比较 video-to-text attention 时间曲线与用户控制曲线，以相关性、幅度和空间项优化 latent；代码在预定早期区间内按相关阈值决定优化并可提前停止。阈值控制已经明确存在。候选不同在参考视频视觉时延的校准和拒判，以及不反传的时域路由；仍需与同等预算固定 schedule、阈值门控 baseline 比较。不能只把动态阈值改成“置信度”就声称结构创新。

3. 只保留一条具体候选

输入：固定参考 clean VAE latent R、真实 sampler 在调用 n 后给出的 clean-endpoint estimate Y_n、source-only 预设的动作保留区域/时间段、编码器覆盖几何。首次实验继续使用预设区域，不顺带声称已完成自动动作定位或用户编辑意图理解。必须沿实际 sampler 的 x0 约定读取，不能机械套另一模型的 z-t v 公式。

观测：在真实物理时间坐标构造 D5(R)、D5(Y_n)，暂把它定义为粗时序特征。对局部区域定义匹配代价 c_n(t,u)=1-cos(f_R(t),f_Yn(u))，并保留未归一化能量/有效空间支持用于拒判。求
  pi_n = argmin_{pi∈P} sum_t w_t c_n(t,pi(t)) + lambda Reg(pi)，
  P: |pi(t)-t|≤L，pi 单调且斜率有正下界/有限上界；缺支持段允许拒判，不强迫填满路径。
这里 pi 把 source time 映射到 target time，pi(t)-t>0 表示目标晚。P、L、Reg 和阈值需在开发集冻结。当前常数 lag 是 pi(t)=t+delta 的严格简单基线，必须保留。单调约束/DTW 本身不是新公式；若片段只有一个近似恒定延迟，就没有理由期待它胜过常数 lag。

置信状态需区分：可信延后、可信已对齐、不可判。至少拒绝近常量/低能量、无共同空间支持、路径落搜索边界、多个相近路径、能量显著不匹配、强挤压或拉伸才匹配上的情况。cosine 对正比例幅度变化不敏感，单看 cosine 无法排除动作幅度不足；周期动作也可有多个正确形状但错误周期的匹配。现有 margin≤1e-6 只是数值退化门，不是校准后的正确率保证。新门的覆盖率—错误率必须独立验证，不能看当前输出选门。

控制：只在预先允许保留动作的 query 集合、可信延后时，把 query 读取 reference 的支持从全时间收窄到同物理时间附近 band B(t)。执行器保持原 reference 总质量 m_ref：
  O' = O + g_n m_ref [A_ref,B V_ref − A_ref V_ref]。
g_n 为门状态；native、radius1、same-bin 是已有/待测算子基线，选定一种后冻结，不把 radius 搜索混入首个闭环。这里不根据估计 delta 移动 band 中心：过去 signed offset 可控性未成立，不能因为观测出+10帧就假定读未来/过去参考一定修正+10帧。单纯同物理时间收窄已有修复证据，是更少假设的执行器。

因果顺序：Y_n 在调用 n 完成后才获得，门只能作用于调用 n+1 及以后。step005（零基5）可为 index6 决策，不能回写产生自身的同一次 forward。观测到当前完整视频的后续物理帧是离线视频编辑允许的上下文，不等于偷看未来去噪状态；仍不能使用最终视频、未来 x0 或独立全程 mass 轨迹决定当前开关。

停止：只有后续实际受控轨迹的 observer 在同一支持上确认回到容差，才称“修复后停止”。unknown 可以按安全策略暂停，但日志必须写 unknown，不能算已修复。容差/滞回/最大持续步数是已知控制组件；首次门应固定。动作被压成近常量、幅度消失或部位被遮住不能触发“已对齐”。关闭后仍须检查复发、最终局部形状、幅度、身份、背景及窗口边缘。数据不足时先做一次开关的最小闭环，不预支多轮自治成功。

4. 能形成机制差异的必要对照

A. 先证明 encoder 校准不是只平滑，也不是同身份像素相似。
优先使用已保存 latent 和已冻结源窗口做 CPU 验证：原片/真实像素域已知延迟、常量、不同起始编码相位、周期动作、幅度下降/遮挡、跨身份，以及正常 native 与错误 native。真实 shift 必须在 RGB 先做再编码，latent 平移不是等价控制。已有 gap5 恒等于17帧积分，二者不应重复记作两法；比较同相位设计与不同相位但匹配物理跨度的特征，并报告时域频响/短事件宽度代价。若差异完全由17帧低通解释，贡献应降为鲁棒粗时序读出，不能称独立相位机制。

B. 证明拒判和单调局部匹配必要。
常数 lag、相同特征的受限单调 path、去掉拒判三项比较；预先固定容差、覆盖率及错误率口径。评价含正延后、零延后、负延后、幅度不足、周期歧义、遮挡，不只已知坏例。错误类型和拒判不得混成零时延。若单调 path 的改善仅来自把动作停住/伸缩对齐，或仅在挑出的窗口出现，应保留常数 lag 版本并放弃这项结构主张。

C. 证明动态判断优于既有固定早期指导，而不是样本上的 schedule 记忆。
先在 CPU 盲评 observer 的 earliest reliable call；新的早期 gate 是新探索终点，原 step005 主 pose gate 保持 unknown。再做同 source/seed/noise 的真实闭环与固定6..14、固定相同干预次数/同一 band、始终开、只开不关对照。跨样例交换触发 schedule 的 yoked control 有助判断实例相关信号是否有作用。全程 mass 结果不得作为当前 native 分支的停机 oracle。次数匹配不等于 sigma-dose 匹配，应同时记录步位置、sigma 区间、路由层数和额外耗时。

D. 证明新的“观测—控制接口”确实有用。
分别报告时延估计、误触发/漏触发、完成采样后的时序与质量、关闭后的复发，以及 wall time/NFE/显存。最强已有简单执行器若相同质量且无需 observer，方法优势只能来自少干预、更低成本或少伤正常样例；若这些都没有，不能用组件增多主张架构进步。FlowMotion/MOFT/TempoControl 的移植应区分完整作者方法与受控局部基线。ReTime 的原任务不同，不能把其均匀进度目标在保留原节奏指标上吃亏当作公平胜利。

5. 当前最小推进门与明确否证

当前适合先做的不是额外扫 GPU 参数，而是复用第二 seed 的已保存 x0，按冻结 gap5 和固定窗口检验预测、拒判及独立 pose 可判格，同时保留背景坏例/unknown。它能检验跨 seed，但因为第二 seed 视频质量本身差，不能替代独立正常 native 数据。新起始 phase 与更短动作将决定编码校准是否具有超出低通的价值；没有这些证据，暂限“粗时序”题目。

满足以下前提后，一条真实闭环值得跑：至少一例在可控调用前有独立可信延后信号、至少一例正常 native 能保持门关闭、退化例能拒判，且使用下一调用的真实因果接口。现有 left-arm 证据可支持新的局部探索，但不能充当已冻结 whole-body 检测成功。固定早期路由有效说明执行器可用，不说明这三个观测前提已齐。

以下任一事实将否定相应主张，而非自动终止全部研究：
  1) 改起始 phase/身份后读出出现±17假峰，或高 margin 仍反向错误：当前 observer 不可闭环；
  2) gap5 在真实短动作上只反映周围大动作：不能研究短事件缺失，需承认粗时序范围；
  3) 单调 path 与常数 lag 无增益或错误伸缩才能匹配：去掉 path，不能包装多余组件；
  4) 实例门的 schedule 交换后效果不变：动态反馈作用未成立；
  5) 对齐信号下降来自幅度消失/遮挡，或停止后重新延后：停机依据不成立；
  6) 固定预算简单路由同等质量、开销更少且正常案例无额外损伤：组合尚无方法价值；
  7) 只当前错误 seed 成功，独立正常/不同动作没有验证：属于机制试验，不能扩写为普遍能力。

若通过，较稳妥的贡献组合是：编码结构导致时序读出伪差的实证与校准评测；带拒判的参考相对局部物理时间估计；依据该估计选择性调用现有路由的轻量控制接口及质量/效率收益。相近论文构成必要基线，不是自动否决；反过来，也不能把这一组合的可实现性当成已实现架构创新。本次核查没有在列出的主来源里看到完整同构的“按 H3 独立编码槽位校准、拒判局部物理 lag、以真实下一 forward 参考 band 控制并验证停机”的实现，但这个有限事实仅允许继续实验，不提供新颖性保证。

6. 最近一项最小因果试验：先不加入单调映射

按 root 最新确认，近期试验仅检验“低成本 latent 反馈是否有因果用途”。本节是上述较长候选的缩小版，不将第3节未实现的组件写成已有功能。

固定源事件窗口50–65物理帧、原先选定的观察区域、同一 source/seed/condition/noise；不自动定位，不新增 ROI。第6次 forward 完成后读取 x0_step005，以已冻结 gap5 + 常数 lag 搜索给粗时延；从零基 index6（第7次 forward）起才可能路由。以后在实际受控轨迹上重测，不从独立 native/mass 的未来轨迹取代观察。执行器只用已经验证的 Full/radius0、相同 query 范围、相同层和 reference mass 口径。

初始状态为 OFF。对每一次可用的实际端点，下一 forward 的状态规则固定为：
  accepted 且 lag≥4：ON，使用 Full；
  accepted 且 −2≤lag≤2：OFF_ALIGNED，不路由；
  accepted 且 lag=3：保持前一有效状态；若前一状态为 UNKNOWN/暂停则保持不路由；
  accepted 且 lag≤−3：OFF_ADVANCED，不路由，单列提前/overshoot；
  rejected/degenerate/ambiguous：UNKNOWN，不在下一 forward 路由，不算已修复。
停止判据来源是原2帧误差容差，开启4帧来源是已有像素域已知延迟阳性控制；这是开发集上的初版工程规定，不是新阈值理论，也不是校准过的概率置信度。离散整数 lag 的规则覆盖全部情况。若以后改连续时间匹配，必须显式重定义区间，不能沿用这一整数枚举而留下缝隙。

只处理正延后域有实际原因：当前 Full 已有对正延后的响应证据；它是否能纠正提前尚未验证。因此不使用 |lag|≥4 双向开启。OFF_ADVANCED 与 OFF_ALIGNED 必须分开；UNKNOWN 也不能贡献“成功关闭”统计。新门即使在 step005 触发，也只是新定义的探索性端点，不重写旧 whole-body pose unknown。

最少对照：原 native；已有固定6..14 Full；真实闭环；预先固定构造规则的等调用数脉冲。后者可在闭环得到 K 个真实 active calls 后，从同一个许可起点连续使用 K 次 Full，不能搜索最优放置位置。该对照使用闭环确定的预算但不使用其调用位置，必须如实标为配对事后预算匹配，而非独立预登记采样参数。若 K=0，则它等于 native，不能算新增支持。全部保留 sigma位置/剂量、reference mass、层数、NFE、observer拷贝/计算时间。等 K 排除“仅仅做更多次”解释，仍不排除 sigma-dose 与轨迹差异。

评价分开：何时打开/关闭及为何暂停；每个实际 x0 的读出与可判独立运动证据；最终 lag/幅度/形状/身份/背景；窗口外是否受损；关闭后是否复发。已有 fixed Full 会出现重影，因此 lag减小不够。若闭环只复现固定早期脉冲而无质量、正常病例保护或成本收益，本轮仅证明接口可用，尚未形成有用新方法。

7. 后续算法差异应从哪条证据产生

编码相位方面：有价值的目标是相位条件下可校准的时间对应误差，尤其在不同输入起点、真实短动作与跨身份下仍有正确拒判；单独把 period=5 写入差分不是贡献。必须用跨度匹配控制区分“去编码槽位伪差”与“把所有运动低通”。如果差异只来自长跨度平滑，保留其工程价值并收缩原理主张。

多尺度方面：gap5 提供粗移位但分辨率不够，较短跨度有分辨率但受槽位扰动。若以后能用相位校准后的细尺度验证粗尺度对应，同时在尺度冲突时拒判，可能形成有独立必要性的估计器；简单加权几个 gap 或多阈值投票是常规信号处理。需要短事件长度分层、phase shift 负控、同总跨度/算量基线证明细节恢复与误触发改善，不能由当前 gap5 正例预支此结果。

单调匹配方面：只有不同部位/相邻动作的延迟在时间上真实变化、且对应可识别时，局部 path 才比常数 lag 有理由。SPF/ReTime 已有单调时间重参数，DTW 也不是新原语；可区分处需是参考相对、局部、带缺支持拒判的物理时钟估计如何改变当前 denoising 的参考读取，并在相同成本下更少破坏非目标动作。如果新数据仍只是整段常数延后，应保留更简单的常数 lag，不为“架构”硬加路径求解器。

上述三项目前均是需要由误差案例选择的后续方向。当前最小闭环的因果用途先决定哪一项值得实现，不能同时堆叠后再用一个改善结果声称每个组件有贡献。
