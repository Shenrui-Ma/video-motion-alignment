# R60：可见单骨段观测诊断

单独观察肩—肘可以恢复原整臂因腕不可见而失去的时移敏感性。同时，当前匹配规则会接受部分无事件对应关系的动作片段。**本轮支持继续研究观测器的可辨识性；单骨段版保留为 CPU 诊断，R59 继续使用已冻结的整臂四组设计。**

所有扫描沿用原置信阈值 0.3/0.5、coverage≥0.8、最少8有效帧、16/32帧窗口、stride4、±24帧 lag 搜索、匹配歧义/残差门、common-support gain>0.5 与原 persistence。这里的“合格”表示通过这些数值门；关节置信分数及两次扫描一致性尚未校准为事件匹配正确概率。没有修改生产文件或调用 GPU、解码器、pose 模型。

## 1. 已知时移与遮挡

upper 只取左5→7、右6→8；forearm 只取左7→9、右8→10。各版本的双侧、左侧、右侧仍分别计算，真实骨段名写入结果。两套政策独立，候选不能跨 upper/forearm 接续 persistence。

固定五条源姿态，复用之前封存的 d=−8,−4,0,4,8 帧合成目标。目标物理时刻 t 包含源 t−d 的内容，越界置信为0，原物理时间和有效前缀保留。相同观测提交两次仅检查 persistence 是否可达 ON。

| 观测特征 | 非零时移格可达 ON | 零时移格出现 ON | 已知时移与可靠 lag 不符的行 |
|---|---:|---:|---:|
| upper | 20/20，覆盖5/5源 | 0/5 | 0 |
| forearm | 16/20，覆盖4/5源 | 0/5 | 0 |

forearm 的 short_0352 全部 UNKNOWN；upper 恢复该源可测性。分母是固定源与时移组合，重叠窗口和左右骨段不计为独立视频。

遮挡对照固定五源 d=0/+4，将 target 两腕或左腕的置信置0，坐标、时间、人物选择保持原值。每版本20格：upper 的10个非零时移格全部可达 ON；forearm 的两腕不可见组全部 UNKNOWN，仅左腕不可见时由右前臂在4/5源检出+4。两版本各10个零时移遮挡格均无 ON。8项定向测试同时验证了单骨段逐值继承、无效骨段保留缺失、同侧有效性和大残差拒绝。

## 4. 方法边界与已有工作

TeleMorpher §4.3用源/目标骨架确定相同解剖部位，再对局部区域建立对应和形变。因此按人体部位建立对应已有直接先例。[TeleMorpher](https://arxiv.org/html/2606.19676v1#S4.SS3)

QueryWarp v1 §3.2根据姿态估计 appearance flow 与 occlusion mask，在自注意力前融合前帧变形后的 query 与当前 query。遮挡置信控制特征采用已有先例。[QueryWarp v1](https://arxiv.org/pdf/2402.12099v1)

MotionEcho根据近期 motion loss 的移动平均触发和截断教师指导，动态触发本身已有先例。[MotionEcho v2](https://arxiv.org/html/2506.19348v2#S3.SS4)

这些已读来源没有给出本轮“原整臂门→可见单骨段、同物理窗口 signed lag、共同支持 gain、相邻去噪步 persistence”的完整实现；本次限定核对不足以证明该组合尚无人做过。当前单骨段改动首先是可测域修复，需证明可靠性和实际效果后再论证方法贡献。观测按身体部位划分，现有执行器仍覆盖所选时间 bin 的全部空间 query。

后续应分别记录关节可见性、同事件的对应证据、时移估计、以及动作类型/姿态改变。腕不可见时保留腕相关 UNKNOWN；上臂可测仅支持上臂方向结论。分层观测若采用整臂优先、单段补充，需要固定选择规则并禁止跨骨段拼接 persistence。本轮没有部署该层级规则或调新阈值。
