# Content-coordinate finite replay adapter

This is an executable Comfy node and finite sampler implementation, not a deployed controller. It consumes the **new same-environment native live** packed states at steps 9 and 19. It never uses the old reconstructed history or its failed replay gate.

`H3ContentCoordinateReplay.run` calls the existing `guider.sample` once. The existing wrapper prepares multimodal conditions, sets complete latent shapes and all 21 sigmas, and creates `KSamplerX0Inpaint`. Inside its finite sampler, each independent call replaces the initial sampler argument with the corresponding saved complete packed AV state. It invokes `model_k(x, sigma)` exactly once. There is no Euler update and no trajectory callback. Existing `BaseModel`/`ModelSamplingAV`/H3 forward therefore apply their own input, audio carry and x0 conversion once. The outer original normalization runs once; only after its video/audio exact check is the final GATE marked passed. The returned last raw x0 only satisfies the sampler interface; it is not a generated trajectory or video.

## Actual interventions and gates

The order is zero9, zero19, then optionally swap9, swap19. Both new zero calls must match the saved full raw AV x0 and all raw/actual Q_C, Q_R, K_R tensors element for element, including dtype, norm weights/eps, actual RoPE/position tensors and fixed probe metadata. Any failure preserves the current evidence and prevents all swaps. Each call gets a fresh copy of the original native router, the original full schedule, exactly 1 model call/50 blocks and 200 successful Triton dispatches, zero CUDA/eager dispatches and zero failed dispatches. Six backend counter keys use the actual `*_calls` schema.

The swap exchanges encoded bins [5,10) and [10,15). All other encoded bins, position/RoPE, role and coordinate noise stay fixed. A cloned prepared payload references the same newly allocated Z from both `refs[0].latent` and `cond_video_latents[0]`; original containers and tensors are restored in finally. The existing refined Qwen **multimodal** presentation is retained. Original target AV state is also retained. Source-following is evidence about this reference-latent pathway; coordinate-following can come from position, noise, unchanged visual context or target context. This artificial encoded block exchange is not a natural video shift.

`ConditionRowsOracle` calls the original `_cond_video_rows` method. It independently makes the exact patchified [30176,96] CPU float32 noise from a fresh private Generator with seed 2026101701; it never adds step to seed and never swaps noise. Augmentation arithmetic stays on the original Z device/dtype path, then transfers at the original final point. It requires the original returned rows to be exactly equal and returns that same original object. Every call records full noise and augmented-row hashes, and all four N must be equal. Historical conditioning N was not independently stored; evidence is the frozen original method/recipe, same Torch environment, current rows equality and the new zero output gates. No historical independent N hash is invented.

## Inputs and future deployment

Pinned `live_inputs.json`, `native_contract.json` and `input_identity.json` bind the existing metadata. All four tensor files are SHA-checked before any is decoded. `load_live_inputs` checks actual `state_file_sha256` metadata, full state signatures, full QK shape/finite values, trajectory, step, case and schedule. The node also checks actual core-file SHAs, conditioning-cache files, checkpoint stat against the existing full-SHA receipt, package assets and a root-supplied Torch/CUDA version record.

The node requires a separate root-reviewed `h3-content-coordinate-root-release-v1` JSON, not supplied here. Required fields: `scope` (`two_zero_only` or `two_zero_then_two_swap`), `maximum_attempts=1`, `cohort=content_coordinate_calibration`, `ready_sha256`, `policy_sha256`, `native_contract_sha256`, `live_inputs` exactly equal to the pinned file, `core_root`, `additional_frozen_runtime_assets` (resource owner binds exact graph, native router sources, cache loader, noise loader and backend-audit bootstrap), `environment={torch,cuda}` matching the recorded new live environment, and one fresh absolute `output_dir`. Its SHA is a node input. Reuse the original native graph's trusted condition cache, saved full AV noise, BasicGuider, native router and complete 21-sigma schedule. Replace its sampler output with this diagnostic node; do not attach VAE/video outputs or the 20-step observer. Runtime owner must separately check resource budget/unique ownership before loading any model. This implementation never starts a model service or submits a prompt itself.

No real state/capture tensor was read for implementation or CPU tests. No model call has run for this adapter. The new exact zero gates and fixed-K readout on swap captures remain future measured results. If a zero gate fails, retain it and diagnose source/domain/backend differences; do not loosen tolerances or borrow the old failed gate. If complete same-state replay cannot be made exact, the alternative is one new passive native trajectory recording the same prepared context and condition noise before a same-run bounded branch; that is a separate release and has not been implemented or executed here.
