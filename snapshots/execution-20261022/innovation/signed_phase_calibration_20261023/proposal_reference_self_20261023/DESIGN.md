# 参考自身时间分布的校准：先检验可辨识性

这是新的 CPU 诊断提案，未执行真实数据拟合，不修改已冻结的配对读出、政策、视频或结论。已有实际结果与独立复算位于 `../calibration_live_runner/actual_run_20261023/`；此次只实现 NumPy 合成 oracle 和反例。

结论先行：下一步更适合检验**完整参考分布的时序指纹能否区分时间**，而非立即求逆得到另一个 alpha 信号。推荐把分布轨迹匹配作为主要诊断，把线性时间码及其谱增益作为辅助诊断。两者均使用 reference-only 空间留出；通过后才值得考虑 generated 分布的迁移问题。

## 1. 需要校准的是读出坐标

在一个固定去噪步、固定层和固定 head 下，记

\[
C_{t,p,j}=p(K_{R,j}\mid Q_{R,t,p}),\qquad
g_{t,p,j}=p(K_{R,j}\mid Q_{C,t,p}).
\]

`t` 为参考 query 的真实 latent 时间 bin，`p` 为预先固定的空间 probe，`j` 为参考 key 时间 bin；每行是完整有效 key 支持上的概率分布。`τ_t` 使用原物理帧区间中心。已有朴素坐标 `μ(g)=Σ_j g_j τ_j` 默认 key 的时间标签就是可靠的读出坐标；reference-self 的大偏置说明这一默认需要检验。

非对角自身注意力**不必然**丢失时间信息。例如 `C` 是一个置换矩阵，`Cτ` 可以错得很远，但每一行仍唯一识别一个参考时刻。相反，静态内容使所有行相同，任何重新标定都无法恢复绝对时间。这里研究的是从内容分布恢复参考轨迹位置，尚未引入“动作相位”的语义假设。

当前概率使用实际 Q/K 按真实 RMSNorm 权重与 eps 归一化、但不施加显式 RoPE 的内容分布；去掉显式旋转不消除网络内部的角色、位置和条件信息。因此即使 reference 的时间可预测，也可能只是预测了 H3 的五 latent 角色或其他时间编码。

## 2. 线性时间码：什么能逆，什么不能逆

先仅用训练 probes 平均构造 `C̄∈R^(T×J)`。令 `H=I−11ᵀ/T`，`X=HC̄`，`y=Hτ`。求解

\[
w_\lambda=\arg\min_w\|Xw-y\|_2^2+\lambda\|w\|_2^2,
\qquad
\widehat\tau(g)=\overline\tau+(g-\overline C)w_\lambda.
\]

截距消除概率行和为一带来的常量坐标自由度；最小范数解自然去掉不可观测方向。若 `X=UΣVᵀ`，解为

\[
w_\lambda=V\,\operatorname{diag}\!\left(\frac{\sigma_i}{\sigma_i^2+\lambda}\right)U^Ty.
\]

无正则时存在精确时间码的充要条件是 `y∈col(X)`，等价于 `y` 与 `ker(Xᵀ)` 正交。无需 `X` 满秩；秩一的连续指纹也可能完整表示一个标量时间。真正有关的是时间目标在各奇异方向上的分量，以及逆增益

\[
L=\|w\|_2,
\qquad |\widehat\tau(g+\delta)-\widehat\tau(g)|\le L\|\delta\|_2.
\]

即使训练误差为零，近似静态的 `C` 也会把微小概率变化放大成任意大的帧差。`λ>0` 限制该增益但同时引入偏差，不能修复周期别名或凭空增加信息。代码把 ridge 写成 `λ=ρσ_max²`，用于合成比较的无量纲参数；本提案**未根据真实输出选定 ρ**。下一步应先报告谱、目标不可恢复残差、增益与留出误差，而非按训练拟合优度挑一个正则值。

线性码还会把两个相隔很远的姿态分布混合读成中间时间，即使参考轨迹从未出现该混合姿态。它可能输出参考范围外的时间。裁剪到视频范围只能隐藏这些失败。

## 3. 完整分布轨迹匹配：保留歧义，不强行平均

以 `z_t=√C̄_t` 为概率指纹，距离取 `d(g,C̄_t)=‖√g−z_t‖₂`，即固定比例的 Hellinger 距离。首先采用离散参考时刻，不引入连续曲线拟合。对给定噪声半径 `ε` 保留完整候选集合

\[
\mathcal T_\epsilon(g)=\{\tau_t:\ d(g,\overline C_t)\le\epsilon\}.
\]

集合为空表示当前分布超出参考支持；集合有相隔较远的多个时刻则报告时间歧义。只有集合直径满足预先要求的时间分辨率时，才有该分辨率上的唯一定位。静态/周期/双峰时，不取几个候选时间的均值。

定义参考自身的分辨率曲线

\[
d_{\min}(\Delta)=\min_{|\tau_s-\tau_t|\ge\Delta}\|z_s-z_t\|_2.
\]

如果一次观测到真实参考指纹的误差确实有界为 `ε`，则 `d_min(Δ)>2ε` 是排除相隔至少 `Δ` 的候选的充分条件，直接来自三角不等式。没有正间隔时，该尺度无法稳定定位。只在离散参考点成立；如果以后增加插值，需要重新验证曲线自交与速度下界，不能沿用离散证书。

空间留出的 reference 残差可以给出**经验噪声半径**，不能给 generated 查询提供分布外误差保证。若外观变化恰好把 `g` 变成另一个参考时刻的指纹，支持检查和 reference 留出都可能完美通过，但动作时间并未改变。这个不可辨识反例是本提案的边界，不应通过加一个阈值掩盖。

## 4. Reference-only 留出方案

下一次获准的真实 CPU 诊断只需已有 NPZ 内 `qrn_kn` 与 `qrw_kw` 两个 reference-self 数组；暂时不读取 `qn_kn/qw_kw` 等 generated 概率，也不读取成片事件收益。两条轨迹的参考状态可能不同，所以分别构造各自指纹，另报告其交叉稳定性，不假定二者一致。

固定范围仍是原 layer25、steps9/19、全部56heads、8probes和31个完整有效时间 bins。保留原 physical spans、spatial ids、padding mask。两个 step 各自计算，不能混成一个训练集后选更有利的 step。每个 head 都给出结果，聚合图只汇总全集，不按新视频改善选择 head。

1. **空间留出**：训练 probe序号 `[0,2,4,6]`，测试 `[1,3,5,7]`，再交换。模板只由训练 probes 构造。输出逐时间、逐 probe 的完整误差，不把31×8当独立视频重复次数。空间 probes 具有内容差异与相关性，此留出检查的是可迁移性，不是统计独立性。
2. **完整分辨率曲线**：输出所有实际时间间距上的 `d_min(Δ)`，并报告 held-out reference 到正确时刻模板的残差全分布与最大值。先不选“最佳 Δ”或降低半径以获得通过。使用 held-out最大残差形成的证书仅是 reference 范围内的经验稳定性诊断。
3. **角色与循环歧义**：将错误配对按 `t mod5` 相同/不同分组，同时完整展示距离矩阵。如果同角色跨周期难以区分，只能读出角色或周期相位。已知真实位移的合成对照必须保持角色背景、只移动内容成分，不能把整条向量直接平移冒充内容位移。
4. **时间泛化单列**：连续时间块留出可以检查线性码是否记忆每一行，但最邻近模板如果移除了该时间，就必然具有时间量化误差。对此应单列“缺失模板插值”任务，不混入空间留出的同支持精度。若实施，按固定5-bin角色周期块交叉留出，边缘块和未覆盖时间明示；不以该试验调到对 generated 输出有利。
5. **参考扰动检验**：固定列置换同时施加于模板和观测，分布匹配应完全不变；统一概率轻微混合应符合逆增益界。静态、角色周期和双峰反例必须保持拒绝/歧义，不能以 mean 恰好对准作为成功。

此计划不新增生产接受阈值。先看参考能否支持所需的时间分辨率，再决定是否值得做 generated 域的独立校准。若两个 step、绝大多数 reference 指纹本身就有宽歧义集合，下一步应停止这一路读出，而不是先加控制器。

## 5. 无法通过参考自校准解决的问题

- **外观与时间同指纹**：同一 `g` 可以来自真正的内容移位，也可以来自零延迟的外观变化，reference-only 方法无法区分。
- **摄像机与动作**：时间可识别的背景或镜头运动也能让 C 非退化；读出的仍可能是场景进度而非目标小动作。
- **稀疏空间采样**：8 probes 没覆盖手、杯口或嘴时，整条轨迹的位置可能可识别，小动作却不可见。
- **参考状态改变**：native/weak 的参考 K 与 reference Q 都可能变化；在一个字典上拟合后跨另一个字典读取，需要独立校验，不可取支持交集或隐式广播。
- **控制方向仍缺失**：即使获得可靠的参考位置读出，它也没有给出 alpha 对该读出的方向导数；当前 Q/K 在该 attention 内固定，不能把输出修正 D 直接当作 Q 的变化。尚需真实局部 H3 链的独立导数/有限差分验证，才有反馈控制意义。

## 6. 代价与下一最小动作

两条轨迹×两步×56heads，每个 head 的模板约31×31；SVD与全部时间距离矩阵只需 CPU 小矩阵。实际 reference-self 原始概率可直接从远端已有 NPZ 取，不需模型、新 attention、GPU 或本地大张量。工作量大约 `O(4×56×T³)`，T=31时数量级约670万基本规模的矩阵运算；该表达忽略SVD实现常数，不用作实测耗时承诺。

下一最小动作建议：另行冻结 reference-only 输入清单和上述留出输出契约，然后只用现有远端 reference-self 数组生成完整距离/谱/留出诊断。当前目录未执行这一步。若 reference 时间本身不可辨识，明确结束此路径；若可辨识，再设计与编辑收益独立的 generated 外观/静态/已知移位测试。

本次12项 CPU 合成测试证明的是上述代数性质与失败反例。它们没有证明当前真实 H3 指纹已经可用，也没有改变现有方法和已完成实验。
