# 实际 STOP 检验独立复核

四个方向均为31/31唯一正确，总124个预先固定的相关格点全部通过；名义帧误差为0。最小 margin 分别为0.066753606、0.066878421、0.070679188、0.071123535，远大于冻结的浮点并列容差。

复核在原服务器CPU上进行，只解码reference白名单。以逐head/probe累加的Hellinger系数公式独立重建全部4个31×31距离矩阵，未调用生产core/run；与原结果最大绝对误差1.33e−15。完整输入/输出SHA、有效支持、全部逐bin并列集合、margin和判定均一致。独立复算耗时0.437秒，大数组留远端。

结论是：这套保留位置对应、联合所有head的参考指纹，能在两个采样步的两条条件轨迹间稳定定位相同参考坐标。纯位置码也能完全通过，所以当前结果尚未读取出真实内容位移。旧跨空间方案失败与本次成功同时涉及空间对应和多head联合方式变化，不能单独归因为某一个因素。
