# 下一步建议：保留 probe 身份的零 GPU 停止检验

**建议只批准一个新的 CPU 反证检验，暂不提出新的 alpha 控制器。** 旧方案将四个空间 probe 平均成同一个时间模板，再迁移到另外四个位置；这项跨位置共享假设已经失败。新的检验保留全部八个位置的对应关系，只问：同一参考视频在两条推理轨迹里，完整、配对的参考分布指纹能否稳定辨认同一参考时间 bin？不训练读出、不调半径、不选 head/step，也不读取生成侧概率、视频分数或事件改善。

本文件是方案评审，未读取实际概率数组运行新统计，未授权新增 GPU 前向。已释放的原 field 同环境复验继续独立执行原契约；它的效果不用于选择本检验的参数或通过标准。

## 1. 现有捕获究竟保留了什么

输入仍为已核验的两份 `step009/019_all_probabilities.npz`，只读取 `qrn_kn`、`qrw_kw`、valid mask、spatial ids 和 nominal frame spans。每份数组 `[56,32,8,32]`，31 个完整有效时间 bin，layer25；四种参考上下文为两轨迹 × 两去噪步。既有状态、视频、捕获和数值定义门槛继续有效。

现有概率 `C[h,t,p,j]` 保留 **query 的空间 probe p**，但每个参考时刻 j 的 key 已通过 log-mean-exp 汇总八个采样位置。故本次仅消除“先平均 query probe 再跨位置迁移”这一假设，不能称为 query/key 均按同一人体点匹配。原始 Q/K 也已保存，但本轮不更换为逐位置 key 或另一个相似度，避免同时改变两个因素。

八个固定采样位置是网格位置，不是跟踪到的手/杯口/关节。四份上下文共用一段参考内容，属于相关重复观测，不能当四段独立视频或数百个独立实验。

## 2. 冻结观察量和唯一主检验

令 a,b 分别表示同一个去噪步内的 native-reference 与 weak-reference。将各 head/probe 的平方根概率逐项拼接，保留 p 的身份：

    Zᵃ_t = concat_{h=1..56,p=1..8} sqrt(Cᵃ[h,t,p,valid_keys]) / sqrt(56·8)
    dᵃ→ᵇ(t,j)² = ||Zᵇ_t − Zᵃ_j||²
    marginᵃ→ᵇ_t = min_{j≠t} dᵃ→ᵇ(t,j)² − dᵃ→ᵇ(t,t)²

每个距离等于全部 56×8 对应行的平均平方 Hellinger 型距离，所有 head、位置等权。静态背景占据的维度可以相同，但不会因先平均概率而抵消其他位置的变化。保持全部候选距离和并列最小值；不取多个候选时间的平均。

主检验恰好四个方向：step9 native→weak/weak→native；step19 native→weak/weak→native。每方向 31 个时间 bin，输出完整 31×31 距离矩阵、31 个 margin、并列候选、名义 bin/帧坐标误差。31×4 是相关测试格点，不是样本量124的视频实验。

目标是**参考坐标的零移位稳定性**：两条轨迹包含同一参考输入，所以期望检索 j=t。t 仅用于最后核对正确标签；读出函数本身对全部 j 检索，不接收 t、不限制对角邻域、不使用 RoPE/位置坐标作输入。时间坐标仅把检索结果换算成名义 bin 中心，不称逐像素真实动作延迟。

不同去噪步的字典不混为训练集，也不把跨步不变性增加为必要条件：实际控制器可在各自 step 建参考字典。本次不另做跨步搜索。

### 预注册停止门槛

唯一数值容差 `η=64·float64_eps`，用于平方距离 [0,2] 的浮点并列判定；它不是模型噪声半径或语义置信阈值。

- **STOP**：四个方向中任一个时间 bin 的 margin≤η，或任一输入/有效支持/数值门槛失败。结束“现有 layer25/8probe、等权联合指纹可作完整参考时间坐标”这一路方案；保留所有失败格点，不筛出成功 head、时间段或某一步另讲收益。
- **仅允许进入独立内容校准**：四方向的全部31个 bin 均唯一正确，margin>η。该严格门槛对应本轮声明的任务——在同支持上区分每一个可用 nominal bin；不引入任意允许错误百分比。通过也不产生 alpha 或控制器准入。

这是一项便宜且保守的必要筛查。margin 接近零时应原样报告其数值，不能将“通过机器精度并列门槛”描述为强抗扰性。若未来要允许歧义时 abstain，必须另立观察量和独立置信度校准，不能事后将本轮失败改成通过。

## 3. 必须先过的有限反例

以下为纯数组、有限维构造；不读取真实 native/weak 收益来定期望结果。

| 构造 | 固定检验应怎样表现 | 对科学解释的约束 |
|---|---|---|
| 静态：对全部 t，C[h,t,p,:]=π[h,p,:] | 每行31个并列、margin=0，STOP | 不应凭 query 时间标签输出一个看似准确的时间。 |
| 五角色周期：C_t=u_(t mod5)，不同角色用不同 one-hot | 同角色跨周期仍并列，STOP | 稳定辨认角色不等于绝对参考时间。 |
| 唯一但乱序指纹：C_t=e_(π(t))，两上下文一致 | 全部唯一正确 | 本检验不会错误要求参考自身注意力必须在对角线。 |
| 空间异质但可识别：不同 p 用不同固定置换，保持同一 p 对应 | 联合指纹应正确；统一交换两上下文的同一 probe 顺序不改变距离 | 保留身份与跨位置平均确实是不同假设。仅交换一边允许失败，不能偷偷最优配对。 |
| 纯位置码：所有上下文 C_t=e_t，画面内容可以完全静止 | 零移位检验仍完美通过 | 明确展示：仅靠现有捕获，即使100%成功也无法排除位置残留。必须有下一节内容干预。 |

| 联合改列标签：所有上下文同时对 key 时间维做同一置换 | 距离与判定完全不变 | 排除依赖某一个 key 的显式时间标签。 |

将整条已有特征行平移后再检索，可作为索引代码的单元测试，但不算真实内容位移校准，因为它同时移动了内容、位置残留及上下文指纹。

## 4. 现有数据的充分性，以及真正缺的最小证据

**现有捕获足以运行上述停止检验；不足以验证有符号动作相位或动态 alpha。** 缺的是内容时间发生变化而 query 位置/编码角色保持不变的观测。纯位置码反例在现有四份数据中与真正可辨识的内容指纹无法区分；增加同一数据上的 SVD/ridge/radius 或更多检索公式不会解决这个问题。

只有停止检验通过后，才值得单独申请一个有限前向、被动捕获的校准计划：

1. 在原 actual AV x_n、sigma、模型/backend、其他条件和 probe 坐标固定时，分别观察**已知正/负参考内容位移、静态参考、时间不变的外观扰动**。仍为原两个 step/layer/全部heads/probes，不依据收益换位置。
2. 测试 Q_R 与 **固定原参考 K_R 字典**配对。不能把被移位参考的 Q、K 一起移位后又把列当原参考时间，否则可能抵消待测移位。使用原读取公式和全部键支持，不借用生成事件时间选择查询行。
3. 首个机制校准可用保持 H3 5-bin角色的已知 ±5 bin 内容移位（名义17帧），位置标签不动。它测试内容/位置分离，尺度尚不足以声明能辨认更短动作。若从像素视频构造，需要有足够原始连续上下文的等长窗口；不得循环补帧。若在已编码参考 token 上构造，须先核对真实输入入口并注明只验证编码内容位移，不能冒充自然视频/VAE 的等价性。共同有效区、边界上下文和时间映射必须在看到结果前固定。
4. 静态参考应给宽歧义/拒绝；已知位移应给正确方向及对应参考位置；时间不变外观扰动应保持原参考位置或明确超出支持，不能稳定报告一个错误位移。以上必须全条件呈现，不以选择某一个head解释失败。

最小新证据是上述四种受控参考条件在两个既定 step 的实际观测（原零移位观测已存在）。它们可由独立、有限 model forward 的只读 hook 取得，不需要为此生成四条完整20步视频；但条件准备、真实同状态/同backend和边界映射仍须另行审核。本文件没有授予这8个条件前向权限，也不建议在本次CPU停止检验前占卡。

即使该参考校准通过，参考读出迁移到 generated Q 仍需独立的外观/运动证据；另外还缺真实 H3 局部链中的修正方向导数。当前层 Q/K 在 O+αD 修正时固定，已有捕获没有测到 ∂Q_next/∂α，不能从参考检索结果直接写出可信反馈 alpha。

## 5. 与当前 field 复验的关系及下一决策

原 field 使用同query参考 Value 差分的平方切向能量，与本提案的有符号时间读出是两条不同机制。其同环境复验锁定原6源码、原alpha/QP、相同cache/noise/model、图仅14/50/52改变；本文件不重新打开参数调整，也不推断仍在预算等待中的成片结果。

因此下一步只有一个清晰决策：**先独立冻结并运行现有 capture 的身份保留联合指纹 STOP 检验。失败则不继续这一路；通过则说明跨轨迹的零移位参考定位成立，再讨论受控内容校准。现阶段不接 alpha。** 这保留了用户需要的内部数学信号方向，同时把位置残留、外观混淆和真实修正效用分别放在可验证的位置。
