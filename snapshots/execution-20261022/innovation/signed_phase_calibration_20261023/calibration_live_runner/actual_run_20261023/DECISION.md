读出目前不足以直接作为动态alpha的误差信号。具体证据是：到嘴窗口的均值变化从step9的负值变为step19正值，且事件窗口内head/probe分布跨越正负；第19步到嘴窗口均值+1.9164、median+0.6247、p10−2.9968、p90+6.5801。对称Q/K归因中，到嘴窗口step9的Q贡献−0.444155、K贡献+0.113564；step19为Q+1.996568、K−0.080130。它定位到了查询与键的变化来源，没有给出动作相位的标定。

当前参考自身的读出也有明显偏置。弱引导轨迹的3个源事件窗口分别使用bins[4,5,6]/[11,12]/[23,24]，与冻结主窗口完全相同；reference-self的“query时间减所读参考时间均值”在step9为−33.2677/−13.9626/+23.2524帧，在step19为−32.9801/−13.9769/+23.7706帧。reference query并不天然读回本时刻，因此直接用key的绝对时间作概率均值坐标缺少可靠自校准。该值是reference-self检索偏置，不是参考视频动作发生了这些帧的移动。

生成查询的归一化时间分布熵在这些窗口均值约0.753–0.806。到嘴事件的参考窗口质量step9为0.04835，step19为0.06377，而31有效bins上该2-bin窗口的均匀质量是0.06452；当前聚合读出对这个事件的时间区分较弱。以上只引用既有冻结描述量，没有另挑head、调整温度、删除事件或改政策。

当前决定：保留全部结果，不接入控制器。下一项只做reference-only的离线可辨识性研究：先检验reference-self的整条时间分布轨迹能否区分不同时刻，以及静态/重复动作/周期位置角色下的退化；在reference-only空间probe留出中验证时间码或轨迹投影，验证前不使用native/weak改善标签选择head、窗口或阈值。它是待检验的新假设，不能直接用来改写本次冻结主结论。
