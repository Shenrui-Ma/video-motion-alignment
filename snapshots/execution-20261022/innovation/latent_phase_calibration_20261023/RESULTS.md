# Latent 相位校准结果：自移位通过，真实编辑读出未通过

2026-10-23。本轮只用 CPU 读取旧 latent，没有运行视频生成、DiT、VAE、姿态模型或 RGB 解码，也未改动现有实验包、服务和队列。

## 直接结论

现有缓存足够在几秒内检验一个内部读出。冻结的“4×4 pooled latent 时间差分＋余弦代价＋单调匹配”能精确找回人为施加的整段 bin 位移；但它没有从真实 native 编辑中读出已标注的局部动作延迟。因此，**这套读出暂不能作为动态 α 剂量干预的相位收益标签**，不继续用它给六次额外 DiT forward 判优。

这是对特征、匹配和置信判据组合的失败诊断。已有矩阵中仍有非对角候选，不能据此判定 latent 内没有动作时间信息，也没有验证或否定 A/B 控制量本身。没有根据此次 cross-edit 数值调参或重新筛选样例。

## 执行与证据

- 两个样例、native/global_weak 两种历史结果、step9/final 两个快照，共8次 source→edited 比较。seed、完整历史 prompt SHA、形状、源文件及捕获 manifest 在 `INPUTS.json`；实际文件 SHA、tensor 内容 SHA 和 metadata 均逐项读取／验证后写入完整结果。

- 6项 CPU测试通过：非均匀时间映射、DP与穷举解比较、已知位移、静态偏置、无信息输入、周期歧义及不回绕边界（部分在同一测试覆盖）。无运行错误。

## 自校准

对 source 和每份生成预测分别施加 −2、−1、0、+1、+2 bin 非循环位移。执行60项移位检查，其中 source 在 native/weak 配对中重复；去重后是10份张量×5位移，即 **50项独立输入／位移组合**。全部有效位置的匹配索引误差为0，正确率100%，有可信点时方向正确。

12次静态逐通道偏置检查全部通过，最大描述子差 **1.083×10⁻¹⁵**，路径不变。饮酒仅使用完整有效bin0..30，手帕0..41，排除跨入补帧的bin和差分端点。无循环回绕、填充参加评分。

这些检查验证了已实现的索引、边界和整段移位识别能力。真实动作延迟往往只影响人物手部或某一个动作阶段，背景和其他运动仍对齐；整段 latent 移位并不覆盖这种难度。

**与既有事件不一致的具体位置：**

- 饮酒native：瓶口到嘴、离嘴分别已标注延后9、10.5帧。final读出在这两个事件的候选路径均为零，可信点均缺失；step9的到嘴事件甚至保留了1个零偏移可信点。
- 手帕native：撤手事件已标注延后16帧。step9和final均只留下零偏移候选，事件内无可信点。

因此表中的“0”应读作该内部路径输出，不能对外写成“动作无延迟”。缺失的事件观测继续保留为missing，不填0。

## 从已有代价矩阵得到的进一步定位

为区别特征问题与路径约束问题，执行后只读保存的final矩阵，检查每行带内最低代价的位置；没有重算特征、改变参数或用它替代预登记结果。完整记录在 `POSTHOC_MATRIX_INSPECTION.json`。

- 饮酒native：12/29行最低代价在同bin，17/29行偏好 `source_bin=target_bin−5`；预登记路径最终仍为同bin。
- weak饮酒29/29行同bin。weak手帕38/40行同bin，另2行偏向+5bin。
- 手帕native也有大量−5bin候选及少量±4/+5候选；预登记路径大部分回到同bin。

这提示两项需要区分的机制：第一，单调路径的步长／平滑代价可能压掉突发的局部时间错位；第二，**5个位置bin正好组成17帧的一组**，大量±5候选也可能包含 VAE／位置分组的周期特征，并不天然等于真实动作延迟。饮酒真实9/10.5帧与该17帧候选明显不同；手帕16帧接近17帧也不能单凭这一例消除周期别名解释。

同时，final所选路径的平均余弦相似性从native到weak提高：饮酒0.8385→0.9406，手帕0.7345→0.8744。这说明本特征能感知总体参考相似性差异，但没有建立它与具体事件时间的一一映射。固定全画面池化可能被背景、镜头或整体结构主导，手部事件所占比例很小；这是待验证的解释，不将其包装为已定位的模型内部原因。

## 下一步的边界
