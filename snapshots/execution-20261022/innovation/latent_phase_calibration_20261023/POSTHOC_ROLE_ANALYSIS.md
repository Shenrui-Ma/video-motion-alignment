# 事后定位：H3 的五位置分组与 latent 相似度偏置

2026-10-23。此分析在预登记读出失败后提出。主结果、参数和分数保持原样；只读源码、既有代价矩阵及原始 cached latent，新增描述性 CPU 统计。

## 结论与下一步价值

**确实存在 t%5 位置分组的统计异质性，以及很强的同组相似度偏好；这项偏好在 reference self 已出现。** 因此，native 中大量 −5bin 最小代价不能直接读成动作延迟。源码为它提供了合理结构来源：VAE 每17帧单独编码为5个 latent，组内位置不同；DiT 的 `(1,2,2)` patchify 不合并相邻时间位置。

这些证据值得支持一个新的、独立预登记的“位置组干扰与动作读出”诊断。当前还没有证明位置组偏置是最终动作延后的原因，也未测量该偏置在 DiT 的条件 attention 输出 S± 中保留多少；不要据原始 latent 统计直接修改 α 控制器。

## 实际源码中的时间布局

以下是本机实验所用 ComfyUI/H3 实现，来源和精确行片段保存在 `POSTHOC_CODE_SOURCES.json`。不是凭 FRAME_PER_TOKEN 名称推断。

`comfy/ldm/minimax/vae.py`，SHA `40c4bf2db63279e0d13eb8de2c8a4602207a90cf9350f94afbee7aeed8b757ea`：

- 第327–355行：`clip_length=17`；`time_down=(1,2,2,1,1,1)`，总时间压缩比4；`tokens_chunk_size=ceil(17/4)=5`；`token_drop=3`，`token_overlap=2`，`frame_pre_padding=3`。
- 第544–557行：`encode_temporal` 每次取独立17帧片段调用编码器；最后不足17帧时重复尾帧；各片段 latent 按时间拼接，最后删3个 latent。107帧得到 `ceil(107/17)*5−3=32`，158帧得到47。
- 第640–664行：decode 每5个 latent 起一段，读取含2个 overlap 的片段；移除前置padding并在输出片段间blend。因此不能将一个 latent 的卷积影响范围严格等同于一个名义帧区间。
- 第685–689行：输出使用全局逐通道 mean/std 归一化，代码没有在这里对五个组内位置分别做均值／方差标准化。

`comfy/ldm/minimax/model.py`，SHA `0d5edcf32b4b98d704eaa51de60ed71f507d0c7d9845947f566647dc76fb8dfe`：

- 第30–31行：`FRAME_PER_TOKEN=(1,4,4,4,4)`、`FRAME_RESCALE=5/3`。
- 第42–56行：video patchify/unpatchify 是 reshape＋维度排列，默认时间patch大小1，只合并2×2空间位置；五种组内位置仍分别保留。
- 第95–102行：RoPE时间坐标使用上述帧跨度的exclusive cumulative sum，再加各模态的origin。该坐标是分组起点，不是 VAE 的精确感受野中心。

`comfy_extras/nodes_minimax_h3.py` 第37–50行明确将时长补到 `17k+5`，latent 长度是 `5k+2`。这与捕获形状一致。这里“role”仅指分析索引 `t%5`，并不声称模型另有五种语义角色embedding。

## 为什么人工整段移位能全部通过

一个与当前现象相容的示意模型是

\[
z_t=c_{t\bmod5}+m_t,
\]

其中 c 表示组内位置相关成分，m 表示内容。中心差分含 `c[(t+1)%5]−c[(t−1)%5]`；当该项较强，描述子自然偏爱相同mod5。

人工移动整段latent得到 `z̃_t=c[(t−δ)%5]+m[t−δ]`，把角色相关成分和动作一起搬走；即使不依靠动作，读出也可能凭组内位置特征找回δ。真实编辑的情形更可能是输出保留自身组布局、局部动作变化，即近似 `z′_t=c[t%5]+m[t−δ]`。此时组相关成分仍支持同bin／同role，而局部动作需要不同匹配。

这个分解是解释反例，不是已经从模型中唯一识别出的两个可加语义分量。它说明已有“整段latent自移位100%通过”尚未测试**位置分组保持、只有动作内容移位**这一条件。新的prereg若成立，应专门覆盖此条件，而不是继续只扩大整体平移次数。

## 是否值得另立读出诊断

**值得，但应围绕这一个已观察到的干扰设计控制，而不先改模型。** 可以预登记比较原读出与一种角色条件化的归一化／去均值读出，验证在保持分组布局的干扰控制中是否减少mod5偏好，同时保留真实短事件的时间信息。角色统计如果由整段视频估计，可能连同动作趋势一起消去；必须在独立样例和冻结事件上检验，不能用当前两例反复选参数。

只取 `t±5` 的同role差分会把尺度扩大到前后约34帧，可能直接抹掉本课题关心的短动作，不能当无代价的修补。当前实测只支持“应排查组内位置干扰”，尚未支持一种新的有效控制器。
