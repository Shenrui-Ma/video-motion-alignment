# 实际 attention 控制统计中的五位置分组差异

2026-10-23，独立事后分析。读取已完成的机舱 `short_0252`、饮酒 `short_0358` 两次 temporal_gain_field 运行，没有重新推理或修改控制器。

**五位置分组差异在当前 attention 控制统计里也明显可见；首步锚归一化和时间平滑已经削弱了它。** 这一证据比原始 latent 的分组统计更接近控制器实际输入，但尚未将编码位置效应与真实动作、外观、镜头变化分离。以下均为描述性统计，不将时间点或层当作独立视频样本做显著性检验。

## 统计来源与口径

每例20个去噪 forward × 50层，分别29、32个实际窗口bin。源码以同一个查询 `Q_t` 分别读取参考时刻 `t−1`、`t+1`，形成：

\[
b_t=S_{t+1}(Q_t)-S_{t-1}(Q_t),\quad D=m(S_t-R),\quad
A=\sum_{h,p}\|\Pi_{b_t}D\|^2,\quad B=\sum_{h,p}\|D-\Pi_{b_t}D\|^2.
\]

`A/B` 是沿局部参考特征切向／其正交补的能量，不直接命名为纯动作／纯外观。统计来自实际 attention 的 probe 投影，已经经过 Q/K/V 和参考质量 `m`，不复用此前原始 latent 描述子。

本次保留全部61,000个“步×层×bin”记录。仅将窗口首尾共4,000条标为排除；其余57,000条全部参与估计。每bin最多56 heads × 8 probes = 448个有效探针；第49层部分探针被原控制器的信号条件遮掉，机舱最少398、饮酒最少399，仍保留这些bin。分组使用绝对 `t % 5`，两图均从bin0开始。机舱内部五组数为 `[5,6,6,5,5]`，饮酒 `[6,6,6,6,6]`。

先在每个相同 step、layer 内按role求均值及方差，再汇总950个非首步调用；首步另列。报告的效用比例为：

\[
q=\frac{A}{A+B},\qquad
\hat q=\frac{A/A_0}{A/A_0+B/B_0}.
\]

`A0/B0` 是每层每bin首个有效步的固定锚。本次所有内部bin都在step0建立锚，因此首步 `q̂=.5`、实际 `α=.25`。完整输出也保留 A/B 每有效探针能量、能量加权比例、增长比 A/A0 与 B/B0。

控制目标在 `.25` 处、除以总能量后的负导数为 `1.5(2q−1)`；归一化后换成 `q̂`。未平滑的闭式解 `clip((q+.125)/(3.5−2q),0,.5)` 只作目标解释，存为 `raw_local_optimum/normalized_local_optimum`；实际应用值始终取运行记录 `alpha`，没有将离线公式当作另一次视频实验。

## 结果

下表均为steps 1–19，同步同层先分组再平均。列顺序为role0到role4。

| 实际记录 | 机舱 | 饮酒 |
|---|---|---|
| 归一化前 `A/(A+B)` | .102 / .157 / .104 / .129 / .250 | .099 / .138 / .105 / .104 / .194 |
| 首步锚归一化后 `q̂` | .513 / .475 / .501 / .517 / .488 | .505 / .461 / .512 / .497 / .448 |
| 最终实际 `α` | .257 / .244 / .254 / .261 / .251 | .250 / .238 / .255 / .249 / .232 |

原始切向比例在两例都偏高于role4，并且在step0已经出现。归一化后的role4并未继续获得最大α：机舱基本回到先验附近，饮酒低于其他组。这与“固定组内尺度被首步锚抵消、后续只响应相对变化”的实现相符。

这里将每次调用内部的组间平方和相加，除以内部总平方和，得到描述性 `η²`；它衡量该统计量的组间结构，不表示动作误差的解释率。组间方差为每次调用的五个role均值的总体方差，再对调用平均。

| 统计量 | 机舱组间方差 | 饮酒组间方差 | 机舱 η² | 饮酒 η² |
|---|---:|---:|---:|---:|
| 原始切向比例 q | .007950 | .005548 | .854 | .782 |
| 锚归一化 q̂ | .003602 | .003133 | .330 | .332 |
| 归一化后未平滑局部α | .001355 | .001066 | .329 | .315 |
| 实际平滑α | .000552 | .000419 | .265 | .252 |

对每个step/layer再扣除各连续五bin片段的均值，保留全部内部bin和不完整边缘片段，原始q的role4差值仍为机舱 `+.1007`、饮酒 `+.0645`。最终α的role4差值则为 `−.00145`、`−.01244`。这项辅助口径减少了慢变化片段均值的影响，没有改变主结果或选择特定动作区间。

## 下一步含义与验证
