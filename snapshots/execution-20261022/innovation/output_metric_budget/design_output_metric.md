# 用输出投影度量 Attention head 的修正预算

状态：离线设计及小张量原型。未接入运行中的模型、节点或队列。先等待本批 head 预算实验的成片，再决定是否进行这一独立消融。

## 1. 要解决的具体问题

当前 `heads_budget` 保持输出投影前的修正能量：Σ_h e_h α_h²=a₀²Σ_h e_h，e_h=Σ_i‖D_i,h‖²，a₀=0.25。它能排除“只是加大输入修正剂量”的混淆，但不同 head 随后经过不同的输出投影矩阵。投影会改变各 head 的尺度，还会产生相互加强或抵消。

一个两 head 例子：D₁=D₂=1，投影权重分别为 1 和 −0.9。固定系数 (0.25,0.25) 与系数 (√0.125,0) 的投影前能量相同；投影后能量分别为 0.000625 和 0.125，后者是前者 200 倍。当前预算的数学定义是正确的，但度量位置未覆盖后续投影。

## 2. 真实 H3 中的位置和可访问性

已核对保存的 H3 源码 `innovation/partial_rope/sources/host41_model.py`（SHA256 `0d5edcf32b4b98d704eaa51de60ed71f507d0c7d9845947f566647dc76fb8dfe`）：

- `Attention.forward` 先调用被我们替换的 `optimized_attention`，然后调用 `self.out_proj(out.squeeze(0))`。
- `out_proj` 为无 bias 的 Linear。该 H3 默认 56 heads×128 channels，共 7168 输入通道，输出隐藏维度为 5376，共 50 个 DiT block。
- 可经 `diffusion.blocks[l].attn.out_proj` 访问模块。在线性有效权重 W∈R^(5376×7168) 中，第 h 个 head 对应列 `128h:128(h+1)`。
- 投影结果还经过 `gate_msa` 逐通道缩放，才加到残差 x；之后进入另一归一化和 MLP。因此 W_o 度量对应 attention 输出投影后的局部变化。若进一步度量即时残差，需把 gate 也纳入，不能把 W_o 后的范数写成最终 latent 的变化范数。

另只读核对了服务器当前 Comfy `ops.py`（SHA256 `428b83aba285d22d64511aa8e98254403ab34c0b12d72a832973578d76abda42`）。`CastBiasWeightContext` 会处理 offload、cast、weight_function/LoRA；混合精度 Linear 还可能执行输入 `pre_quant_scale` 和输入量化。实现必须使用与本次 out_proj 一致的有效权重与输入缩放，保留缓存失效条件。若实际启用动态输入量化，模块不再是精确的全局线性映射，Gram 是其线性代理，需要用小批 probe 的真实模块差值验证误差。直接读取裸 `.weight` 不满足这些条件。

## 3. 输出诱导 Gram 和两个预算

对同一组输出 Query probe i，令 X_i,h=D_i,h W_hᵀ。所有 head 必须使用相同 query 索引。定义

G_hg=Σ_i w_i⟨X_i,h,X_i,g⟩，w_i≥0。

G 是半正定矩阵。对任意系数向量 a，有

E_out(a)=‖Σ_h a_h X_h‖²=aᵀGa。

这保留了 head 间的交叉项。固定弱引导预算为 B₀=a₀²1ᵀG1。

仅使用 G 会允许利用零空间：若两个 head 的输出完全相反，则共同增大二者不会改变 aᵀGa。有限 probe 上的抵消还可能在未采样位置失效。增加不含交叉抵消的约束：

- aᵀGa≤B₀。
- aᵀdiag(G)a≤γa₀²tr(G)，首个消融 γ=1。
- 0≤a_h≤0.5。

当固定基准本身接近完全抵消，例如 B₀≤10⁻⁶a₀²tr(G)，先使用固定 a₀，不把近零预算放大为激进 head 权重。这个阈值属于数值保护，应记录触发比例。

可以最大化当前 head 方法已有的线性效用 `Σ_h e_h u_h a_h`，其中 u_h 是 probe 的切向能量占比，先保持效用不变，只更换预算度量。约束集是凸的，固定 a₀ 总是可行。使用“≤”允许预算留空；强制等式 `aᵀGa=B₀` 会变成非凸可行集，并可能强迫无可靠信号的 head 继续耗用预算。

严格凸正则可给出唯一优化解，但一般 G 含交叉项，不能直接复用当前按 head 独立的 water-filling 闭式解。小维度二次规划是可行的下一实现方向，尚未写入运行时。

本次 CPU 原型只实现一个更轻的安全过滤器：先取得现有 head 分配候选，再对整向量共同缩放到两个预算内。它满足给定 G 的约束，用于验证度量与保护逻辑，不宣称求出了上述优化问题的最优解。应记录实际使用预算；若大量缩小系数，需要额外匹配剂量对照。

## 4. 低成本计算路径

直接保留每个 probe、head 的 5376 维投影较贵。以 29 bins×8 probes=232 个 query 为例：

| 项目 | 每层数量 |
|---|---:|
| 逐 head 精确输出投影 | 8.94×10⁹ MAC |
| 精确 Gram 内积 | 3.91×10⁹ MAC |
| 全 X 的 FP32 临时内存 | 266.44 MiB |

可用输出空间的共享随机投影 R∈R^(5376×k)，例如 Rademacher/√k：

W̄_h=W_hᵀR，Z_i,h=D_i,h W̄_h，Ĝ_hg=Σ_i⟨Z_i,h,Z_i,g⟩。

共享同一 R 保留 head 之间的交叉项，E[Ĝ]=G。每个 head 使用独立 R 会破坏交叉相关。k=32 的算术规模为：

| 项目 | 数量 |
|---|---:|
| 缓存 WᵀR（每层、权重变化时一次） | 1.23×10⁹ MAC |
| 每层 probe 计算 Z | 5.32×10⁷ MAC |
| 每层 sketch Gram | 2.33×10⁷ MAC |
| Z 的 FP32 临时内存 | 1.59 MiB |
| 50 层 WᵀR 的 FP32 缓存总量 | 43.75 MiB |

这些是算术量，运行时还受权重 cast/offload 和显存带宽影响，需实测耗时。缓存应在各层有效权重已可访问时建立，不能为 sketch 常驻额外一整份模型；LoRA、权重补丁、dtype、输入缩放或模型变化必须使缓存失效。

k=32/64 与少量空间 probe 给出的是近似度量。近抵消方向的相对误差尤其敏感。先在少数层/步用独立未参与求解的 probe 计算候选与固定系数的真实投影差值，报告能量比误差和预算超出率；验证未通过时保持原固定弱引导。首次比较 k=32 与 64、固定 sketch seed，禁止按最终视频收益选择 sketch。

## 5. 动态强度与 layer 分配的关系

### 单个 α 的投影后目标

原 D_T、D_N 在投影前正交，投影后 T=D_TWᵀ、N=D_NWᵀ 通常不正交。记 A=‖T‖²、B=‖N‖²、K=⟨T,N⟩、C=A+B+2K。若定义

J(a)=‖a(T+N)−T‖²+λa²B+μ(a−a₀)²C，

则 a*=clip((A+K+μa₀C)/((1+μ)C+λB),0,a_max)。省略 K 会优化另一个目标。本次原型仅验证该恒等式；它还未与正在测试的 anchor 校准方案组合。

这个度量不解决时间方向的语义辨识：参考特征的局部时间变化也可能包含外观、遮挡与镜头变化。数学上仅凭 A/B 或 G 无法唯一识别哪部分修正会改善动作时序。指标、编辑完成情况和成片小动作对照仍用于评估代理目标。

### 因果 layer 预算

当前逐层控制器可在该层即时调整强度；跨层选择则不能在第 1 层提前知道当前第 50 层的统计。可以在去噪步 s−1 结束后收集各层质量 q_(s−1,l) 与局部修正能量 e_(s−1,l)，在步 s 开始前分配层系数：

Σ_l e_(s−1,l)a_(s,l)²≤a₀²Σ_l e_(s−1,l)。

首个 step 使用固定 a₀。该等式只约束上一 step 的预测预算；当前实际能量 Σ_l e_(s,l)a_(s,l)²要另行记录，不能称为当前 step 精确保守。局部能量可用 W_o 后范数相对该层残差范数归一化，若能获取原 gate 则纳入 gate。

另一种在线上界是设置上一 step 的预算并逐层扣除当前已发生能量；预算不足时截断当前系数。这能保证不超出旧预算，但会偏向较早层，应单独消融。各层的局部扰动之和也不是最终 latent 扰动的范数；后者涉及下游 Jacobian 与跨层交叉项，精确计算需要额外信息。

因此先做 head 度量，不与 layer 选择或动态 anchor 叠加。layer 版本待 head 证据明确后再独立实现。

## 6. DOF 零假设的诊断

对单位切向 u，随机误差协方差为 Σ 时，投影能量占总体能量的统计比例由 uᵀΣu/tr(Σ) 决定。只有各向同性且相应独立条件成立时才是 1/d。有效秩 `(trΣ)²/trΣ²` 不能单独确定切向朝向，因此不能机械地把 d 换成有效秩就认为完成校准。

后续可用已有特征的时间打乱、带收缩的白化或同一 query 的远邻参考读取建立内部零对照。前者无需额外 attention，但打乱后 query 上下文也变了；后者更接近同 query 对照，但需要额外小 probe 查询。这些仅为诊断方案。当前已实现的 anchor 控制器使用每层首个有效 step 的实际 A/B 比例，不再使用 128 维白噪声先验。
