# 固定修正能量的时间强度分配

状态：`review_only`。独立节点 `H3TemporalGainFieldFixedBudget`，未部署，未写入运行队列。准备机舱、饮酒、书本和手帕四个原有案例，独立 cohort；四例全部纳入，不按新方法收益选取。

## 这个对照回答什么

原 field 的 QP 同时改变时间分配与整体修正剂量。此前的时间均匀对照保留 field 候选剂量、去掉时间分配；本对照保留候选的相对分配、把剂量约束到同次前向固定 α=.25 的水平。这是第三种独立剂量控制，不叠加其他方法。

原 `controller.py`、`components.py`、`frozen.py` 逐字复制，不改 A/B、因果锚、平滑系数 .625 或 QP。生成候选 `a_t` 后，使用完整分辨率修正

\[
D_t=m_t(S_t-R_t),\qquad E_t=\sum_{h,s,d}D_{h,t,s,d}^2.
\]

M 只包含本次 QP 成功求解的 bin。选择 c≥0，使

\[
\sum_{t\in M}E_t\min(.5,c a_t)^2=.25^2\sum_{t\in M}E_t.
\]

在 M 内应用 `min(.5,c a_t)`，其余 bin 仍为 .25。端点、新锚、无证据及失败区间都不进入预算。无 cap 时，c=.25√(ΣE/ΣEa²)；达到 cap 后用单调求根，不能简单截断闭式解，否则会低于目标剂量。

因此整个目标视频窗口满足

\[
\sum_tE_t\widetilde a_t^2=.25^2\sum_tE_t
\]

至源 dtype 舍入误差。没有达到 cap 的位置保留候选比例；达到 cap 的位置固定为 .5，其余位置继续按同一倍率缩放。均值相同不等于剂量相同，例如 α=(.1,.4)、E=(9,1) 的平均 α 为 .25，但能量是 .25，而固定 .25 的能量为 .625。

匹配对象是这个运行当前前向中的 D。各方法使用不同 α 后，后续 hidden state 和 D 会分化；这里不匹配另一条独立 weak/field 轨迹，也不控制 W_o 后或最终视频的能量。

## 可解性和退化行为

f(c)=ΣE min(.5,c a)² 连续、单调。正能量且正候选的支持 S 决定上界 `.5²Σ_S E`。目标不超过此上界时可达；在至少一个正能量项尚未饱和的区间内严格递增。正常冻结 QP 在 μ=1 下的局部最优值最小为 1/28，非负平滑的离散最大值原理保留这个正下界，因此正常运行的可变 bin 不会全部为零。

- 没有可变 bin，或 Σ_M E 不超过原统计 dtype 的最小正正规数：保持 .25。
- 候选全零，或非零候选支持能量不足：明确记录原因并回退 .25；不声称找到倍率解，也不偷偷扩大非零支持集。
- 恰好等于支持容量时可取所有正候选支持均饱和的根。
- 非有限输入、负能量、超出 [0,.5]、固定 bin 被改动、FP64 总和溢出：明确拒绝。

实际求根先尝试无 cap 闭式解；需要 cap 时，在有限的 log(c) 区间最多二分96轮。用归一化非负能量权重和 log-sum-exp，避免微小正候选平方下溢。极端 c 无法由一个 FP64 数表示时，仍可用有限 log(c) 表示并得到有限实际 α，审计保留这种情况。求根残差上限 2e-13；转回源 dtype 后再次验证总能量相对误差≤3e-7。

## 接入、计算量和审计

同原 field：native、全参考、同时间、前邻、后邻，共5次 attention。没有额外 DiT、VAE、RGB 或模型。每层每步额外把 2×T 的候选与完整分辨率能量小向量复制到 CPU，再作标量求根；求根使用 CPU，真实设备同步耗时需在 GPU 运行中记录。

`candidate_alpha` 和 `control.alpha` 对应原 QP；实际 `alpha` 对应 capped radial 控制。`fixed_budget` 记录 mask、c/log(c)、求根方式/迭代数、支持容量、目标剂量、候选剂量、实际剂量、cap、fallback、CPU耗时与小向量传输量。KKT只检查候选，不把缩放结果称作原 QP 最优解。

`audit.py` 独立检查冻结目标、支持可解性、log(c) 对应的逐bin输出、整体剂量、边界以及实际舍入误差，再复用冻结 field 审计核对锚和候选 KKT。它不调用运行时求根函数。
