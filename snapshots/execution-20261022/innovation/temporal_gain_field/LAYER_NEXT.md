# 下一轮独立 layer 选择：延迟一步的层强度预算

仅设计。先看本批 anchor 和 heads 的成片；layer 方案不与逐 bin field 或 head 分配叠加。

对去噪步 s−1 的每层 ℓ，保存：

1. 同 Query 参考时间差分的 A/B 与该层初始锚点，得到规范质量 `u_l=r_T/(r_T+r_N)`。
2. 全分辨率同时间修正 D_l 的相对能量 `e_l=||D_l||²/(||O_native,l||²+ε)`，其中 O_native 是原 attention 的输出。它度量该层投影前的局部相对扰动，避免直接把不同层的绝对激活幅度混成一个尺度。

第 s 步开始前，只使用这些已完成统计，分配全视频统一的层系数：

max Σ_l e_(s−1,l)u_(s−1,l)a_(s,l)，
subject to Σ_l e_(s−1,l)a_(s,l)²≤0.25²Σ_l e_(s−1,l)，0≤a_(s,l)≤0.5。

质量非负时可复用现有能量预算 water-filling：`a_l=min(0.5,c·u_l)`，由预算确定 c。无证据层固定 0.25，并从待分配集合中移出；只在有证据层之间分配它们自身的基准预算。质量全相同时恢复固定 0.25。

首个去噪步固定 0.25。若 u 用首步 anchor 归一化，首步 u 全为 0.5，第二步也保持 0.25；之后才根据已观察到的相对变化做层选择。这个两步初始行为是因果校准的直接结果，应写入日志。

第 s 步执行中重新测当步 e_(s,l)，在 50 层完成后记录：

- 预测预算比：`Σ e_(s−1,l)a_(s,l)² / (0.25²Σ e_(s−1,l))`。
- 当步实际漂移：`R_s=Σ e_(s,l)a_(s,l)² / (0.25²Σ e_(s,l))`。
- 层系数、质量、有效层掩码、饱和比例和两个比值随采样步的曲线。

预测预算可以精确满足；R_s 不预先等于 1。前层改动会影响后层输入，当步尚未运行的层统计无法提前获得。不要把本方法写成当前完整 50 层预算守恒。若 R_s 系统性偏离，再做剂量匹配对照或独立的因果预算反馈，首轮不增加补偿机制。

该局部能量也不是最终视频 latent 的变化范数：最终影响还依赖 W_o、AdaLN gate、下游 Jacobian 和跨层交叉项。若输出 Gram 的审计表明 W_o 引起明显尺度偏移，可把 e_l 换为经过验证的投影后局部能量，作为另一独立消融。

最小对照为固定 0.25、即时 scalar anchor、延迟一步的 layer 预算，使用同两例；不改变 heads、视频时间窗口或 prompt。再用固定置换层质量的控制检查收益是否来自正确的层对应，而非只改变层强度分布。该方案的贡献落在跨层资源分配，和逐 bin 时间强度场保持明确区分。
