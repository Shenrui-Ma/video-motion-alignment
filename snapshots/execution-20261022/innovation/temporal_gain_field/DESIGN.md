# 逐视频时间 bin 的动态引导强度场

状态：独立 CPU 研究原型。没有部署，没有修改 anchor、feature 节点或推理队列。

## 1. 作用位置与输入

目前 anchor 方法在一次去噪前向中，为每个 DiT block 产生一个 α。此候选保留视频时间轴，为去噪步 s、层 ℓ、视频 latent 时间 bin t 分别产生 α_(s,ℓ,t)。α 仍乘在原同时间参考修正 `D=m(S−R)` 上；只是由广播一个标量改为沿视频时间轴广播一个向量。同一 bin 内的空间位置与 attention heads 共用该 α_t。

输入仍来自当前 Query 查询参考视频所得的 attention Value 特征。每个 bin 保留 8 个固定空间 probe；利用相同 Query 对参考前/后相邻 bin 的查询，形成中心时间差分 b=S_next−S_prev。将 D 分解到 b 的方向与正交补空间，按 heads、空间 probe 汇总，得到 A_t=Σ‖D_T‖²、B_t=Σ‖D_N‖²。

与 scalar anchor 相比，不增加 attention 调用、不增加 DiT 前向、不做 RGB/VAE 解码，只把已有 `[H,T,P]` 能量按 `(H,P)` 求和，保留 T。A_t/B_t 是参考特征局部时间变化的代理量，没有被定义为已测得的动作延迟。

## 2. 每 bin 因果校准与尺度规范

每层、每个 bin 分别在首个有效去噪步建立 A₀,t/B₀,t。建锚当步 α_t=0.25；之后锚点固定。令 r_T,t=A_t/A₀,t，r_N,t=B_t/B₀,t，再规范为

v_T,t=r_T,t/(r_T,t+r_N,t)，v_N,t=1−v_T,t，v_t=1/2。

因此每个有效 bin 的数据项具有相同尺度；一个动作能量更大的 bin 不会仅因绝对幅值更大而主导平滑项。A、B 同比例变化保持 v_T/v_N 不变。实现使用等价的缩放交叉乘积避免比值溢出。

没有当前证据、尚未建锚、非有限输入或总能量接近零的 bin 固定为 0.25。平滑图删除其两侧连接，避免把邻居信号传进这些 bin。已经建锚后，当前 A 或 B 单独变为零仍然可以产生有效强度变化。

有效窗口的第一个和最后一个 bin 固定为 0.25，不参与控制统计，也不与邻居建立平滑边。它们的单侧差分包含 S 自身，会造成共有项自相关；本版保持端点处理与现有 scalar anchor 一致。少于三个 bin 的窗口全部使用固定 0.25。内部缺证据处按同样规则形成独立连续段。

## 3. 严格凸目标与 λ 的含义

在有证据的连续段 Ω 上求解：

J(a)=Σ_(t∈Ω)[(1−a_t)²v_T,t+3a_t²v_N,t+μ(a_t−0.25)²/2]
     +λΣ_((t,t+1)∈E)w_t(a_t−a_(t+1))²，0≤a_t≤0.5。

首个固定配置为 μ=1、λ=0.625。等距 latent bin 的 w_t=1；若传入真实 bin 时间中心 τ，则 w_t=median(Δτ)/Δτ_t，仅由几何决定，不根据样例效果调整。

记 c_t=v_T,t+3v_N,t+μ/2，r_t=v_T,t+μ·0.25/2，则去掉常数后

J(a)=aᵀMa−2rᵀa，M=diag(c)+λL_w。

M 的主对角为 c_t 加相邻边权总和，两个副对角为 −λw_t。由于 c_t≥1+μ/2>0、L_w 半正定，M 正定；Hessian 为 2M，最小特征值至少 2+μ。每个带 box 约束的连续段都有唯一最优解。

λ 的固定取值来自平衡状态 v_T=v_N=0.5：此时 c=2.5。均匀长链、未触及 box 时，频率 ω 的强度变化被乘以 `c/(c+4λ sin²(ω/2))`。λ=c/4=0.625 使交替高频模式约减半，同时保留常量模式。它是无量纲的平滑强度，不是视频动作错位阈值。

λ=0 时退化为逐 bin anchor 的闭式解；λ→∞ 时，每个独立证据段趋向共同值 `clip(Σr_t/Σc_t,0,0.5)`。缺证据处仍保持 0.25，两个段不会互相传播统计。

## 4. 有界求解和输出意义

原型采用保持可行的 active-set：先固定触及上下界的变量，在其余连续区间用 Thomas 算法求解三对角系统；若解越界，沿当前点到自由解的方向移动到第一个边界；到达自由解后检查边界梯度并释放违反 KKT 的变量。每轮线性系统计算为 O(T)，不构造稠密 T×T 矩阵。

显式检查半梯度 g=Ma−r：自由变量 g=0，下界变量 g≥0，上界变量 g≤0。默认迭代上限 `4T+16`。到达上限或数值检查不通过时，记录未收敛并把该连续段回退到固定 0.25，不把未求解的结果计为成功。

该方案形成连续的强化和减弱区域，而非二值开关窗口。μ=1 时，有证据 bin 的最优强度下界为 1/28≈0.0357；正平滑保持该下界，最大值为 0.5。无证据 bin 继续使用基准 0.25。可在展示中用 `α_t>0.25` 的连通段标出强化区域，不增加按样例拟合的阈值。实际系数在各去噪步、各层分别变化，不预先规定视频中必须有几段窗口。

## 5. 接口、计算代价和审计

`update_gain_field(A[T],B[T],valid_count[T], state=..., step_index,layer_index,...)`
返回 `(alpha[T], next_state, diagnostics)`。当前原型明确要求 CPU 小向量；没有隐含设备传输。state 保存每 bin 的 A₀/B₀、建锚步及最近调用步，拒绝重复/倒序调用、层混用和几何/参数变更。

未来接入可在原 GPU probe 统计之后一次传出 A/B/count，并传回 α_t；T=29、50 层、20 步下，三个 FP64 统计向量总量约 0.66 MiB，α 向量约 0.22 MiB。真实开销还包括每层同步延迟，应与已运行 scalar anchor 实测配对。每层两个 anchors、有效性和建锚步的状态量为 O(T)，无需保存视频或完整 attention 矩阵。

每次记录 α_t、无平滑系数、A_t/B_t、规范比例、建锚位置/步、有效证据掩码、平滑边、各段迭代次数和 KKT 残差。修正能量应另按真实全分辨率 D_t 记录 `Σ_t α_t²‖D_t‖²`，该目标没有约束总剂量恒定。

`benchmark_cpu.py` 测 29/41 bins 各 1000 次，详见 `cpu_timing.json`；该数字只含 CPU 统计校准和求解，不含 GPU 同步、传输或 attention。

## 6. 验证与最小实验

19 项 CPU 测试覆盖：box KKT 与穷举 active-set oracle、上下界符号、迭代上限、常量恢复 0.25、逐 bin 能量尺度不变、因果建锚、端点、无信号隔断、稀疏异常平滑、λ=0 与大 λ 极限、状态保护、非均匀时间间距、保留 T 的 head/probe 归约及严格正下界。

先等当前 scalar anchor 的两组成片。若继续此候选，先保持两例原 prompt/seed/模型/几何，用该固定 μ/λ 配置；比较 Baseline、固定 0.25、scalar anchor 与 gain field。出现收益后，再增加 λ=0 消融和剂量匹配的均匀强度对照，区分“空间时间分配有效”与“总修正量变化”。本版不叠加 head 分配、跨时刻 coverage 或 layer 预算。

代理目标仍会受到早期锚点噪声、参考特征外观/运动耦合影响；逐 bin 统计样本比逐层标量更少。首批审计应同时看系数饱和、回退比例、KKT、编辑任务完成情况和固定小动作的视觉对齐。
