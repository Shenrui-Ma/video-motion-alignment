# 同位置组切向消融（边界原算子）

独立节点 `H3TemporalGainFieldRole5`，CPU已验证，尚未部署。操作与实验图说明见 [HANDOFF.md](HANDOFF.md)，冻结源码与测试证据见 [READY.json](READY.json)。

在完整±5邻域内，仅将同Q参考切向由 `S(t+1)−S(t−1)` 改为 `S(t+5)−S(t−5)`；边界沿用原±1。原端点遮罩、QP连接、先验与平滑保持不变。

**这是位置组匹配与时间跨度的联合干预。** 本批H3编码每17帧构成一个5-latent块；向前或向后5个位置bin跨过一个17帧块，因此±5的中心差分两端在参考图像帧时间轴上相隔34帧。本批24fps约为1.42秒；帧数指预处理后输入H3的参考帧，原文件如经重采样则不直接使用其原始fps换算。短邻居改成长跨度可能抵消时间不变的同位置组加性成分，也可能抹去快速转折或短脉冲。不能仅凭本消融的效果把收益归因于位置组抵消。

`FRAME_PER_TOKEN=(1,4,4,4,4)` 用于H3的位置／时间坐标映射。上述34帧是位置跨度，**不称VAE精确感受野**；编码卷积、分段处理与解码重叠另有影响范围。

三个固定去噪步×三个固定层另算±1 shadow，与实际±5共享同次Q、D、m和probe，比较只限共同内部位置。shadow拥有独立首步锚，不改变实际alpha或主状态。它增加18次小probe attention，不增加完整DiT forward、VAE或RGB处理。

审计接口：`python3 audit.py <runtime.json>`。实际生成需要主线程审核和独立运行验收；本目录的 `CPU_full_complete.json` 仅为CPU dense随机QKV的真实wrapper测试证据。
