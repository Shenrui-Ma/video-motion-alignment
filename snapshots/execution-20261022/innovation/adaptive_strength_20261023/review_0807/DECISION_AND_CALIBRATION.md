## 2. 缺的是误差方向，不只是归一化

当前统计为：

    D = m(S_t − R)
    b = S_(t+1) − S_(t−1)
    A = ||Proj_b D||²,  B = ||D − Proj_b D||²

A/B在 D→−D 或 b→−b 下不变。设真正目标残差e=(−1,0)、b=(1,0)，D=(1,0)和D=(−1,0)给出相同A=1、B=0，却使 ||e+αD||² 在α=0的导数分别为−2与+2。首步锚和预算能改变尺度，无法恢复被平方丢弃的符号。

直接新增 <D,b> 仍不够：它给出参考特征局部切向的朝向，没有观测当前画布到底早了还是晚了；镜头、背景、外观变化也会给出非零值。当前A/B里的b和D共享Q，Q改变会同时改变两者，因此“切向能量增加”也不是独立的错误观测。

另外一个需要禁止的循环定义是令 L=||R−S_t||²，再沿 D=m(S_t−R) 测收益。固定Q时 R'=R+αm(S_t−R)，于是 L'=(1−αm)²L；它必然下降是更新定义的代数性质。把这条曲线当作“短动作被修复”会让所有实验自动通过。

## 3. 唯一建议继续的候选：独立读出 e，再沿真实局部链求 s

先把它叫作**候选的内容检索相位**，通过冻结的native/weak动作事件校验后，才作为动作相位代理。

在下一层 ℓ+1 的同一前向中，取画布query q_i 和参考视频keys k_(j,r)，两者均为Q/K RMSNorm之后、当前层RoPE之前的值。i是画布位置，j是有效参考时间bin，r是预先固定的空间probe。定义：

    l_ij = logmeanexp_r(q_iᵀ k_(j,r) / sqrt(d))
    p_ij = softmax_j(l_ij)
    mu_i = Σ_j p_ij tau_j
    e_i = tau_i − mu_i

tau使用已有位置bin中心；正e表示当前画布内容更像较早参考位置，即候选的延后读数。比较不同模态时不使用packed RoPE origin。相位的首要输出是完整p、峰位置和歧义，均值e只在分布被校准为单一可辨识峰时使用。两个对称峰的均值为0不能当作已对齐。每个head/probe先保留原始读数，不按本批视频收益挑head。

该设计不等于原始QK时间质心。必须去掉**本层显式RoPE**：实际H3代码在Attention.forward内先Q/K RMSNorm，再对前96/128维做split-half旋转；可在该处被动捕获，或用同一张旋转表的转置逆转。当前层逆旋转不会消除此前网络中已混入的位置与角色信息，需由校准揭示剩余偏置。仅取32个非旋转维可作诊断，但不临时把它选为主方法。

要判断当前修正是否会降低这个e，不能把D直接加到Q。H3真实局部链是：

    z_i(a) = x_i + gate_attn ⊙ W_o(O_i + a D_i)
    h_i(a) = z_i(a) + gate_mlp ⊙ MLP(ModNorm2(z_i(a)))
    q_next,i(a) = QNorm(W_Q,next ModNorm1,next(h_i(a)))
    s_i = d e_i(q_next,i(a), K_ref,next) / da  at a=.25

当前层只改canvas，参考状态在该层输出后不受此改动，因此这一个局部next-query检验可以冻结next参考K。再往后的联合attention会让参考也受canvas影响，不能把这项局部结论外推为完整DiT导数。

固定参考K时有可独立核验的解析式：

    d mu_i/da = Σ_j p_ij (tau_j−mu_i) d l_ij/da
    d l_ij/da = Σ_r p_(r|i,j) k_(j,r)ᵀ (d q_next,i/da) / sqrt(d)
    s_i = −d mu_i/da
    G = Σ_i w_i e_i s_i

只有G<0才表明增加系数在这个**已校准的局部代理**下有一阶改善方向；G>0提示减小。若以后允许控制，在固定有效观测集合上，一维线性模型的最小二乘增量为 Δa=−Σw e s/Σw s²，再受已有[0,.5]与预定小信赖域限制。Σw s²为0、分布歧义或局部近似失败时回固定.25。当前阶段不选新的λ/μ、不上线这个公式。

这条局部链的W_o、gate、MLP、norm和下一层Q投影都是逐token运算，可在原8个空间probe上做独立JVP/有限差分；不需要额外DiT attention或VAE。实际接入仍需核验量化算子与batch形状：FP64连续CPU导数通过不意味着INT8动态量化也可微。采集/检查若需要额外线性和MLP调用，应记录真实代价，不承诺零开销。

## 4. 最小校准与明确的失败门槛

先做CPU数学与小张量oracle。它们检验可辨识性和实现契约，不代替真实语义：

1. **已知±2/±1/0 bin移位。** 非循环、仅公共有效区间；冻结位置组c_(t mod5)，只移动内容m_t：x'_t=c_(t mod5)+m_(t−δ)。同时保留旧的全向量移位作为“过于容易的对照”。不得以移动role与内容一起得到的100%准确率通过新门槛。
2. **零移与外观变化。** 保留相同动作相位，单独加静态通道/身份偏置、改变尺度；必须保持零移或明确拒绝。任意未知线性外观变换一般不可辨识，出现误报时记录适用域，不靠在同样例拟合映射强行消去。reference和canvas身份信息若主导相似度，候选失败。
3. **静态、周期、混合峰。** 静态参考不能提供相位；重复动作可有多个等价峰；对称错位峰不可凭均值报0。应输出unknown/ambiguous，不给控制系数。一个强静态背景加一个移动主体的构造须同时检验整体池化与固定局部probe，防止背景把相位压成0。
4. **角色/位置与镜头反例。** 同一内容只改显式RoPE时，逆旋转前后需给出正确差异；只改c_(t mod5)而内容不动，不能报告动作移位。镜头移动而主体静止应检验该读出究竟测到什么，先保留失败案例，不把所有时间变化称动作。
5. **方向导数oracle。** 包含W_o翻转/消除某方向、gate=0、非线性FFN、±D相同能量而相反收益；解析s与中心有限差分一致，正负方向均覆盖。用当前R→S的收缩例作为必须判为循环论证的负面设计；不能把它作为成功样例。

无退化、非周期合成例以原校准门槛为上限参考：至少90%公共有效位置的bin误差≤.5，非零移位方向正确；所有位置与拒绝率同时报告，不能只保留少量易点。静态/周期的重点是拒绝而不是准确率。先冻结构造、参数和容差，再看真实native/weak读数。

真实读出正负对照仍固定为旧饮酒0358、手帕0059，各native和weak；native分别存在9/10.5帧、16帧的冻结延后事件，weak近零。它们用于验证一个新观测是否读到了既有事实，不作为新控制器的正收益样例。要求在全部冻结事件上报告匹配与缺失，不能以原始latent全局均值0来否定已知事件。位置bin映射的时间只称等效时间差，真实逐帧事件给粗粒度校验。

**通过顺序：** 数学/反例门槛 → 被动真实Attention捕获与native/weak事件核验 → 真实局部s有限差分 → 最后才考虑预定样例控制实验。任一前置项失败，停止该候选；不通过换阈值或事后选head来绕过。

## 5. 现有缓存能做什么

现有field/fixed-budget/role5审计保存A/B、锚、alpha、能量、有效probe计数和少数shadow平方统计，没有Q/K/V、b或D向量。A/B在正负方向上不变，因而无法从这些JSON重建有符号s。旧x0捕获保存预测clean estimate和最终latent，没有直接保存采样中的x_n。旧原始latent读出已在真实native延后事件上失败，不能换个相位名称继续使用它作收益标签。

现阶段可立即做的只有：本文件的真实结果/剂量复算、代码入口审查、CPU合成可辨识性和局部链oracle。真实内容相位校准需要下一次独立只读采集；不必生成20步视频，但若用旧Euler状态递推重放，必须先对同一步旧预测x0核验，端点一致不足以证明中间状态正确。当前没有启动任何重放或GPU工作。

建议未来最小采集只固定一个层（零基25）和两个已有步（零基9、19），两个旧样例的native/weak，沿用8个空间probe、全部heads、有效参考范围。这些索引先固定，不能在结果后选表现好的层/步；若中间状态或缓存身份不能核验，先报告无法复用。采集在远端原地分析，回传小型时间分布与证据，不下载模型/大latent。不把这项诊断命名为新视频结果。
