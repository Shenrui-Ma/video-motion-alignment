# 动态强度与 Attention heads 分配：数学设计和 CPU 原型

控制器已接入独立 H3FeatureGuidance 节点，首批实验配置与校验记录位于 batch/。下文区分已实现方案和后续层分配方案。

## 1. 当前修正与旧方向门控

H3 每个 DiT block、每个 head 的原 Attention 输出记为 `O`。输出视频 query 对全部参考视频计算的条件 Attention 输出为 `R`，只对对应时间 bin 的参考 token 计算的输出为 `S`。原参考视频总概率质量为 `m = exp(LSE_ref − LSE_full)`。现有有效方法在整个去噪过程中使用：

\[
D=m(S-R),\qquad O'=O+0.25D.
\]

旧 `direction_gated` 使用原参考匹配概率的时间重心估计 offset，乘以相邻参考条件输出的有限差分作为方向，最后取 `α_eff=.25 max(cos,0)^2`。其行为有三个明确特点：

- `α_eff` 始终小于等于 `.25`；低匹配集中度、低 offset、低变化量和方向冲突都会置零。
- 每个 head/bin 的四个固定空间 probe 直接平均，缺乏动作信息的背景 probe 也以零进入平均。
- 被削掉的修正能量没有分配给其他 heads。原十组测试同时改变了 head 选择和总剂量。

原 Q/K 路由时间重心还包含 RoPE 相对坐标和外观匹配因素。新控制器直接观察参考 Value 条件输出的时间变化，不把这个重心称作动作延迟。

## 2. 参考特征时间切向量

对同一个输出 query，额外计算相邻时间 bin 的条件 Attention 输出 `S₋`、`S₊`。采用：

\[
b=S_+-S_-,\quad E=S-R,\quad E_T=b\frac{\langle b,E\rangle}{\lVert b\rVert^2},\quad E_N=E-E_T.
\]

`E_T` 是与局部参考时间变化同方向的修正，`E_N` 是其正交补。两者在默认的一阶切向量配置下正交。这里的时间变化也可能含视角、遮挡和光照变化；`E_N` 也包含动作的非线性变化，不能直接命名为“外观误差”。

内部时间 bin 的中心差分没有使用 `S` 构造切向量，降低 `E` 与切空间共享目标项造成的自相关。有效窗口首尾的单侧差分含 `S`，随机 Attention 核验发现它会把动态 α 推向上限。因此首尾 probe 仅从控制统计中排除，以质量权重 `m=0` 标记；有效统计必须满足 `m>0`。输出引导仍覆盖首尾 bin，并采用内部 bin 得出的同一层 α。窗口只有一至两个 bin、没有内部 probe 时回到固定 `.25`。邻居索引始终限制在有效窗口内，避免读取补齐帧。原型另保留两段 secant 的 ridge 投影作为可选消融；该配置为正则化分解，不宣称严格正交。

在固定空间 probe 上计算 `D_T=mE_T` 和 `D_N=mE_N`，汇总平方能量 `A=Σ||D_T||²`、`B=Σ||D_N||²`、`C=Σ||D||²`。默认每个 block、每个去噪 step 只选一个标量 α；同一 block 的所有 head/bin 使用它。这样先单独检验强度控制，再检验细粒度分配。

## 3. 动态 α：自由度归一化的正则最小二乘

一个 head 的通道数为 `d`，一阶切空间秩为 1。直接比较 `A` 与 `B` 会引入维度偏差：各向同性变化在期望上只有 `1/d` 的能量落到该切方向。先比较每个自由度的平均平方变化：

\[
V_T=A,\quad V_N=\frac{B}{d-1},\quad V=\frac{C}{d}.
\]

取固定弱引导 `α₀=.25` 为先验，`c=(1−α₀)/α₀=3`，最小化：

\[
J(\alpha)=(1-\alpha)^2 V_T+c\alpha^2V_N
+\mu(\alpha-\alpha_0)^2V,
\quad 0\le\alpha\le\alpha_{max}.
\]

第一项倾向于补偿参考时间变化方向的残差；第二项限制其余方向上的改动；第三项在证据有限时保留已验证的 `.25`。这是当前 Attention 特征中的代理目标。闭式解为：

\[
\alpha^*=\mathrm{clip}_{[0,\alpha_{max}]}
\frac{V_T+\mu\alpha_0V}{V_T+cV_N+\mu V}.
\]

首轮建议 `μ=1`、`αmax=.5`。当每个自由度的时间切向变化和其余变化相等时，`V_T=V_N=V`，闭式解严格回到 `.25`；时间切向残差异常大时增强，其他方向变化占主导时减弱。白噪声随机方向经过多 probe 汇总后接近这一先验。

静态参考、零参考质量、零修正、无有效 probe 时回退 `.25`；它们不被当作“已对齐”的证据。全局关闭用 `α_prior=α_max=0`。无穷大 `μ` 回到固定 `.25`。最终输出仍须检查有限数值；控制器提供的是系数，不替代已有的 Attention 数值保护。

原型同时保留未做自由度归一化的版本：

\[
\alpha=\mathrm{clip}\frac{A+\mu\alpha_0C}{A+\lambda B+\mu C}.
\]

当 `λ=μ=1` 时，它化为 `clip(.125+.5 A/C)`。在高维低秩条件下可能系统性减弱，适合作为归一化的消融。`λ=3` 的平衡点是 `A=B`，而不是 `A:B=1:3`。

## 4. 独立 heads 分配：固定修正能量的受约束优化

这组实验固定每层的总修正剂量，只重新分配给不同 heads。全分辨率修正能量为 `C_h=Σ||D_h||²`，probe 估计时间切向占比 `f_h=A_h/C_h_probe`。取：

\[
\max_{a_h}\sum_h C_hf_ha_h,
\quad \sum_h C_ha_h^2=\alpha_0^2\sum_h C_h,
\quad 0\le a_h\le\alpha_{max}.
\]

目标是给线性时间修正收益更大的 heads 分配更多预算。KKT 条件给出 `a_h=min(τ f_h, αmax)`。原型对排序后的饱和 head 前缀枚举，直接求 τ，无反复网络前向或迭代 GPU 求解。若高收益 heads 已全部达到上限，余量分配给剩余 heads；所有收益相同或缺少方向信息时恢复固定 `.25`。

这里守恒的是 head 拼接前、输出线性投影前的 Attention 修正 L2 能量。`W_O` 会混合 heads，因此投影后的残差能量仍应单独记录。

首轮只分配同一个 block 中的 heads。跨层分配需要本 step 尚未计算的后续层统计，不能即时全局优化。后续可用上一 step 的 50 层统计形成一 step 滞后的预算，需独立实验，不能混进首轮 heads 对照。

## 5. 接入 API 与计算量

文件：`prototype/controller.py`。

- `dynamic_strength_dof(S,R,S_prev,S_next,m, reduction='block')`：推荐动态 α 候选，返回标量和设备内 diagnostics。
- `dynamic_strength(...)`：未按自由度归一化的消融；可选 `reduction='head_bin'`，首轮不用。
- `heads_budget_strength(..., exact_head_energy=energy_H)`：独立 heads 分配，返回 `[H]` 系数；传入全分辨率 `ΣD²` 才守恒完整修正能量。
- `allocate_energy_budget(...)`：独立 KKT 分配函数，可单独验证预算。

四个特征输入形状 `[H,T,P,D]`，`m` 为 `[H,T,P]`。首批每 bin 采用八个分层空间 probe。全 Attention、全部参考 Attention 和同时间 Attention 复用现有计算，只增加前后邻居两个批量小 query Attention；控制器是 `O(H·T·P·D)` 的点积与归约。无 `.item()`、`.cpu()`、VAE、DWPose、RGB 检测或额外 DiT 前向。JSON 日志在原 forward 边界序列化。

## 6. 最小实验及记录

先用机舱、饮酒两个既有任务，保留现有原始 prompt、seed、20步、模型和完整几何：

1. 已有普通编辑和全程固定 `.25`。
2. 自由度归一化动态 α，其他结构不变。
3. 固定 `.375`，以及根据动态版日志生成的等均值或等修正能量固定强度对照。用于分开强度变化与控制依据。
4. 固定每层 `.25` 修正能量的 heads 分配，单独测，不同时启用动态 α。
5. 跨时刻覆盖与同时间弱引导融合由主线程独立配置；前三项先保持同时间修正方向。

逐 step/block 记录 α 均值/分位数、`A/B/C`、有效 probe、fallback、精确修正能量、head 系数和预算误差。记录官方可用指标、用户授权的动作偏移帧、编辑完成情况、采样/逐步耗时。若高比例层退回先验或 heads 分配几乎均匀，这是机制使用情况，需和最终效果一起呈现。

## 7. 已完成验证

CPU 回归使用 `.9` 既有 PyTorch 环境、`CUDA_VISIBLE_DEVICES=''`，未申请 GPU。控制器覆盖正交投影能量、尺度不变性、零信号/非有限 fallback、维度校准、白噪声均值、关闭/固定极限、heads 精确预算、饱和/极端 utility、随机对照目标改善；边界修复增加零质量统计排除及 `32 heads × 128 bins` 随机特征检验。Attention 集成另测冻结固定 `.25` 等价、五次调用、有效时间窗口、独立 head/time 循环，以及长序列随机 QKV 的 α。最新结果与测试代码 SHA 分别在 `prototype/test_result.json` 和 `prototype/feature_attention_test_result.json`。真实模型成片由主线程后续实验检验。

## 8. 后续层选择：前一步统计与当前步累计预算

首批的动态 α 已经随层、随采样步变化；`heads_budget` 只在每一层内部重新分配。全局层选择另设实验，不修改当前冻结节点。原因是一次 DiT forward 按顺序执行 50 层，早层执行时，后层本步的修正能量尚未出现。

设采样迭代为 `n`，层为 `l`。完成第 `n−1` 步后，保存每层的实际修正能量 `C_(n−1,l)`，以及自由度校准后的时间变化比例 `u_(n−1,l)=V_T/(V_T+V_N)`。对这些已知统计求解：

\[
\max_{a_l}\sum_l \bar C_l\bar u_la_l,
\quad\sum_l\bar C_la_l^2=\alpha_0^2\sum_l\bar C_l,
\quad 0\le a_l\le\alpha_{max}.
\]

其中 `bar C/bar u` 使用前一步数据，或在步骤结束后更新的 EMA；首次 forward 使用固定 `.25`。同样可用饱和前缀求解得到 `a_l=min(τ bar u_l, αmax)`，下一个 forward 逐层采用。该方案只有一步统计滞后，没有额外 DiT 前向，也不缓存整个网络的所有中间特征。

上式守恒的是前一步估计预算。当步 `C_(n,l)` 发生变化时，实际总能量会变化。因此第一版应分别记录预计预算、当步实际预算、与当步固定 `.25` 计算预算的比值，而不是把前一步等式写成当步等式。

若实验需要当步的严格剂量上限，可增加一个因果累计预算账户。设层执行前余额为 `r_(l−1)`，初值为 0；当前层已算出 `D` 后，其完整能量 `C_l` 已知：

\[
b_l=r_{l-1}+\alpha_0^2C_l,\qquad
\hat a_l=\min\left(a_l,\alpha_{max},\sqrt{b_l/C_l}\right),
\qquad r_l=b_l-\hat a_l^2C_l.
\]

零能量层不扣预算。由 `r_l≥0`，任意前缀和最终总量均满足：

\[
\sum_{j\le l}\hat a_j^2C_j\le\alpha_0^2\sum_{j\le l}C_j.
\]

这条约束使用当步实际修正方向，成立于当前生成轨迹的 Attention 输出、`W_O` 之前。它允许后层使用前层节省的预算；前层无法借用未来层的预算。最后一层可以在 `αmax` 内用完余额，超过上限的余额保留并报告，不能事后改写已经执行的层。该顺序偏好是明确的结构取舍，应与仅用前一步预算的版本分开测。

建议次序：先测前一步层分配，再测累计预算上限，最后才结合层内 heads 分配。控制项包括固定 `.25`、前一步统计随机打乱层序、与实际总能量匹配的固定 α。记录每层强度、余额和能量预测误差，区分“选择了合适层”与“整体引导变弱”的贡献。遇到没有完整前一步统计或非有限统计时，整步回到固定 `.25`。
