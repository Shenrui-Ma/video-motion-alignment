# 以首个有效去噪步校准动态引导强度

状态：独立离线实现及 CPU 验证完成，成片测试由主线程单独安排。原 DOF 包与正在运行的实验保持原配置。

## 动机与代理目标

真实 H3 的 attention Value 通道并非独立白噪声。已记录的机舱首层切向能量 A=315.8852、补空间能量 B=288.3035，切向占比约 52.3%。把补空间能量除以 127 的旧 DOF 规则，使强度持续达到 0.5 上限。新规则使用同一层本次推理自身的初始能量比例作为标尺，移除环境维数的各向同性假设。

沿用原全程弱引导的修正方向 D=m(S−R)：S 是同时间参考 bin 的 attention Value 聚合，R 是整个参考视频的聚合，m 是原始参考视频 attention 概率总质量。少量固定空间 probe 使用同一输出 Query 查询相邻参考 bin，得到 b=S_next−S_prev。将 D 正交分解为切向分量 D_T 和补空间分量 D_N，汇总 A=Σ‖D_T‖²、B=Σ‖D_N‖²。切向表示参考特征的局部时间变化方向；这两个分量没有被赋予纯运动/纯外观的语义标签。

有效窗口两端的 probe 不参与 A、B 估计，避免单侧差分和 S 产生共有项自相关。估计出的强度仍作用于整个有效视频窗口，包括两端。Attention 次数保持原控制器的五次：全序列、整个参考、同时间、前邻居 probe、后邻居 probe；没有额外 DiT 前向或中间视频解码。

## 因果校准和闭式解

对每层 ℓ 独立保存本次推理的第一次有效统计 A₀,B₀。该次调用 α=a₀=0.25，之后锚点固定：

- v_T=A/A₀，v_N=B/B₀，v=(v_T+v_N)/2。
- c=(1−a₀)/a₀=3，μ=1，0≤α≤0.5。
- J(α)=(1−α)²v_T+cα²v_N+μ(α−a₀)²v。
- α*=clip((v_T+μa₀v)/(v_T+cv_N+μv),0,0.5)。

第一项偏好增大对参考时间变化方向的修正；第二项限制补空间修正；第三项偏好维持基准强度。目标是在当前特征代理量之间分配修正剂量。

若 A/A₀=B/B₀，闭式解严格回到 a₀；两种能量同步缩放也保持 α 不变。切向相对增幅较大时 α 上升，补空间相对增幅较大时 α 下降。μ→∞ 回到固定 a₀；a₀=0 时关闭引导。有限有效数值域内，这些性质与通道维数无关。

实现不直接计算可能溢出的 A/A₀，而分别缩放当前与初始能量，构造 A·B₀ 与 B·A₀ 的同比例量，再除以其共同总和。该公共缩放不改变二次目标的最小点。`normalized_temporal/complement` 记录这一和为 1 的等价量。

## 状态、边界和审计

`anchor_strength_from_energies(A,B,valid_probe_count, state=..., step_index=..., layer_index=...)` 返回 `(alpha,next_state,diagnostics)`。输入为同设备浮点标量，state 不原地修改，计算没有 `.item()` 或 `.cpu()`。每层首个有效 step 建锚；无 probe、非有限能量、静态近零能量或初始任一分量不可辨识时，使用 a₀ 并等待之后有效统计。已建立锚点后，某一当前分量恰为零仍可产生有意义的增减；只有总能量接近零才回退。

`State.anchors[layer]` 仅属于单次节点执行。控制器拒绝同层重复/倒序 step、混用其他 layer 的 state 或中途变更参数。完整采样结束后，再使用同一 patched MODEL 会在 attention 计算前报错，要求创建新 run 的节点状态，防止静默变为普通编辑。50 层汇总只在一次前向完整结束时记为完成；异常原样保留为失败。

记录每层每步 α、A/B、锚点、建锚 step、归一化比例、是否使用锚点、回退原因标志、实际修正能量与计算时间。所有原有效窗口、prompt、seed、模型和几何保持不变。

## 验证与实验关系

CPU 回归覆盖纯数学目标、双向调节、尺度不变、极端能量、零值/无效值、state 隔离和顺序保护；attention 回归覆盖冻结 .25 路径精确等价、首步与固定 .25 等价、仅目标区间变化、head/time/probe 独立循环、五次 attention 和端点屏蔽；节点回归执行 50 层完整前向、跨步状态、两个独立 run 和已消费 MODEL 拒绝。

另保留旧 DOF 实际 α=0.5 轨迹的 850 层统计作为离线数值回归。新公式在这些已有 A/B 上可增可减且无触顶；这是固定旧轨迹上的反事实计算，新控制器的视频效果由独立推理评估。

首批只替换强度控制器，与原固定 α=0.25、已完成的实际 α=0.5 和固定 α=0.375 对照。该方法不与 head 重分配或跨时刻覆盖叠加。初始高噪声步可能产生不稳定锚点，固定锚点也会忽略绝对欠对齐程度；首若干步稳健聚合、后一步更新锚点属于后续消融，当前实现没有加入。
