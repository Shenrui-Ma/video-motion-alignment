缺输入或尚未完成时只写 pending 状态；身份不符或检查失败时只写 invalid 状态。完整结果在所有门槛通过后原子发布。旧历史回放失败 gate 既未修改，也无法作为新 live gate 使用。

## 交接边界

本轮仅运行合成 CPU fixture，未读取真实 Q/K、未生成真实分析、未调用 GPU 或改队列。完整 shape fixture 的媒体是合成字节身份，数值 receipt 是合成记录；它证明串联与校验行为，不是模型表现证据。

实际运行应使用新的输出目录。runner 读取已完成的视频检查与数值 oracle receipt，并复核关联文件及每 head 阈值；它不重复解码视频或执行 oracle。收到全部新输入后可在张量所在服务器以 CPU 执行 README 的入口，保留远端完整 NPZ，仅回收小 JSON/哈希记录。

`SIGNOFF.json` 包含完整资产与测试哈希。父线程负责实际输入收齐和后续语义解释；本签审不触发部署。
