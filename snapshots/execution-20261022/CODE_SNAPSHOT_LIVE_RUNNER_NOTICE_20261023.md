# Live calibration runner source snapshot

This increment preserves the CPU-only runner, its tests and frozen dependency list, plus the small live-observation audit and queue-continuation programs. Original research sources were read without modification. Host aliases, personal paths, device UUIDs and private addresses are replaced by placeholders in this source archive.

Runtime manifests, credentials, SSH settings, captures, model weights, videos and scientific result arrays are excluded. The runner dependency manifest records the original scientific file hashes. CPU verification uses generated sanitized graph fixtures and temporarily binds those fixture hashes in an isolated test directory; that temporary test binding is not a change to the archived dependency manifest or live research code. Deployments must supply their own verified runtime inputs and ownership records.

Only changed source blobs are uploaded. No old media or model assets are retransmitted.
