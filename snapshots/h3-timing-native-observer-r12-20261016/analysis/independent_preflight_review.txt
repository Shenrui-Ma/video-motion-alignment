3. SAME-STATE PREDICTIONS, COORDINATES AND CALL COUNTS
- PredictionProbe validates the official guider, seed and the same model_options object. It snapshots sigma with an explicit CPU copy, preventing aliasing on CPU. It records the complete packed x signature before either branch.
- Before/after each evaluation it checks x, timestep, original+processed conditioning and full PDD grid; CPU/current-CUDA RNG is compared without rewinding it. A detected mutation fails the job. Both branches use the same executor and processed conditions; there is no latent optimization/update between them.
- authorize/finish_forward require one complete 50-block evaluation per branch. Native routes0 blocks; Full routes50. A Full branch is impossible without a current native decision authorizing it.
- Only the chosen output is returned to the original sampler. The original sample_euler performs its single update; record forwards the original callback exactly once. Callback x is verified against the pre-update transaction input, and callback x0 against the chosen endpoint.
- Final totals require20 callbacks,20+K model evaluations and50K routed blocks, with K equal to actual Full selections. K is not hard-coded to9 or29 total NFE. The last physical index19 can trigger and is costed.
- Endpoint archives use detached CPU copies; video normalization is identity, audio is divided by4. Returned model output is untouched. Input archives at indices6/10/14 are complete raw packed FP32 x with the complete grid, seed and condition/reference signatures; final raw sampler video/audio are also saved.
- These raw input files reconstruct the sampler tensor state, not a standalone model/conditioning environment. Replaying them also requires the pinned model/core and regenerating conditions with matching signatures. The archive does not store every conditioning tensor as a portable independent checkpoint.
