Exact policy
Every physical step first computes native on the actual current noisy state.
Indices0..5 always return native. Index5 observer is archived passively; it cannot
initialize a pending choice. Initial previous actual Full choice is False.
At indices6..19 inclusive, accepted current-native lag>=4 appends Full on exactly
the same x/sigma/seed/conditions/full PDD grid and returns Full. Accepted[-2,2],
accepted<=-3,orunknown return native. Lag3 retains the preceding physical step's
actual selected branch. Full's observer result is archived but never selects.
Native means the original H3 reference-conditioned model with only our Full off.
It is evaluated on history-dependent states, not on an untouched native trajectory.
