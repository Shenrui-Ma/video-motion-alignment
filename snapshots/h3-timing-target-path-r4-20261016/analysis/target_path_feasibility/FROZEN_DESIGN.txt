M 门失败后的一个计算结构：把同帧参考修正投影到目标自身的时间轨迹
2026-10-16。独立设计与原文核验；本文件没有实现/部署算子，没有读取新的目标特征，没有启动 GPU。

1. 建议与证据边界

保留一项：同一次 forward 中，先计算原生目标输出 Y，以及 full same-bin 会产生的候选输出 C；C 只提出“这一刻应该更接近什么特征”，最终写回值从目标自己的相邻时刻 Y 中读取。多个目标时刻共同选择一个有界、单调、有端点约束的时间映射。先检验 C 是否能由这条目标轨迹近似，再决定是否生成视频。

这条路径不依赖已经失败的跨外观 M，不用变化量峰值、signed latent derivative 或其 runner-up margin 估计动作时钟。它利用已有效的 full 分支作为候选提议，同时检验：能否减少直接写入参考特征引起的肢体重影/外观代价。它只能搬动目标中已经存在的特征状态；不能补出目标路径里不存在的姿态。当前尚无证据证明早期目标特征已包含正确动作。

值得做的下一 GPU 工作至多是一次同机 native 的被动 C/Y 观测，不是直接把新模块铺到全部采样。如果以下离线门拒绝这个前提，就不启动它的生成试验。现有 R/Y 足以检查形状、常量退化和候选时间范围，不能回答最关键的 C 可表示性；因此本文没有再跑一套只会得到 unknown 的 R/Y 指标。

最新实测由 root 提供，替代旧候选报告中的 pending：
— R2 .41 的 N/F/D/S 主窗 .3 阈值 lag 为 14/2/12/14；.5 为 14/2/unknown/14。动态去静态不是此次 full 修复的充分条件，静态单支也不充分；这不是已经证明某种非线性协同，因为两臂的后续采样轨迹不同。
— R3 .9 A100 的 DC 已得到 +1/+1，与该机 full +1 同效，native +13。故不能把 .41 的 DC 失败推广成“动态分支普遍无效”。两运行环境权重/core对齐，但 .41 CUDA INT8、.9 Triton INT8及Torch版本不同；这是跨runtime敏感，尚未隔离硬件、量化或attention核。SP结果仍待定。
— native被动probe中DC的effective L1约2.31/2.36/2.39，negative mass约.66/.68/.69；SP的读出系数非负。对固定attention、仅V受有界扰动时，L1可给局部最坏情况放大界；不能据此证明完整DiT稳定性或量化是因果。
— full 主窗改善，但 frame55 有肢体重影，尾段误差约 .156→.175。只对齐时刻不能代表完整成功。
— M call6 高变化 val NMSE 5.742，I/D/A 为 1.256/.975/1.125；post M 10.557，I/D/A 为 1.451/1.002/1.116；0/4 头支持，共同支持不足80%。冻结 M 门失败，不能再换阈值把它称成功。
— 变化量 observer 曾在主窗给出正确方向，也在第三窗给错位且 margin 更大；signed derivative 出现 ±17 帧的错误答案，17 又与 chunk 周期重合。没有可用的自动 phase sensor。

这些事实不否定整个研究。它们要求新模块直接面对“full 有效但有质量代价”，并让不可用的轨迹明确拒判。

2. 只保留这个结构，不再保留累计变化量时钟方案

原先考虑过“累积特征弧长→匹配参考进度→重定时”。定向核验发现直接近邻 SPF/ReTime，且本轮 observer 反例已表明局部变化曲线未必对应动作时刻。此处不把它作为第二候选。

本方案的源到目标关系是 C 提议、Y 提供最终值；不将 R=X_ref 直接当作 C，也不拟合 R→Y。C 与 Y 位于同一块、同一 native forward 的 post-SDPA/pre-W_O 输出坐标，包含相同的原生目标分量。这并不使 C 自动成为正确目标标签；它只是当前已知有效干预的一次局部反事实。

source05 的首轮假设必须写清楚：固定机位、单个主要人物、相同输出画布几何；候选只沿同一空间地址的目标时间路径查找，先用一个共享时间映射。相同空间地址不等于同一人体部位。运动相机、人物大幅平移、多主体异步动作或不同身体部位需要不同时间映射时，本版本可能不适用；不能省略空间对应后声称适用所有动作编辑。

3. 具体输入、方程与插入位置

3.1 同一次 forward 的候选提议

对实际 H3 block b、sampler call k、head h、目标时间 bin t、空间 token s，记：
  Y_{t,s,h}=O_native(t,s,h)，即 post-SDPA/pre-W_O。
  z_ref=softmax(Q K_ref^T / sqrt(d)) V_ref，条件于参考视频组内部归一化。
  z_same=softmax(Q K_ref,t^T / sqrt(d)) V_ref,t。
  m_ref=原生目标 query 分给参考视频组的总 attention mass。
  C_{t,s,h}=Y_{t,s,h}+m_ref(t,s,h)[z_same−z_ref]。

C 必须按已冻结 full 实现的真实 dtype、归一化、写回次序构造；上式是其数学定义，不允许用另一个 FP32 近似核生成 C 后称为实际 BF16 full。保存处均在 W_O 之前，不能拿 V、reference 输出 R、x0 或另一条已被干预过的采样轨迹来替代。

C 只需在事件 E={14,...,19} 保存。候选查找/连接窗口固定 W={10,...,25}；窗口端点是本轮既有事件前后的缓冲范围，不据新视频效果移动。用于核验的物理时间来自实际 position-bin 表；不是每 bin 统一乘4。

3.2 目标轨迹与相邻时刻的共同约束

定义离散时间映射 π:W→W。固定集合 F：
  π(10)=10，π(25)=25；
  |π(t)−t|≤4；
  π(t+1)−π(t)∈{0,1,2}。

这是非递减 bin 映射，不是严格递增的连续物理时间映射。0 会重复一个特征状态，2 会跳过一个状态；必须报告重复/跳过，不能称天然平滑。不同 bin 的物理间隔不一样，“最多跳2”不是固定2倍物理速度。

令 P_t=C_t（t∈E），P_t=Y_t（t∈W\E）。选择
  π*=argmin_{π∈F} Σ_{t∈W} Σ_{h∈H_fit,s∈S_fit} ||Y_{π(t),s,h}−P_{t,s,h}||² / ν_h。
  ν_h=mean_{t∈W,s∈S_fit,c}(Y_{t,s,h,c}−mean_{u∈W}Y_{u,s,h,c})²。

ν_h 只平衡头的数值尺度，不对特征做 motion 去均值，也不是从源到目标的映射。ν_h=0/非有限时拒绝；不靠增大 epsilon 继续计算。所有近似相等的成本按预登记规则选离 identity 更近者，再按路径字典序确定，避免任意跳时。

这个问题可在16×16的小格上做动态规划；不用 N² attention、不训练、不新建视觉模型。每个 t 的选择受邻时刻 π(t±1)、端点和窗外保持成本共同约束。它不是每个 query 各自最近邻后再把不单调部分“修一下”。

写回候选：
  Y_new(t,s,h)=Y_{π*(t),s,h}，t∈W；窗口外保持原生。
首次机制验证让同一个 π 作用于该块全部空间/全部头，避免逐头/逐像素重定时破坏同帧组成。估计 π 的固定四头/固定输入区域不意味着已验证其他52头。实际实施需要同层控制验证这一推广；如果不成立，应拒绝当前共享映射，而不是从效果挑头。

π=identity 时必须绕过写回，精确返回原对象。先用 clone/gather 生成副本，禁止顺序原地覆盖导致后面的 t 读取已改 Y。参考、文本、身份图、音频行本次不改；后续网络当然受目标变化影响。映射整数读取没有插值混色，但也没有视频质量保证。还须区分：C的构造只改reference分支，最终Y重读却替换目标query的整个attention输出，其中文本、音频、target self等贡献也随之改变；它不再具有reference-only交互隔离。外层residual仍来自原时刻，二者是否兼容必须实测，不能将时间索引搬运等同于移动了一个已解码姿态。

首个被动观测位置固定 zero-based block25，calls6/10/14；call6 是主门，10/14 是诊断，不能用晚期成功替换早期失败。原有 all-layer full 的有效性不代表 block25 单块 full 已有效，后面的生成实验必须使用相同插入范围作对照。

3.3 实际覆盖范围与边界代价

已核对 source05 实际 position-bin 表：t=14..19 的 π(t)=t+4 对应物理位移分别为13、14.5、14.5、13、13、13帧。它覆盖当前约14帧延后的粗尺度，不提供亚帧或精确14帧修复能力。

一条可行路径（t=10..25）为：
  [10,12,14,16,18,19,20,21,22,23,23,23,23,23,24,25]。
这说明正向读取范围在几何上可行，也暴露了代价：为了在事件内提前动作，前段已变快、后段出现重复。不能同时要求事件内整体+4bins、在t13/t20立即恢复identity、又保持单调。故只保存 C 的六个事件 bins 足够提出约束，但必须保存/计分 Y 的缓冲窗口，不能只展示事件内部。

4. 可用现有 R/Y 做什么，以及明确不做什么

现有 R3 保存是四头全时空 R/Y，component_probe.py 返回 full/static/dynamic/SP 的 RMS、cosine 等 scalar；源码没有保留 C 向量。因此：
— 能核对42×23×41×128布局、非有限、完全常量退化、位置范围是否覆盖上述位移。
— 能在 Y 上造已知移位/恒定序列测试 DP 的实现，但这只测算法，不证明早期正确动作存在。
— 不能求真实 ||Y_u−C_t||，不能算候选可表示性、被移除残差或真实路径方向。
— R/Y 的最佳相似时间不是 C/Y 的最佳时间；替换后会重新引入已失败 M 所面对的外观与对应混淆。
— 最终成片中存在某个姿态，也不能证明 call6 的 Y 含有可搬动的对应特征。

本轮不再做一套 R/Y 正向指标。除了极端退化，它们不能减少是否保存 C 的决策。真正有决策力的是下面这个一次被动观测后的拒绝门；不需要为了得到它运行带新干预的视频。

5. 最小 C/Y 观测规格：同机、同 forward，不能拼接异机特征

C：block25，calls[6,10,14]，heads[0,14,28,42]，event bins14..19，全部23×41空间，128维。
每点2,896,896元素；原生BF16为5,793,792 bytes，若真实算子输出FP32则11,587,584 bytes。不得先用FP32近似再转BF16冒充实际C。

Y：同一 native forward 的同四头、全部42bins×23×41×128；BF16每点40,556,544 bytes。已有 .9 Y 只有在本次相同张量逐元素相等且布局/条件都一致时才可复用；.41被动C不能凭相同seed直接与.9 Y配对。最稳妥是在.41同时保存Y，不需要再保存R。

同点 C+Y BF16共46,350,336 bytes=44.203125MiB，三点约132.61MiB。可额外保存六个bin的 m_ref scalar和原生/full分支误差核验，但它们不能替代C。

必须注明：这是从 native Q/K/V 计算的“一次 counterfactual full 提议”，不是 full arm 在此前干预后形成的特征。额外计算局部分支有实际kernel/同步成本，NFE仍按原生forward计；不要写零开销。不得为了probe调用模型第二次或改变RNG。

若复用生产full函数会写原tensor，先克隆输出并只在副本上计算；如独立重算选定heads导致kernel选择/数值不同，应记录为近似并核对误差，不宣称exact。优先沿已验真实函数、取其被动副本，头截取只发生在保存时。

metadata包括实际call/block、video/audio timestep、layout/frame_rows、时间表、条件/噪声/代码/backend/hash、C构造路径和dtype、原生Y与保存是否同forward。被动capture前后native输出一致门仍成立。不得因这是文献候选而绕过现有资源admission、进程精确清理或冻结队列。

6. 冻结离线门：检测结构可行性，不冒充动作正确性

6.1 不看目标选区域/头

沿用 native_feature_capture_protocol.txt 已冻结的 source-only 高变化23个3×3 tiles及其hash。按(y,x)字典序排序，序号0,2,...,22的12个tile用于fit，序号1,3,...,21的11个用于held-out。使用各tile的9个空间位置，不临时画新ROI。
H_fit=[0,28]；H_hold=[14,42]。先以fit求π，held-out两头/空间只评价，不反过来选path。若最终改用四头合求π，须把这与冻结检验的π分开报告；不能用更好结果替换门。

native_feature协议已有来源RGB分组，应复用其已验证hash。若当前run输入几何不一致，重新只根据实际source生成并冻结分组后才加载target。这个分组表示输入变化，仍可能混有背景/光照，不称真实关节mask。

6.2 主门与两个必要的拒绝量

在call6，以冻结π分别计算held-out头上的：
  E0_h=Σ_{t∈E,s∈S_hold} ||C_t−Y_t||²/ν_h；
  Epath_h=Σ_{t∈E,s∈S_hold} ||C_t−Y_{π(t)}||²/ν_h；
  B_h=Σ_{t∈W\E,s∈S_hold} ||Y_{π(t)}−Y_t||²/ν_h。
ν_h对held-out头按同一W、同一fit空间的Y定义，不能用C或效果改尺度。

决策门预先固定为：两held-out头的E0有限且非零，二者(Epath+B)<E0；先合并两头分子/分母得到 1−Σ(Epath+B)/ΣE0≥25%；事件中读取的物理时间位移中位数>0且至少4帧。25%是节省下一轮GPU的工程门，不是显著性或正确动作证明；不因未过门而改head/ROI/窗口/阈值。若C−Y近机器精度，报告提议太小而不是除以很小E0取得高百分比。

B把缓冲区变化当成本。只降低event误差而把变化推出窗口不能过门。该门用的是feature proposal fidelity，绝不是pose lag终点；它最多说明full的部分方向能由已有目标时间状态实现。

同时报告两个不可略去的比较：
(a) event每个query独立选u的最近邻下界 Efree。若Efree/E0>0.75，即使不付边界成本也不可能满足25%门，直接拒绝本候选，不能称需要更大gain。它表示本读出范围/度量下的提议不可充分表示，不证明正确姿态绝对不存在。
(b) identity与普通固定+4bins读取（后者只作event表征成本，不假装满足端点）。若π近似总是+4且与它误差相同，就没有数据证明“提议自适应”必要；下一生成若要做，只能作为oracle固定重定时基线或补充校准，不先称自动模块。

6.3 不能只靠峰值margin的负对照

必须加入同一实际张量的两个预登记反例：
— 静态扰动提议：b_s,h=mean_{t∈E}(C_t−Y_t)，C_null(t)=Y_t+b。它保留本次候选的时间常量偏移，但不要求改动作时刻。若它也通过同一个主门并给出≥4帧中位提前，本机制不能区分静态条件偏移与所需重定时，拒绝当前版本。这个反例不等同R2 static arm，不能混称真实static复现。
— 反序提议：C_reverse(t)=C_{33−t}, t∈E。用原same-time目标路径和同一个DP/主门。若反序也稳定通过，说明当前特征/约束没有提供顺序特异性，不能把正例cost下降当时序证据。它是人工负控，不是另一个真实生成结果。

重复动作、时间常量路径、错误方向但特征近似的状态可能骗过所有这些检验。若有这种实际反例，报告unknown/拒绝，而不是增加margin阈值强行宣布可信。共同头/空间泛化是最低条件，不是充分的语义置信度。

call10/14原样报告。仅晚期可表示意味着尚未通过早期实施条件；不能用它覆盖call6失败。若call6刚好满足feature门，仍不能证明正确动作已存在；接下来才是必要的生成否证。

7. 若门通过，最小生成实验怎样避免“只是更弱的full”

可检验的窄假说是：某一已知full修复事件的有效提议，包含能由目标当前时间路径表达的分量；以单调共享读取落实这部分，可保留时间修复并减少直接写入参考特征的副作用。无需先宣布这是全新数学，已有模块的组合也可以形成有用方法，前提是实际新增约束有可测作用。

首次建议把新增path投影限定在block25、calls6..14，其他块/其他交互遵从一个明确固定底座。可采用已有效all-layer full作底座，只在block25以target-path读出替代该块的full写回；则必须承认其余49块仍会注入参考值，不能宣称完全消除了参考外观污染。选择这个底座是为了先测是否能降低已知质量代价，不把single-block不足误判为path原理失败。另一种全single-block方案需要额外验证single-block full本身有效；两种设计不得混着比较。

这一路线的最少必要性组：
(i)相同底座full；
(ii)仅block25使用上述joint path；
(iii)相同位置独立NN读取，删掉单调/端点共同约束；
(iv)相同位置把full残差缩到与(ii)实际写回RMS相同，排除只是减弱干预。
原生可复用严格匹配样例。RMS等幅版本属于对照，须预先固定计算规则，不围绕视频结果扫gain。若算力只够第一对，先跑(i)/(ii)，但只能报告个例效果，不能声称共同约束必要。

生成成功要求：主窗lag的修复基本保留，覆盖/幅度/形状不降，frame55重影和尾段代价至少有一项按冻结指标改善；同步检查W两侧和本来正确窗口。只把lag变小而新造停顿、重复姿态、背景跳变不算成功。旧full的异常部位不能被新展示裁掉。

若(ii)与(iv)相同，当前证据支持减弱full而非新增路径必要性；若(ii)与(iii)相同，不否定target-valued读出有实用性，但不能声称joint约束贡献；若固定+4bins同样好，应保留它为强基线，不把自适应成本合理化。若只有发现例成功，先在已冻结第二seed/第二片段及正常例检验；不把4头/单层结果推广到全部H3。

9. 能形成什么贡献，什么结果应立即转向

潜在的方法贡献是训练自由的“reference提议、target值实现”的受限读出，在已证明强full有质量代价的条件下，保持动作时序且改善编辑保持；共同时间约束是否必要由(i)–(iv)区分。不是差分、减均值、DP、token传播或attention可改写性本身。

新出现的跨runtime差异也可成为独立可验证的贡献线索：若相同输入/权重下非负读出约束确能降低可控数值扰动引起的动作偏差，稳定性与效率可和动作评测组合。但当前DC在.9有效、.41弱效，SP未完成，不能预支这种结论。对输入V的局部L1界也不能代替对量化、Q/K变化及后续采样的因果控制。它作为现有SP/DC队列的解释问题保留，本文没有另起第二套结构。

可以互补的证据包括：明确区分lag、形状/幅度与可见性失败的短事件评测；报告正常例、失败频率、区间外成本和拒判；与开源邻近方法在同骨干可实施范围做对照；测真实耗时/内存/NFE，展示一次forward内方案是否降低反复解码/重生成成本。新的评测或效率证据可以与方法共同构成贡献，不要求每个数学原语都从零发明。当前没有这些完成结果，不能预先记为贡献。

立即拒绝或降级当前候选的情况：
— C连独立NN下界都不能被Y路径表示：目标尚无可用状态，重定时不是合适执行器。
— 只有late checkpoint可表示：没有通过拟用早期执行窗口的前提。
— 静态/反序反例也给出同样强的提前响应：不能把拟合当可靠motion地址。
— 约束路径只能靠大段重复、窗口外大改来拟合：可能只是用其他动作填空，不值得带着主动作正确的故事继续。
— 生成后仅更弱full同效：保留实用基线，不声称新增结构必要。
— 来源camera/身体部位异步导致共享映射失败：拒绝当前固定空间、一条时间路径的假设；不能立刻叠光流、M、多个阈值再把整个组合叫本轮成功。

本轮建议：冻结以上门，保存同forward实际C/Y后做一次离线判别。它是一次有明确退出条件的结构前提验证；若失败，就转向full提议本身的内容/空间选择机制，而非继续扫time offset或用失败的clock启动闭环。研究继续，当前候选的可用性和创新贡献都由后续证据决定。
