# 固定轨迹 20 步去均值资格重放

原 Controller 的 20 步输出逐字段与实际记录相同，原 ON（0-based）为 `[1,3,4,10,14,17,18]`。仅加入 `demeaned-relative-gain > 0.5` 资格后，ON 为 `[1,3,4]`：三个主动作触发保留，四个早段静态窗触发被过滤，没有新增 ON。主动作三步的最终选中候选与原记录相同。

在所有步累计 236 个原合格候选中，195 个通过、41 个被过滤。此处计数单位是“步 × 窗口 × 描述符”，不是独立样本。每个候选的原增益均由原 pose 重算精确复现（最大误差 0）。

使用现有 helper 的逐比较共同支持：每一项 proposal 与一个 null lag（−2…2）比较时共用可见帧/骨段和置信度权重；不同 null 比较之间可以有不同支持。两个置信阈值 0.3/0.5 的所有比较均须满足增益严格大于 0.5。原绝对增益排序、连通分组和持续性规则未修改。没有计算全 null 共享支持变体，没有寻找新阈值。

这是已有 R133 0…8、R138 9…19 普通预测轨迹上的后验诊断。取消早期或后期干预会改变后续生成状态，因此结果不能当作修改控制器后的真实闭环运行或最终质量保证。

单次远端 CPU 用时 23.41 秒，返回 JSON 119,719 字节；无 GPU、新 pose 提取、视频渲染或 pose/observer 大文件回传。所有新增本地文件仅在本目录。
