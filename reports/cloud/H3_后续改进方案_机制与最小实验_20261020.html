动作时间对齐：下一步改进方案

在已有效果的时序引导上，进一步改善动作对齐与编辑质量，并把引导选择变成轻量的模型内部计算。

本文件保留2026年10月20日的方案讨论。第4节已按2026年10月23日的实现与实验更新；架构图中的矩阵与曲线为机制示意。

当前算子参考特征保护选择修正位置时间覆盖RoPE 频带建议顺序

1　当前方法与本轮验证

H3 的主 DiT block 对文本、参考图、参考视频、输出音视频 token 做联合 Self-Attention。我们的修改位于 optimized_attention 返回的各 head 输出与 out_proj 之间，作用于输出视频 query 读取参考视频 keys/values这一部分。

A = softmax(QKᵀ / √d)
mᵢ = Σj∈参考视频 Aᵢⱼ
o′ᵢ = oᵢ + αmᵢ(μsame − μref)

mᵢ 是当前 query/head 在原始 softmax 中分给参考视频全部 keys 的概率之和。μref 是这些 keys 对应的归一化 Value 加权和；μsame 只在对应物理时刻的参考视频 token 内重新计算 Attention。修改后经 out_proj、AdaLN 的 gate_msa 加入 residual stream，再执行后续 FFN 和 DiT 层。

这轮新增版本在计算 μsame 时，对输出 query 的副本补偿参考与输出的时间坐标原点差。设 Δ = 输出原点 − 参考原点：

q̃ = Rtime(−Δ)q
o′ᵢ = oᵢ + αmᵢ[Attn(q̃ᵢ, Kref,same, Vref,same) − μref]

原始联合 Attention 和用于求 mᵢ、μref 的 Q/K 保留原相位。这一组合回答：在已有同时间引导上，参考分支的相位补偿是否带来额外收益。Δ 来自 token 坐标布局，动作延后帧数另由成片测量。

DIAL 的推理模块依据主体空间 Attention 图，在视频 query 到人物参考 keys 的 logits 上增加偏置，调节参考主体的影响。当前方法保持参考视频组的总概率，并把组内概率集中到同物理时刻；本轮相位实验进一步修改辅助 query 的时间旋转。

机舱、饮酒、书本和手帕使用各自历史配置的有效视频区间；Sam 真人书记舞保留历史第 50–65 帧窗口。五组均沿用第 7–15 次去噪前向及全部 50 个主 DiT block 的固定引导。每组保留原提示词、种子和实际缓存条件，四列为参考、普通编辑、时序引导、时序引导＋相位对齐。

2　参考特征保护：组合两个方向的 Attention 修改

优先补一个成本较低、能直接解释副作用的实验：输出视频读取同一时刻的参考，同时限制参考视频在深层读回生成中的视频状态。

机制

联合 Attention 中，输出视频能读取参考视频，参考视频也能读取输出视频。虽然输入参考 latent 固定，参考 token 的 hidden states 会随着 DiT 深度变化。因此下一层使用的参考 K/V 已经包含上一层的交互结果。我们的假设是：错误的生成姿态可能经反向读取进入参考特征，削弱正向引导，或增加重影。

o′T = oT + mR(μsame − μref)
o′R = Attn(QR, K除输出视频外, V除输出视频外)

第二式对剩余 keys 重新做 softmax。两个修改分别写入输出视频行和参考视频行；同一层的 Q/K/V 已经生成，所以参考行的修改从后续层开始影响输出。文本、人物参考图与音频仍按原定义参与。首轮沿用已有视频窗口和采样区间，以便直接比较。

也可复用原 Attention 的组分解来实现这一限制。对参考 query，令 mT 为它分给输出视频 keys 的总概率，μT 为该组归一化 Value 均值，则：

o′R = (oR − mTμT) / (1 − mT)

这与排除输出视频 keys 后重新归一化等价，可复用原联合 Attention 输出及一个参考到输出的子 Attention。若 1−mT 很小，直接计算剩余 keys 的 Attention 更稳定。这里的分解是实现选择，组合实验检验的是两条方向修改后的成片效果。

已有依据与最小实验

此前 Sam 书记舞的同条件评审中，第 50–65 帧窗口的手臂方向匹配时差：普通编辑为 13 帧，正向同时间引导为 1 帧，单独限制反向读取为 8 帧。三条实际成片来自 R3 普通编辑、R3 正向引导与 R25 反向限制；种子、实际条件和噪声已核对。正向方法已接近对齐，组合实验主要看是否进一步减少重影、保持身份和背景。

四种设置为普通编辑、仅正向引导、仅反向限制、二者组合。对同一种误差量 E 可计算组合交互 E组合−E正向−E反向+E普通；时间误差与画面质量分别报告。先用一个已有重影的有效样本和一个有效编辑样本，再复测另一种动作。

与已有工作的关系

OmniTransfer, Identity as Presence, FullDiT2 已采用非对称的参考交互；Vidu S2 已研究对应帧交互。这里借鉴它们的结构原则，研究冻结 H3 中两条边的组合效果。可形成的贡献在于：是否找到使动作时序恢复且减少编辑损伤的具体机制与适用条件。

风险集中在参考适应性：阻断反向交互也可能让参考特征更难适配新的角色或场景。原 Attention 的额外计算量会增加，成片耗时与质量一起记录。

3　按修正方向选择 Attention heads、层和强度

这是更适合继续发展为算法的方向：在本次前向内，估计“把这个 head 的时序修正加进去，会使局部运动差异变大还是变小”，再选择写入位置与强度。

从 Attention 权重到实际特征改变量

同样的 Attention 变化，经过不同 head 的 Value、输出投影和 AdaLN gate 后，对模型状态的作用不同。我们先计算少量 sampled queries 上的原时序修正，再把它投影到 residual stream：

δoℓh = mℓh(μsame − μref)
rℓh = gateℓ ⊙ WOℓh δoℓh

rℓh 是固定当前 Q/K/V 时，该层该 head 的修正经过 out_proj 与 gate 后产生的局部增量。原 Attention 和 FFN 继续正常执行，选择开关只控制额外时序修正。

固定测量位置与坐标

令 YT、YR 为本层原 Attention 经输出投影与 gate 加入 residual stream 后、进入 FFN 前的输出视频和参考视频特征。rℓh 就在这个坐标空间内。每层使用当前状态分别判断，同层选中的 heads 合并写入。

先验证一个轻量的局部误差

用固定的共享线性投影 P 测量两侧特征。W 是整个局部时间窗口内固定的空间对应；参考特征先按物理时间重采样到输出时间轴。D 在固定空间网格计算相邻时刻的特征差，除以实际时间间隔：

HT = P(YT),　HR = W P(YR)
e = [ √λ₀(HT−HR) ; √λ₁D(HT−HR) ]

第一项比较同一物理时刻的状态，第二项比较局部时间变化。状态项提供时间相位锚点：仅比较速度时，恒速段的固定延后可能被漏掉。采用固定网格差分，是因为稳定纹理沿自身运动轨迹的特征可以始终不变，沿轨迹求导会把运动消去。

跨角色替换时，身份、比例、纹理也会进入这个误差；参考与输出 token 的噪声水平和条件 timestep 也不同。首先用保存的中间特征、已知时间偏移和已对齐样本，分别检查各去噪阶段的响应。共享投影、空间匹配、两项尺度与可信范围依据这一步确定，使自动判断主要响应动作偏离。

选择 head，并计算引导强度

在本次计算中固定参考状态，对每个 head 的修正使用同一个投影和误差定义：

gℓh = [ √λ₀P(rℓh) ; √λ₁D P(rℓh) ]
sℓh = −⟨e, gℓh⟩

选择空间匹配可靠、且 s>0 的 heads。将同层的修正合并为 r=Σrℓh、g=Σgℓh，计算：

Elocal(α) = ½ ‖e + αg‖²
α* = clip( −⟨e, g⟩ / ‖g‖², 0, 1 )

当 P、W、D、可信区域和误差权重在当前计算中固定时，上式精确最小化这一局部二次目标。分母为零则 α=0。每层、每次前向重新判断施加或跳过修正。首轮将 α 限制在 0–1，使操作保持为参考组内部概率重分配。

若与参考反向限制组合，先将已经确定的反向限制计入参考状态，再固定它选择正向修正；若两侧一起优化，误差增量应使用 δH=P(rT)−WP(rR)。当前层的 Q/K/V 在写入修正之前已经生成，参考状态的变化经后续层传播。

进一步直接测量局部位移

更直接的一版，可以从同一 residual 测量点构造局部 Q/K 匹配，得到相邻帧的 soft matching 位移。设候选位移为 dⱼ，匹配 logits 为 aⱼ：

p = softmax(a),　u = Σⱼpⱼdⱼ
δu = Σⱼpⱼ(dⱼ−u) δaⱼ

用位移差和同时间状态锚点定义误差，再用 Jacobian 计算修正方向。此时 α* 最小化线性化二次模型；可在少量 sampled queries 上重算局部误差，最多回退两次强度。局部匹配读出从修正所在的 Y 构造，原层已有 Q/K 只提供候选与置信度。

两版都将计算放在模型内部特征上，使用局部投影、匹配和小向量运算。核心验证是这个观测量能否预测最终动作时差，以及额外计算是否足够小。

与已有工作的关系

HALO、Why Do Video Diffusion Models Violate Physics? 已研究运动/结构 heads、按 Attention 熵选择 heads 和因果消融；RefGAP 根据参考组概率在线调整权重，作用层由预先分析选定；EG-Sparse 已动态分配跨 head 稀疏预算。我们的具体候选是用当前时序修正经过投影与 gate 后的增量，以及它相对于局部运动残差的方向来选择干预。闭式最小二乘属于已有数学工具，贡献需要来自这一观测与执行机制的实际效果。

最小实验

比较全 head 引导、同数量随机 heads、熵/运动可靠性选择、上述方向选择。保持候选层、采样区间一致，另做修正范数匹配，区分位置选择与单纯减弱引导。优先复测一条“时序改善但有重影”的样本和一条“身份受到干预影响”的样本。随后检查正常样本能否保持低干预。

额外计算发生在少量 Q/K 对应、sampled queries 的投影和小向量运算中。单次局部误差下降的推导依赖冻结对应，最终视觉效果由成片检验。该候选训练成本为零；实际运行开销需在同一条推理中计时。

4　跨时刻参考覆盖：共同分配相邻参考时间片

同时间弱引导让生成时间片 T₃ 读取参考时间片 R₃。跨时刻参考覆盖允许 T₃ 同时读取相邻的 R₁…R₅，并让所有生成时间片一起决定这些参考片段各被使用多少。

目的是在保持时间对应的基础上，为每个生成时刻补充相邻动作阶段的信息。两种方法都在全部20步去噪中使用 α＝0.25；差别在参考时间片的分配方式。视频时间片用 T / R 表示，去噪步是模型逐次生成视频的计算过程。

4.2　联合分配怎样约束时间

每个生成 bin 的候选范围是对应参考 bin 的前后各2个。模型先计算匹配分数，再求一个分配矩阵 P：每行总和为1，使该生成 bin 得到完整的参考混合；每列总和为1，约束各参考 bin 在整段视频中的累计分配。离对应时刻越远，分配代价越大。若匹配时刻的期望顺序发生反转，再将 P 向同时间分配收缩。

这里的列约束作用于时间分配矩阵 P。每个 Query / head 的总参考概率 mᵢ 仍来自原 Attention。P 在每个去噪步、每个 DiT block 重新计算；本层生成视频的各 head 和空间 Query 共用这一时间分配。

展开数学定义与实际计算

从本层生成视频 Q 中采样最多4个 heads、每个时间片8个空间位置，与参考视频 K 计算匹配。对参考 bin 内所有空间 keys 汇总 softmax 概率，再对采样位置和 heads 平均，得到 C[t,j]。

minP≥0 Σt,j Pt,j [−log Ct,j + 0.25(t−j)²] + 0.5 Σt,j Pt,j log Pt,j
ΣjPt,j = 1，ΣtPt,j = 1，Pt,j = 0 当 |t−j| > 2

实现用 CPU float64 的阻尼 Newton 求解这个小矩阵，再检查期望参考时间是否按生成时间递增。求解失败时，使用同时间弱引导。随后在 GPU 上对每个候选参考 bin 分别计算 Attention(Qᵢ, Kⱼ, Vⱼ)，按 P[t,j] 加权。

Ai,j = softmax(QᵢKⱼᵀ / √d) Vⱼ
O′ᵢ = Oᵢ + α mᵢ [Σⱼ Pt,jAi,j − Ai,ref]

i 表示生成 bin t 内的一个空间 Query 和一个 head；Aᵢ,ref 是该 Query 读取全部参考视频得到的归一化输出。改变的是生成视频对参考视频 Value 的加权组合，写入位置在各 head 的 Attention 输出之后、out_proj 之前。

4.3　与全程弱引导怎样结合

同时间弱引导引导目标为 Aᵢ,ₜ，只读取对应参考 bin。
P = I
当前跨时刻覆盖引导目标为 ΣⱼP[t,j]Aᵢ,ⱼ，读取相邻参考 bins。
P = 联合分配矩阵

二者可以在同一个修正公式里混合：保留一部分同时间 Attention，再加入跨时刻参考信息。上方“混合”按钮展示这一候选。α 继续控制总修正强度，β 控制其中跨时刻分配的占比。

Pmix = (1−β) I + β P
O′ᵢ = Oᵢ + 0.25 mᵢ [Σⱼ Pmix[t,j] Ai,j − Ai,ref]

β＝0 是同时间弱引导；β＝1 是已运行的跨时刻覆盖。β＝0.25 时，引导目标由75%同时间 Attention 和25%跨时刻 Attention 组成。这个混合版本待测试。

5　只补偿部分时间 RoPE 频带

本轮全频补偿对 16 个时间通道对都旋转 −ωbΔ。下一项坐标消融可以给每个频带一个系数：

q̃b = R(−gbωbΔ)qb,　0 ≤ gb ≤ 1

先比较全频、低频、高频和无补偿；仅改变辅助参考分支的 query 副本。后续可根据本次 Q/K 对各频带的相位敏感度选择 gb，检查某些频带是否主要影响跨参考的区分、另一些更影响时间对应。这种功能划分需要实际测量。

ReTime、Untwisting RoPE、RIFLEx 已分别研究频带感知的时间重定时、共享参考 Attention 的频率调制和视频长度外推。这一候选首先承担解释本轮相位结果的作用。它的实现增量很小，适合在全频版本出现混合收益时追加两条受控消融。

6　去噪策略与参考噪声的进一步假设

Flow matching 的速度 v=dx/dσ 描述沿去噪时间的变化；人物运动由沿视频物理时间 τ 的变化描述。把 v 的大幅变化直接当作快速动作，容易混入纹理、颜色和身份编辑。FlowMotion、AV-FlowEdit 已用 latent 差分、速度分解或显著性控制编辑。

更底层的一项高风险假设，是参考条件的噪声水平与对应 token timestep 是否影响运动读取：让参考条件的噪声及其 AdaLN 时间标签成对变化，观察中间层运动匹配是否更稳定。H3 当前参考条件接近干净，强噪声会改变模型熟悉的条件分布。可先做一个固定状态的 Attention 响应检查，再决定是否值得成片；当前优先级低于前述方案。

7　建议的下一轮顺序

本轮五组四列对照已完成。四条 IVEBench 样例加相位后的关键动作区间与原时序引导接近；Sam 书记舞的主窗手臂方向匹配时差由普通编辑的 13 帧，经原引导降到 1 帧，叠加相位后回到 12 帧。该窗口使用原有 0.3 关键点置信度阈值；连续帧中也能看到相应动作阶段延后。

Sam 三版 Motion Fidelity 分别为 0.85237、0.85227、0.85155，整体分数接近，局部动作时间差异明显。本轮以同帧视频与动作时间作为主要证据，MF 同时保留在结果页。
