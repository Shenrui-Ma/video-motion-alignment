# 离线研究展示

下载整个 `cloud` 文件夹，保持 HTML 与 `assets` 的相对位置，在浏览器中打开任一 HTML 即可查看。只下载一个 HTML 时，图片和视频不会随它一起下载。

这些网页是本地单文件报告的媒体分离副本。相同媒体按 SHA-256 去重，保留原始媒体字节；原始报告保持原样。服务器标识与本地绝对路径已在此副本中隐藏。

`manifest.json` 记录每份原始报告、导出网页和所有媒体的 SHA-256。可运行 `python3 tools/export_reports.py` 增量更新。
